# 发布指南（给小九）

## 一、这个包里是什么

一个能直接发出去的「AI 长期记忆」工具包：1 个零依赖脚本 + 2 个技能 + 5 篇方法论文档 + 安装/钩子脚本 + 模板。
**不含任何内网地址、密钥、客户信息**，代码是自研 MIT，可直接公开。

## 二、发布前只改三处

1. `LICENSE` 与各 `SKILL.md` 的 `author`：改成你希望署的名（现为「九品锦里e」）
2. `README.md` 顶部 `<this-repo>`：换成真实仓库地址
3. 如需挂你自己的联系方式/公众号，加在 README 末尾（可选）

## 三、建议仓库名与结构

- 仓库名：`agent-memory-kit`（中文名可用「AI 记忆底座工具包」）
- 首次提交就带上 `LICENSE`（**没有 license = 保留所有权利**，别人不能用，开源等于白发）
- Release 打 `v1.0.0`，附件放 `agent-memory-kit-v1.0.zip`
