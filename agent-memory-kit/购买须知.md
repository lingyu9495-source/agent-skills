# 购买须知

## 你买到的是什么

- 共享记忆底座完整包（v1.3.0）：底座脚本 + 11 篇文档 + 2 个可转发技能 + 模板 + Claude Code 集成示例
- 两种用法都在包里：**单机**（本地目录，零依赖）与**云端一座**（一台服务器，多设备/多人/多工具接进来）
- 授权：MIT，可自用、可商用、可交付给你的客户，保留版权声明即可

## 三分钟验货

```bash
unzip ai-memory-kit-shared-v1.3.0.zip && cd ai-memory-kit-shared
python scripts/ai_mem.py --help
export AI_MEM_DIR=./_m && python scripts/ai_mem.py add "暗号：蓝鲸" --as 测试
python scripts/ai_mem.py recall 蓝鲸
python scripts/ai_mem.py sources
```

看到 `ok`、召回命中、`sources` 里出现"测试"这个智能体，就算装对了。
Windows 用 `python`，`export` 换成 `set AI_MEM_DIR=...`。

## 装不上怎么办

先看 `docs/04-验收与踩坑.md` 的 18 个坑，八成在里面（最常见：`AI_MEM_DIR` 没设成同一个、FTS5 不可用、路径用了反斜杠）。
仍不通，把命令和报错原文发给作者。

## 说清楚的四条边界

1. **记忆怎么存，我们能保证**：你机器上的明文文件（`facts/*.jsonl` + `index.db`），能看、能删、能备份、能搬走。
2. **数据怎么流转，由你的部署和你所用工具决定**，本包不对任何"数据去向"作承诺。
3. **云端版调第三方模型**：语义检索与图片理解会调用模型服务商的 API，请求内容会经过对方。介意这一点就用单机版，或改本地模型部署（效果与成本另议）。
4. 不是向量数据库，不做图谱推理；"什么值得记"由你的写入规约决定。

## 共享范围说准确一点

- **同一个人的多个工具**共用一份记忆（豆包记的，WorkBuddy 能查到）
- **不同人之间默认隔离**（云端版一人一库，A 搜不到 B）
- **团队共享的是事实层**：口径、结论、坑，不含具体客户资料，做法见 `docs/10-团队事实层怎么做.md`

## 云端版怎么买

单机包不含云端部署服务。云端版是**部署服务**（装服务、建账号、接框架、培训、验收单），报价与交付清单见 `docs/11-云端版交付与报价.md`，按人头与接入工具数计价。
