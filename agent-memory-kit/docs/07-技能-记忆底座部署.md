# 给 AI 装长期记忆（可整包转发给别的 AI 执行）

## When to Use

- 用户问"能不能让 AI 记住我""你们的 AI 有没有长期记忆"
- 要给客户机、自己的服务器装记忆底座
- 被问"Obsidian / 知识图谱算不算记忆底座""框架自带的记忆为什么不够"
- 需要把整套安装方法交给另一个 AI / 同事去执行（本技能可直接转发）

## 一、先分清三样东西（90% 的人混在这）

| 东西 | 是什么 | 能当记忆底座吗 |
|---|---|---|
| 知识库 / Obsidian / 双链图谱 | 人写给**人**看的笔记 | ❌ 没有自动抽取与按需召回 |
| RAG 检索库 | 文档切块、向量化、按问题捞片段 | 🔶 半个，能查资料不会记住对话 |
| **记忆底座** | 谁、何时、说过/决定过什么；自动写入、自动召回、可遗忘 | ✅ |

**一句话判据**：只能靠 AI 主动去搜的，是**书库**；能自动记、需要时自动想起的，才叫**记忆**。

底座必须做四件事：写入、存储、召回、治理。缺一件就退化。

## 二、框架自带的够不够

所有框架都是**存得住、想不起**：对话全量落库，喂给模型的只有最近一段。
三层时间尺度：**存储=永久 / 上下文=几万 token / 实际记得=几天到两三周**。
对用户的一句话：**"它不是忘了，是想不起来。"**

单人轻量 → 自带够用；多人团队或交付客户 → 必须外挂，因为"每个 AI 都自觉写记忆"不成立。

## 三、三档选型（别一上来就装重的）

| 档 | 方案 | 依赖 | 内存 | 适合 |
|---|---|---|---|---|
| **A 轻量（默认）** | `scripts/ai_mem.py`：sqlite FTS5 + 明文 jsonl + MEMORY.md | 仅 Python3 | <30MB | 客户机、4G、无人运维 |
| **B 标准** | OpenViking 单机 + 云端 embedding | Py3.12 + 常驻进程 | ~450MB | 8G+、要语义召回与多成员隔离 |
| **C 重型** | Hindsight / Mem0 / Graphiti | Docker / Postgres | 2.5GB+ | 4C8G+、要时序追溯 |

决策树：≤4G 或没人运维 → A；要"自动记"且 8G+ → B；事实会变、要回答"三月时是什么状态" → C（否则别碰）。
**三条件按序看：机器算力 → 许可证 → 谁付 embedding 的钱。星标不参与决策。**

## 四、部署六步

1. **问三件事**：机器配置 / 谁用 / 数据能否出内网
2. **落地**：`bash scripts/install.sh`（或手动拷 `ai_mem.py` 并建软链）
3. **定写入规约**：什么算该记、什么不算、写时带哪些标签
4. **接钩子**（成败关键）：会话启动注入 `memory_hook.py --days 7`，或按需 `--query`，或做成工具
5. **灌第一批**：用户画像、项目现状、历史口径，20-50 条
6. **验收 + 陪跑**：见下

各框架落点：Hermes 写 memory provider；QwenPaw ≥2.3 用 `api.register_runtime_hook` + `ctx.inject_context`（2.2 的 `HookSpec` 那套不生效）；DSH 用会话注入通道；Claude Code 用 `CLAUDE.md` 或 hooks。
**装完必须重启服务并确认新进程环境变量真的带上了。**

## 五、验收四步（缺一不算装好）

1. 写入一条不可能被猜到的内容（"暗号：蓝鲸"）
2. 同会话召回命中
3. **重启/新会话**后它自己想起来 ← 90% 的假成功死在这
4. 换另一个成员账号搜同词，必须搜不到

硬证据不是"它答得像"，而是**会话文件里 grep 得到注入的 `【长期记忆·自动召回】` 标记**。

## 六、高频坑（详版见 docs/04）

- **中文整句搜不到**：`trigram` 只能救短词；整句必须走 `recall`（2-3 字片段 OR 打分），`search` 只给明确关键词
- **只装不注入** = 白装；**只写不读** = 只证明存通了，要查钩子有没有被调用
- **热层 >8KB** 开始挤上下文，模型变迟钝
- **一成员一账号**，混用即污染；**一个团队只一个主库**
- **AGPL-3.0**（OpenViking / Basic Memory）对客分发前过法务
- **429 时记忆静默丢失**（B 档）：调低并发、加重试
- **每日镜像必须白名单**，否则草稿把有用内容埋了
- **C 档三坑**：Postgres 不能 root 跑、HuggingFace 要镜像、体积 8-10GB
- **会话压缩悖论**：摘要不比原文短 → 压缩失败不退避 → 空转。给单会话设硬上限（>3MB 或 >800 轮就轮转）

## 七、对客话术（照抄）

> "AI 的记忆分两层：一层是它的记性（记住跟你打过什么交道），一层是你们的资料库（合同、SOP、历史文档）。
> 我们装的是第一层——记忆存在你自己机器上的一个文件里，你随时能打开看、能删、能带走。
> 第二层用你们现有的共享盘/知识库接进来就行。"

**边界**：不承诺"永不忘记"；不承诺跨客户迁移；客户数据不上我方服务器；embedding 费用谁出写进合同。
