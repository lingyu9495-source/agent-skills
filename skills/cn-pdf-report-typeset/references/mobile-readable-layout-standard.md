# PDF 手机可读排版 · 最终定稿标准（2026-08-18）

用户连续三轮反馈后定稿的标准。**所有 PDF 报告必须用此字号，不许回退到小字号。**

## 最终字号标准（比早期记录更高）

| 元素 | 最终字号 | 备注 |
|:---|:---|:---|
| 大标题 | ≥28pt | 封面 |
| H1 章节 | 18-20pt | 深蓝加粗 |
| H2 小节 | ≥17pt | 加粗 |
| 正文 | **≥16pt** | 手机可读底线 |
| 表格（含表头） | **≥15pt** | 表头深蓝底白字加粗 |
| 页脚 | 9pt | 不变 |

## 三个必须同时做的动作

1. **字号加大 → 同步加宽表格列宽**：15pt 字比 12.5pt 宽约 20%。只改字号不改列宽，文字更挤、更容易溢出。
2. **多个小表格 → 合并为综合表**：4 个能力小表各 5-6 行 + 15pt 字号，一页放不下时最后一个 keep() 块会被推到下一页形成"孤页"（整页只有 3 行内容，用户会看到空页）。**同类内容合并为 1 个大表**（如"能力"列 + "说明"列），一页自然放下。
3. **KeepTogether 只包"标题+同一块内容"**：不要包跨页的大块，否则整块被推走产生大面积空白。

## 验证清单（每次生成后必跑）

```python
import pymupdf
d = pymupdf.open(path)
# 1. 页数
print(len(d))
# 2. 每页溢出（A4 右边距 18mm → 内容右界约 545pt，x2>545 即溢出）
for i in range(len(d)):
    over = [w for w in d[i].get_text('words') if w[2] > 545]
    print(f'第{i+1}页 溢出{len(over)}个')
# 3. 均衡度（除封面/收尾页外各页字符数应接近）
for i in range(len(d)):
    print(f'第{i+1}页 {len(d[i].get_text().strip())}字符')
```

**接受标准**：0 溢出 + 正文页字符数差异不要过大（150-350 字符的页面要警惕孤页/空页）。

## 实例

- 能力边界 PDF v2（服务方案与合规说明）：5 页，表格 15pt、正文 16pt，综合能力表一页放下，0 溢出。
- 反面教材：4 个小表格版 → 能力4 孤页只有 109 字符；合并后 → 均衡。
