# 安装与使用说明（保姆级·照做即可）

> 看不懂技术名词没关系，照做就行。全程不需要装任何软件。

---

## 这是什么东西

一个 **"融资参谋"知识包**。把它交给你的 AI（豆包 / DeepSeek / Kimi / 通义 / ChatGPT 都可以），你的 AI 就会变成一个懂风投、懂政府基金、懂 TS 条款的**融资研判知识助手**（知识工具，不是融资咨询服务）。

它会告诉你四件事：
1. 你这个项目**够不够格**去融资
2. 该**找谁**（点名具体机构）
3. 还**缺什么**（可执行的清单）
4. **怎么递、多久能拿到钱**

---

## 方式一：粘贴即用（最简单，推荐）

**第 1 步**：打开你的 AI 对话（豆包/DeepSeek/Kimi 都行）

**第 2 步**：把本包里 **`SKILL.md` 的全部内容**复制，粘贴进对话框发送

**第 3 步**：接着把 **`references/` 里用得到的文件**也粘进去（一次粘 1-2 个就够，不用全粘）：
- 想找风投 → 粘 `01-vc-institutions.md`
- 想拿政府钱 → 粘 `02-gov-funds.md`
- 想了解市场行情 → 粘 `03-market-policy.md`
- 想知道怎么走流程 → 粘 `04-fundraising-playbook.md`
- 想对标别人的案例 → 粘 `05-case-benchmarks.md`

**第 4 步**：发送这句话开始：
```
按你上面的规则，帮我研判我的项目。我的项目情况是：______
```
（不知道怎么说？就粘 `templates/01-项目画像表.md` 里的 10 个问题，一条条答给 AI）

**第 5 步**：AI 会给你一份完整的研判报告：评分、该找哪几家机构、缺什么、怎么递。

> ⚠️ 提示：AI 的"记忆"有限。如果对话变长后它开始忘事，**重新粘一次 SKILL.md** 就行。

---

## 方式二：装进支持技能的 AI 工具（进阶）

如果你用的是 **Claude Code / Cursor / Hermes / Dify** 这类支持"技能（Skill）"的工具：

1. 把整个 `funding-fit-diagnosis` 文件夹放到工具的 skills 目录
2. 工具会自动加载 `SKILL.md`，并在需要时按需读取 `references/`
3. 之后直接用自然语言提问即可，不用手动粘贴

**Hermes 用户**：把整个文件夹放到你的 skills 根目录下，重启网关即生效。

## 方式三：跑打分脚本（想算精确分数的）

需要电脑上有 Python（一般都有）。打开命令行，执行：

```bash
cd funding-fit-diagnosis/scripts

# 先看演示（不填数据也能跑）
python match_engine.py --demo

# 算自己的项目：照 templates 里的格式写一个 profile.json，然后
python match_engine.py 我的项目.json
```

输出会给你两个精确分数 + 机构匹配清单。

## 常用提问模板（直接抄）

**判断能不能融到钱**
```
我做了个______（项目），现在______（阶段），团队情况是______，
想融______万。请按 skill 规则帮我研判：够不够格、该找谁、缺什么。
```

**找政府基金**
```
我在______（城市）有个______项目，年营收______万，有______项专利。
想申报政府基金/引导资金，该找哪一级？要满足什么条件？材料怎么准备？
```

**对标别人怎么融的**
```
帮我找 skill 里和我这个项目类似的融资案例，看看他们是怎么拿到钱的，
我差在哪。
```

**审 TS 条款**
```
我收到一份投资条款清单（TS），帮我逐条看有没有红线条款，
哪些必须改，哪些可以让。TS 内容：______
```

## 重要声明（请务必先看）

1. **本知识包是"自我研判工具"，不是成功保证。** 它给的是"适配度评估"和"该怎么做"，**不承诺、不保证**你一定融到钱、一定拿到补贴或一定通过评审。融资结果取决于市场、机构偏好、团队执行等多种因素。
2. **数据截止日期：2026 年 9 月。** 政策与机构偏好会变（尤其政府基金政策通常一年一调），做重大决策前请向机构官方渠道、当地主管部门核实最新口径。
3. **不构成投资建议、法律意见、财务意见或证券投资咨询。** 本工具不提供证券投资顾问服务，不涉及任何证券买卖建议。涉及正式签约、股权安排、申报材料，请咨询执业律师、注册会计师或当地主管部门。
4. **不代客融资、不接触资金、不收取融资分成。** 本工具只做信息整理与自我评估辅助，不代理投递、不承诺对接资源、不经手任何资金。
5. 本包内所有数据均标注来源（【官方】/【媒体】/【推断】）；无法核实的部分已明确标注"未查到/待核实"，请以官方披露为准。
6. **机构联系方式**：各机构官网可达，但**官方普遍未公开 BP 投递邮箱**——网上流传的 `bp@机构域名` 类邮箱多为第三方推测，投递易退信。请走官网通道或通过 FA/产业方引荐。
7. **匹配结果是"建议"不是"门票"**：被列入名单只说明条件相对契合，**不代表机构会投你**；未被列入也不代表没有其他路径（可能有未收录的机构适合你）。
