# 项目画像采集表（10 问）

> 用法：把这张表发给用户，让他逐项填。**缺项越少，研判越准。**
> 客户不方便填表就口头问，AI 自己填进这张表。

---

## 一、基本信息

| # | 问题 | 填写 | 备注 |
|---|---|---|---|
| 1 | 一句话说清你做什么、解决什么问题 | | 别写"平台""生态"，写具体 |
| 2 | 赛道/行业细分（越具体越好） | | 如"工业设备预测性维护"优于"工业互联网" |
| 3 | 公司成立时间 + 现在到哪一步了 | | 概念期／有产品／有收入／规模复制 |
| 4 | 注册地在哪？实际经营地在哪？ | | **政府基金必问** |
| 4b | 愿不愿意为了拿钱迁址或到某地设子公司/基地？ | 愿意／不愿意／看条件 | 直接决定政府基金能不能走 |
| 5 | 团队背景（学历、大厂经历、连续创业、行业年限） | | 早期项目权重最高 |
| 6 | 技术壁垒：专利 __ 项、软著 __ 项、独有工艺/算法/牌照 | | 有没有别人做不出来的东西 |
| 7 | 商业化数据：年营收 __ 万、同比增速 __%、付费客户 __ 家、复购率 | | 后期项目权重最高 |
| 8 | 本轮想要多少钱？拿来干什么？愿意放多少股权？ | | 金额决定匹配哪一档机构 |
| 9 | 之前拿过什么钱？（融资/银行授信/政府资金/亲友） | | 判断可衔接性 |
| 10 | 你最想要的是什么：钱／资源／背书／客户？急不急？ | | 决定路线优先级 |

## 二、加分信息（有就填，没有跳过）

- 主要客户是谁？有没有行业头部客户？
- 毛利率大概多少？
- 市场空间你估计多大？（可服务市场）
- 有没有高新技术企业／专精特新／科技型中小企业认定？
- 研发投入占营收比例？
- 有没有海外业务？
- 有没有已签的大额订单／框架协议？
- 你预想的退出路径：IPO／被并购／长期分红？

## 三、AI 采集须知（给使用本 skill 的 AI）

1. **一次问完**，不要把 10 问拆成 10 轮挤牙膏。
2. 用户答得含糊就**追问一次**（如"有收入"要问出大概数字），但不要逼问超过两轮。
3. 用户明确不提供的项，标"未提供"，并在结论里提示"该项缺失会影响判断准确性"。
4. **采集完成后先复述一遍画像**，让用户确认无误，再进入评分。
