# 01 · 选题与竞调

> 这一份解决两件事：**写什么**（选题）和 **凭什么你这篇能比已经发过的强**（竞调）。
> 适用对象：豆包智能体（它按本文件做选题判断）+ 你（你把热榜数据喂给它）。

---

## 一、选题的唯一硬标准

> **能被一句话概括成「这笔钱／这件事，到底怎么走的」。**

概括不出来 → 换选题，不写。
这句话要能填进这个句式：

```
「〔谁〕在〔什么事〕上，一年〔多掏／少赚／省下〕了 ___，因为〔机制〕。」
```

填不出具体机制和方向（多掏还是少赚），说明你还没想清楚，写出来必然是空文。

**反例（都别写）**：某技术框架开源了 / 某个工具怎么用 / 某个概念的科普 / 行业趋势展望。
**正例方向**：一笔成本怎么涨的、一个岗位的活被谁接走了、一项政策改动后谁多掏钱、一家店的钱从哪来到哪去。

---

## 二、选题方向优先序（自己定，但要定）

写进智能体人设里的 4 个方向，按你自己的兴趣排（**兴趣是第一顺位**，写不感兴趣的题写不好）。一个可用的示例排序：

| 顺位 | 方向 | 典型题 |
|:--|:--|:--|
| 1 | 经济 | 企业成本账、用工结构、社保与税、行业冷暖、并购与出海 |
| 2 | 时事 | **72 小时内**发生、能给出确切日期与信源的事件 |
| 3 | 历史 | 历史事件／人物折射出的商业规律（做知识增量） |
| 4 | 自家主业的落地 | 你的领域怎么进了真实生意、动了谁的成本、谁在赚钱 |

---

## 三、过三关（三个「是」才写）

| 关 | 问题 | 过不了的样子 |
|:--|:--|:--|
| **信息增量关** | 读者看完，能拿到一个他原本不知道的**认知**或**一笔账**吗？ | 只是把新闻复述一遍 |
| **身份认同关** | 目标读者扫一眼标题，会觉得「**写的是我**」吗？ | 写给同行看，外行看不懂 |
| **风险关** | 有没有碰到 `02-写作与合规红线.md` 的任何一条？ | 涉及未公开政策、群体性事件、投资建议 |

任一关过不了 → **直接说「这个选题不建议写」，并给 2 个替代选题**。别硬写。

---

## 四、选题评分卡（可数，≥7 分才动笔）

| 项 | 0 分 | 1 分 | 2 分 |
|:--|:--|:--|:--|
| 能算账 | 全是观点 | 有一个数字 | 能算到读者自己的规模 |
| 时效 | 半年以上的旧闻 | 7 天内 | 72 小时内 |
| 大众词 | 专业术语当标题 | 半专业 | 普通人也说得出（「菜价涨了」「工厂关门」这种） |
| 差异化 | 别人都写过同样角度 | 角度略有不同 | 有别人没算过的那一层 |
| 风险 | 踩红线 | 边缘 | 干净 |

**经验规律（重要）**：同一个账号、同一个月里，单篇阅读量的差距可以到**几百比几**。
**选题的权重 > 标题的权重 > 排版的权重**——选题错了，后面全白做。

## 五、免费热榜渠道（都能直接用，不需要登录）

### 5.1 谁去抓

| 谁 | 怎么拿热榜 |
|:--|:--|
| **你（有电脑）** | 用下面的 curl 命令抓原文，把结果粘给智能体 |
| **智能体** | 让它用自己的联网搜索能力找当天热点；拿不到就直说，请你贴一份 |
| **兜底** | 直接打开这些平台的网页版热榜页，自己看 |

### 5.2 四个接口（实测可用，公开 HTTP，无需登录）

```bash
# ① 百度实时热点（带完整一句话描述，最省事）
curl -sL "https://top.baidu.com/api/board?platform=pc&tab=realtime" \
  -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/126.0.0.0 Safari/537.36" \
  -H "Referer: https://top.baidu.com/board?tab=realtime" -m 15

# ② 抖音热搜（带热度值 + 逐条时间戳，可判时效）
curl -sL "https://www.douyin.com/aweme/v1/web/hot/search/list/" \
  -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36" \
  -H "Referer: https://www.douyin.com/" -m 15

# ③ 微博热搜（带逐条上榜时间，时效最灵敏）
curl -sL "https://weibo.com/ajax/statuses/hot_band" \
  -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/126.0.0.0 Safari/537.36" \
  -H "Referer: https://weibo.com/" -m 15

# ④ 今日头条热榜（origin 参数必带，否则报参数错误）
curl -sL "https://www.toutiao.com/hot-event/hot-board/?origin=toutiao_pc" \
  -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36" \
  -H "Referer: https://www.toutiao.com/" -m 20
```

网页兜底页（接口失效时用）：百度 `top.baidu.com/board?tab=realtime`、抖音热榜页、微博热搜页、头条热榜页。

> 这些都是公开接口，**平台随时可能改版**——失效了不要死磕，直接看网页版热榜，或换下面「找人问」的路子。
> 抓的时候**别连续高频请求同一个源**（会触发反爬），条与条之间留 1-2 秒。

### 5.3 各源的字段与怎么读

| 源 | 关键字段 | 怎么用 |
|:--|:--|:--|
| 百度 | `word` / `hotScore` / `desc` | `desc` 是现成的一句话背景，可以直接当事实底稿 |
| 抖音 | `word` / `hot_value` / `event_time`（unix 秒） | `event_time` 是**时效判据**；`trending_list`（热度 0）是上升热点 |
| 微博 | `word` / `num` / `onboard_time`（unix 秒）/ `category` | `onboard_time` 最灵敏；`category` 可当赛道标签 |
| 头条 | `Title` / `HotValue`（**字符串，要转数字**）/ `Label` | `Label`：`new`=新上榜、`recentProgress`=新进展、`depth`=专题（**不是**时效信号） |

**「多榜同现 = 真热点」**：同一个话题在 2 个以上平台同时上榜，才值得动笔。

## 六、时效判据（写时事题必须过这一关）

| 判据 | 做法 |
|:--|:--|
| **≤72 小时优先** | 用抖音 `event_time`、微博 `onboard_time` 直接算（unix 秒 → 北京时间，记得别重复加 8 小时） |
| **超过 7 天** | 只做「历史／规律」向角度，**正文第一段必须写明事件日期**（格式「X 月 X 日」） |
| **百度「新」标签不可信** | 百度没有逐条时间戳，标「新」的可能是几天前旧闻回热——必须用另一个源反查 |
| **模糊时间词禁用** | 正文里**禁用**「刚刚／近日／日前／这几天」这类词，一律写具体日期 |
| **确认不了今天几号** | 让智能体**先向你要当天日期**，别自己猜 |

**检索式反查时间**（不确定某一话题是不是新的）：用搜索平台搜话题核心词，看结果里的「X 分钟前／X 小时前／昨天／X 天前」标记。搜索**只用于反查时效和找原始报道**，拿热榜要用上面的平台接口。

## 七、竞调：把「别人已发的内容」变成你的差异化角度

三步，**必须输出结果**（这是智能体交稿前的一步，不允许跳过）：

**第 1 步｜列清单**：搜这个话题，把已经有人写过的内容列出来，只记「他们说了什么」——
- 事实层：他们复述了哪些事实？
- 观点层：他们给了什么结论？
- 数字层：他们用了哪些数字、什么口径？

**第 2 步｜找空隙**：他们**都没说**的是什么？通常是这三类：
1. **口径没算到读者自己的规模**（他们算一个亿的大公司，你可以算「20 个人的小厂」）
2. **只说了结果，没说机制**（他们把涨价的锅甩给某方，你可以拆成本结构）
3. **停在第一层账**（你可以把线拉出来算第二遍，第二遍常常推翻第一遍）

**第 3 步｜写下来**（三行，进交付物）：
```
同题常见写法：___
本文差异化角度：___
本文独家的一笔账是：___
```

**注意**：可以用别人的事实报道做信源（标注媒体名 + 日期，**单处引用 ≤60 字**），但**不许整段搬运、不许照搬图表、不许洗稿式改写**。观点必须是你自己的。

## 八、防撞车：自己维护一份选题台账

在包里建 `assets/已发选题台账.md`，**每发一篇补一行**。表格：

```markdown
| 发布日期 | 标题 | 选题方向 | 角度／独家的一笔账 | 阅读 | 转发 | 备注 |
|:--|:--|:--|:--|--:|--:|:--|
```

写新稿前先查两件事：
1. **30 天内**写过的题材、角度、标题**不许重复**；
2. 同一个热点可以再写，但**角度和标题必须完全不同**。

台账还有一个用处：攒够 10 行以后，你能看出「哪类题材在这个号上真的有用」——往后选题就照着有效的类型走。
