# 02 · 写作与合规红线

> 这一份是**写作的施工图**：标题怎么算字节、正文怎么搭骨架、数字怎么写才算有来源、哪些话一句都不能说。
> 交付前把第五节的自检表跑一遍，全 ✅ 才算写完。

---

## 一、标题（决定 90% 的打开率）

### 1.1 硬限制：≤ 64 字节

算法和平台完全一致：

| 字符 | 字节 |
|:--|:--|
| 中文、全角标点（，。、？！「」） | **3 字节** |
| 半角字母、半角数字、半角标点、空格 | **1 字节** |

实操约 **≤20 个中文字**。自检命令（把最终标题存成 `最终标题.txt`）：

```bash
python -c "t=open('最终标题.txt',encoding='utf-8').read().strip();print(len(t.encode('utf-8')),'/64')"
```

要写算式就写出来，例：`AI(2) + 落地(6) + ，(3) + 先看(6) + 这(3) + 3(1) + 个(3) + 报表(6) = 30/64`。
超了**砍修饰词，别砍信息词**。

### 1.2 字符限制

- 标题**只允许**：中文、半角字母数字、以及 `，、。·？！—`。
- **禁 emoji、禁生僻符号、禁方括号**。
- **标题字段里禁止出现双引号 `"` `'` 和中文引号 “”‘’**——后台标题字段遇到引号会出问题。需要引用一律用 **「」**。（正文不受这条限制。）
- **标题不写问号**（正文和文末互动卡可以正常用问号）。

### 1.3 九个可用公式（交稿至少覆盖 3 种不同公式）

| # | 公式 | 例子（套你的题材写） |
|:--|:--|:--|
| 1 | 观点断言「X，其实很 Y」 | 便宜的打车，其实在偷你的时间 |
| 2 | 常识反转 | 先上设备的那批厂，先亏钱 |
| 3 | 数字 + 冲突 | 花 30 万改车间，第一年只省 8 万 |
| 4 | 身份对号 | 小公司的预算，为什么总被砍 |
| 5 | 不相干并置 | 保洁阿姨的第一个台账 |
| 6 | 大时代 + 定论 | 这轮涨价，属于会算账的人 |
| 7 | 损失厌恶 | 别再让业务部门自己去试 |
| 8 | 悬念缺口 | 多数人卡在这一步，不是钱的问题 |
| 9 | 数字清单 | 看一项成本，先看这 3 张表 |

### 1.4 标题铁律

- **核心关键词放前半段**（推荐流和站内搜索都吃前半段）；目标读者扫一眼要觉得「**写的是我**」。
- **情绪冲突词白名单**（标题至少命中 1 个）：
  `砍 / 亏 / 偷 / 坑 / 涨 / 贵 / 多掏 / 少赚 / 退场 / 不划算 / 走不通 / 写在条件里`
- **禁标题党**：不写「必看 / 速看 / 震惊 / 99% 的人不知道 / 看完你就懂了 / 建议收藏」。
- **标题-正文一致性**：标题里的**每个数字和事实，必须在正文里能指到具体段落**（每个候选标题后面标上「数字出处：第 X 段」）；指不到就换标题。数字冲突类标题的账**必须来自公开信源，不得为凑冲突自造数字**。

## 二、正文写作

### 2.1 骨架：冲突 → 摆事实 → 算账 → 落点 + 转发句 → 行动

1. **开头 3 句必须抓人**（五选一）：① 反常识判断 ② 真实场景代入 ③ 扎心数字／账 ④ 个人故事或自嘲（受第 4.4 节的纪律约束）⑤ 悬念留白（慎用）。
   **快筛**：前 3 句里有没有**具体的人／场景／数字／反常识**？没有 → 重写开头。
2. **摆事实**：能核实的先摆清（原话、时间、谁说的、到目前为止官方的回应），把「**事实**」和「**我的推演**」明确分开写。
3. **算账（本文的差异化核心）**：每一层论证都要给 **机制 + 具体数字**，把大数拆成读者能对号入座的小口径——「一个人一个月差 29 元」「20 个员工一年多掏 6870 元」。
   **长文题材必须算两层**：第一层算完，再「把这条线拉出来算第二遍」，第二遍常常推翻第一遍的结论。这是最有效的结构。
4. **落点 + 转发载体（两项都要）**：
   - ① 一个干净的判断句（**不是鸡汤**）。反例（禁）：「AI 取代技能，所以人要有品位」。正例：「四年制买的是成本的确定性，不是成本的下降」。
   - ② 一句**能脱离上下文、≤30 字、能被读者原样复制给同事看**的话（转发载体）。**写不出第 ② 句 = 本篇未完成。**
5. **行动**：给一条读者**今天就能做**的自测判据或最小动作。
6. **结尾呼应开头**：开头挖的坑必须填上。

### 2.2 节奏（可数，做不到就是「豆腐块」）

| 项 | 判据 |
|:--|:--|
| 段落长度 | 每段 **≤60 个中文字且 ≤2 个句号** |
| 最短段 | **≤15 字**，全文至少 3 处 |
| 小标题 | **每 300-400 字一个**；必须**口语动词或问句开头**（「这笔账我算了第二遍」✅），**禁名词短语**（「成本水位」❌） |
| 视觉模块 | 每 250 字内至少 1 个非段落模块（卡片、图、引用块…） |
| 对象感 | 每 150 字内至少 1 次「你／你们」 |
| 新信息 | 每 300 字给一个新数字／新账／新张力／新视角 |
| 篇幅 | 常规档 **1200-1500 字**；深度档 **2000-2800 字**（热点×算账类、产业/政策解读类、用工/成本结构类用深度档） |
| 自污 | 主动认一句自己没算到／看走眼的地方 |

自检命令（正文存成 `正文.md`）：

```bash
python -c "
t=open('正文.md',encoding='utf-8').read()
ps=[p.strip() for p in t.splitlines() if p.strip() and not p.strip().startswith(('#','>','|','-'))]
print('段落数',len(ps),'| 最短段',min(len(p) for p in ps) if ps else 0)
print('超 60 字的段:',[p[:16] for p in ps if len(p)>60])
print('句号超 2 个的段:',[p[:16] for p in ps if p.count('。')>2])
print('短段(≤15字)处数',sum(1 for p in ps if len(p)<=15))
print('“你”出现',t.count('你'),'次')
"
```

### 2.3 AI 味自检（交付前逐条过，中一条就改）

- [ ] 三段式排比、每段一样长、每段一个加粗金句 → **最重的 AI 指纹，必拆**
- [ ] 对仗式可引用金句（「AI 不会…只会…」）→ 改糙或删
- [ ] 设问式定义（「什么叫 XX？就是…」）→ 改成直接说
- [ ] 完美递减数据（「第 1 天错 3 处，第 10 天错 1 处」）→ 写毛边
- [ ] 「说句实在话／其实／说白了／值得注意的是」→ 删
- [ ] 结尾把全文再复述一遍 → 删，只留判断
- [ ] 案例均匀分布、句式同模 → 打乱，换讲法
- [ ] 「这就好比」「举个例子」式比喻起手 → 删

### 2.4 语感锚点

语感靠**模仿**建立：挑 3 篇你自己所在领域里「读起来最像人写的」文章，看它们的段落长度、算账密度、怎么标注推测。**学结构，不抄句子。**

## 三、数据纪律（每个数字三件套）

| 项 | 要求 |
|:--|:--|
| **来源** | 媒体名 + 日期，或官方通告文号。**没有来源的数字不许写。** |
| **口径三要素** | 统计期 / 统计范围 / 单位。三个都要写出来。 |
| **混用不同来源** | 把两个不同来源的数字放在一起比较或相除时，必须加一句口径说明：「这两个数的统计周期不一样，只是量级参照」。 |
| **推测** | 涉及未来或推测，必须显式标注：「这是我的推测，不代表当事人的说法」。 |
| **计数** | 稿件里所有数量指标一律按第七节的**计数口径**算，别自己另定算法。 |

## 四、一票否决条款（写完逐条自查）

### 4.1 内容禁令

1. **禁工具教程／提示词教学**：不写「怎么跟它说话」「怎么下指令」「工具使用说明书」。
   判断法：**把「AI」两个字删掉，这篇还剩不剩商业价值？** 不剩 = 教程文，重写。
2. **禁自吹自擂**：不写「我给 N 位客户部署了…」「我帮谁搞定了…」。
   判断法：**把「我」全删掉，还剩不剩干货？** 不剩 = 自夸，重写。
3. **禁投资建议**（没有证券资质）：不荐股、不荐基、不给具体上市公司做投资价值或股权收益测算；「上市能值 X 亿」「若持有至今赚 X」一律不写。
   **边界**：可以引用公开财报里的**经营指标**（门店数、单店产出、费用率、毛利），**不得**做市值、股价、投资价值、股权收益的表述或测算。
4. **禁营销口吻**：不写「教你赚钱」「帮你落地赚钱」「用 20 年经验教你」。文章定位 = **经验分享／知识分享**。
5. **禁导流私域**：不出现微信号、二维码、邮箱、手机号、「加我领资料」「私信我」「进群」、其他平台账号名。站内引导只允许「微信搜一搜：〔你的公众号名〕」。
   并且**不得以资料、名额、优惠、代算等任何回报承诺换取关注／转发／评论**（平台明文禁止诱导关注与诱导分享）。
6. **禁 AI 打标**：结尾不出现「由 AI 辅助创作」「AI 生成」等字样。
7. **禁绝对化断言**：不写「第一个／唯一／首创／最有效／永久有效」，除非有硬信源；**「第一」类必须先核实同类先例**（最容易漏）。
8. **禁算命占卜运势**；传统文化只写文化与哲学。
9. **引用纪律**：引用公开报道只做必要摘引（**单处 ≤60 字**），不整段搬运、不照搬图表、不做洗稿式改写；引用他人观点必须标明出处。
10. **时事纪律**：不评论党政机关决策细节、不解读尚未公开发布的政策文件、不写群体性事件与社会争议事件；**官方通报出来之前，不写事件原因与责任归属**。
11. **无外链权限的现实**：未认证的个人订阅号在正文和「阅读原文」里都放不了外网地址——别写「详见阅读原文」「点击链接」，改成站内动作。

### 4.2 个人经历纪律（防止编造）

个人经历**只允许两种写法**：

- ① **泛化的真实经验**：「我见过的人里，多数…」——**不含年份／地名／人名／具体数字**；
- ② **有信源可查的第三方案例**（媒体名 + 日期）。

**禁止自拟具体年份、地名、企业、人物、直接引语。** 确需亲历细节时，写 `【待补真实素材：___】` 留白，不得虚构。
直接引语一律要能指到信源，指不到就改成间接转述。

### 4.3 必备护身符（每篇都有，缺一不可）

1. **署名**：`文｜〔你的署名〕`
2. **免责声明**：模板见 `SKILL.md` 第四节，可按自己的说法调整，但不能删这一块。
3. **资料参考行**：只写「媒体名 + 日期」，**逐条列全、不带链接**。

### 4.4 固定文案（写进人设里，只许原样照抄）

| 位置 | 你的内容 |
|:--|:--|
| 品牌栏副标语 / 文末 CTA | 〔你自己定一句，例：聊聊我的本行，分享点真实想法〕 |
| 文末署名 | `文｜〔你的署名〕` |
| 文末收尾句 | 〔收尾句〕。微信搜一搜：〔你的公众号名〕 |
| 资料参考行 | `资料参考：〔媒体名+日期，逐条列全〕` |

## 六、常见返工原因（照着躲）

| 返工点 | 正确做法 |

## 七、计数口径（防争议，一律按这里算）

> 同一篇稿子因为口径不同会被判出「合规」和「打回」两种结论——所以所有数量指标一律按本节定义，自检表里加注口径即可，不必纠结另一种算法。

| 指标 | 口径（只算这些，别的一律不算） |
|:--|:--|
| **正文字数** | 只算**正文段落文字**（含标点）；**不含**大标题、小标题、引语卡、金句卡、图注、署名、免责声明、资料参考行 |
| 段落数 / 最短段 | 只算正文段落 `<p>`；不含小标题、引用块、图段、署名、免责 |
| 小标题数 | 只算胶囊小标题的个数 |
| 「你」密度 | 分子 = 正文段落里的「你／你们／你的」；分母 = 正文字数（同上口径），单位：次/千字 |
| 配图张数 | 只算**正文插图**（`[图片1]`~`[图片N]`）；不含表头品牌图、不含封面 |
| 「第 X 段」 | 只数排版 HTML 里正文 `<p>` 的先后序号（配图清单里注明此口径） |
| 标题字节 | 只算**标题文本本身**（不含 `# ` 前缀、不含「（N字节）」标注）；中文/全角标点 = 3，半角字母数字标点空格 = 1 |
| 摘要字数 | 含标点，≤100 字符（目标 80-95） |
| 正文里的图 | `正文.md`（Markdown）**不放**任何图片占位符；图片位置只写在配图清单与排版 HTML 里 |
| 表头图 | 只保留 `<img src="[表头图]">` 占位符；**不进配图清单、不写提示词** |
| `alt` 与图注 | 写**同一句**文案（图注可带「图 N」前缀，alt 也带），避免两处不一致 |
| 资料参考 | 只写「媒体名 + 日期」，**不带链接** |
| 稿内日期 | 填**交稿当日**日期（不知道当天日期就先问，别猜） |
