# 公司章程核心条款设计模板

> 来源：2026-05-18 法律深度学习轮次1 — 公司法基础 L1
> 适用场景：新设有限责任公司章程起草

---

## 1. 出资安排

```markdown
第X条 出资安排

1. 公司注册资本为人民币___万元。
2. 股东出资方式、出资时间如下：

   | 股东 | 出资额 | 出资方式 | 缴足期限 |
   |------|--------|---------|---------|
   | ___ | ___万 | 货币 | YYYY-MM-DD |

3. 董事会应于每年度结束后三十日内核查股东出资情况。
4. 股东未能按期缴纳的，按日万分之___支付违约金。
5. 首期出资须在章程签署后___日内到位，余款在5年内分期缴纳。
```

**法律依据**：《公司法》第47条（5年实缴）、第48条（出资方式）、第51条（董事催缴）

---

## 2. 表决权特别安排

```markdown
第X条 表决权安排

1. 股东会会议由股东按照【实缴出资比例/认缴出资比例】行使表决权。
2. 【创始人姓名】对以下事项享有一票否决权：
   (1) 增资、减资、合并、分立、解散；
   (2) 修改公司章程；
   (3) 出售公司核心资产或核心知识产权；
   (4) 增加或减少注册资本的方案；
   (5) 公司对外提供担保（日常经营担保除外）；
   (6) 变更公司经营范围；
   (7) ___（其他重要事项）。
3. 未完全履行出资义务的股东，其表决权按实缴出资比例行使。
```

**参考案例**：(2019)京03民终10819号（一票否决权有效）、(2017)最高法民终18号（表决权限制有效）

**注意**：一票否决权条款须全体股东一致同意，且不得违反公司法强规。

---

## 3. 股权转让限制

```markdown
第X条 股权转让

1. 股东向股东以外的人转让股权，须经其他股东过半数同意。
2. 其他股东在同等条件下享有优先购买权。
3. 转让价格有争议时，以【最近一期经审计的每股净资产值/最近一轮融资估值的___折】确定。
4. 创始股东在公司上市前转让股权的，须经全体创始股东一致同意。
5. 股东退出时，其股权须在___日内转让给公司指定受让人：
   - 主动离职 → 按【公允价值 / 约定价格】转让
   - 被罢免/除名 → 按【约定价格 / 评估价】转让
6. 新增股东与老股东享有同等优先购买权。
7. 创始股东转让股权时，其他创始股东享有随售权（Tag-Along Rights）。
```

**参考案例**：(2014)陕民二申字第00215号（指导案例96号——"人走股留"条款有效）；(2018)沪02民终1792号（离职退股有效，价格不得显失公平）

## 4. 法定代表人

```markdown
第X条 法定代表人

1. 公司法定代表人由【创始人姓名】/【董事长/总经理】担任。
2. 法定代表人对外代表公司，其签署的法律文件由公司承担法律后果。
3. 法定代表人辞任董事或经理职务的，视为同时辞任法定代表人。
4. 公司应于法定代表人辞任后三十日内确定新的法定代表人。
5. 【可选】法定代表人的对外担保/大额合同签署须经董事会书面授权。
```

**法律依据**：《公司法》第10条（任职与辞任）、第35条（变更登记）、第11条（越权保护）

---

## 5. 利润分配

```markdown
第X条 利润分配

1. 弥补亏损和提取法定公积金（10%）后，剩余税后利润按【实缴出资比例 / 协商比例】分配。
2. 【可选】经全体股东一致同意，可不按出资比例分配。
3. 董事会应在年度结束后___个月内提出利润分配方案，提交股东会审议。
4. 股东会决议分配利润的，应在决议作出之日起___个月内完成分配。
```

**注意**：2024新公司法允许不按出资比例分红，但须全体股东一致同意。

---

## 6. 新增股东/增资

```markdown
第X条 增资与引入新股东

1. 公司增资须经代表三分之二以上表决权的股东通过。
2. 增资时，老股东在同等条件下按其持股比例享有优先认购权。
3. 引入新股东的，新股东须签署公司章程、同意受原章程约束。
4. 增资价格不得低于最近一期经审计的每股净资产值。
```

---

## 7. 退出与清算

```markdown
第X条 股东退出与公司清算

1. 股东退出方式包括：股权转让、公司回购、公司法规定的其他方式。
2. 股东依照公司法第89条（异议股东回购请求权）请求公司回购的，公司应在收到请求后___日内答复。
3. 公司解散的，应当在解散事由出现之日起十五日内成立清算组。
4. 清算期间公司不得开展与清算无关的经营活动。
```

---

## ⚠️ 章程条款效力边界

| 可以约定（自治空间） | 不可以约定（强制无效） |
|---------------------|----------------------|
| 表决权按实缴比例行使 | 剥夺股东知情权、质询权 |
| 股权转让限制（合理） | 禁止股权任何形式的转让 |
| 一票否决权（全体同意） | 违反公司法强规（如不当限制股东退出） |
| 离职退股（合理对价） | 价格条款显失公平（法院可调整） |
| 非按出资比例分红（全体同意） | 免除董事、监事法定责任 |
