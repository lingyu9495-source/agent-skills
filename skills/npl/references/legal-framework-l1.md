# 不良资产法律监管框架与资产形成原理

> L1基础 · 轮次1深度知识梳理 · 2026-05-18
> 编制：助手（不良资产专家）
> 核心关切：不良资产在"法"与"监管"双坐标系中的定义与实务

---

## 一、法律定义 vs 监管定义

| 维度 | 法律定义 | 监管定义 |
|------|---------|---------|
| 依据 | 《民法典》《合同法》《担保法》 | 《商业银行金融资产风险分类办法》(2023) |
| 视角 | 合同权利是否受到侵害 | 资产风险程度与回收确定性 |
| 触发条件 | 违约事实发生 | 逾期天数/减值迹象 |
| 法律后果 | 可诉讼/保全/执行 | 需计提拨备/限制展业 |
| 核心文件 | 借款合同+担保合同 | 五级分类认定表+拨备计提底稿 |

**关键洞见**：不良资产既是法律概念（债权受到侵害），更是监管概念（监管分类标准决定银行行为）。两者之间的**剪刀差**构成了灰色地带和套利空间。

## 二、五级分类制度（2023版新规）

```
新五级分类框架（2023年2月发布，7月施行）
┌────────────────────────────────────────────────┐
│  正常类  │ 债务人能履行合同，无逾期               │
│──────────┼─────────────────────────────────────│
│  关注类  │ 逾期<30天，存在潜在风险信号            │
│──────────┼─────────────────────────────────────│
│  次级类  │ 逾期30-90天，风险较低，回收率60-80%    │
│──────────┼─────────────────────────────────────│
│  可疑类  │ 逾期90-180天，风险中等，回收率40-60%   │
│──────────┼─────────────────────────────────────│
│  损失类  │ 逾期>180天，风险较高，回收率20-40%     │
└────────────────────────────────────────────────┘
```

### 2023版四大变革
1. **范围扩大**：从贷款扩展到所有信用风险金融资产
2. **逾期天数硬约束**：>90天至少初级不良
3. **交叉认定**：同一债务人多项逾期视同整体风险上升
4. **重组资产保留分类**：重组后至少保留不良6个月

```
  正常类     关注/次级     次级/可疑    AMC/NPAS/核销
```

## 四、五维估值约束模型

```
估值上限 ← 受制于
  ├── ① 拨备覆盖率约束（≥150%）
  ├── ② 回收率约束（抵押物+担保）
  ├── ③ 流动性约束（AMC资金成本）
  ├── ④ 监管约束（银登中心规则）
  └── ⑤ 法律约束（诉讼周期2-5年）
```

### 简化定价公式
```
估值 = 抵押物变现价值 × 抵押率 + 信用回收价值 × 回收率
        - 处置成本(3-8%) - 时间折价(年化10-15%)
```

### 折扣率速记口诀
| 分类 | 有抵押折扣 | 纯信用折扣 |
|------|-----------|-----------|
| 次级类 | 30-50% | 10-30% |
| 可疑类 | 50-70% | 30-50% |
| 损失类 | 70-90% | 50-70% |

**"次三可五损七成"**

## 五、法律尽调三查法

```
① 查合同效力：签章、抵押登记、担保决议
② 查优先权：工程款>抵押权>税收>普通债权
③ 查时效：诉讼时效3年/保证期间/抵押权行使期限
```

**口诀**：合同有效是前提，抵押登记要确权，优先权序别搞反，时效过期全白干。
