# 不良资产分类-处置映射速查表（A2综合）

> 从L1分类到L3处置的快速决策参考

## 一、12格映射矩阵（一句话版）

```
                 次级(60-80%)       可疑(40-60%)       损失(20-40%)
                 ──────────────     ──────────────     ──────────────
不良贷款   →    重组+AI催收        综合+差异化处置     批量打包快速转
不良债权   →    协商+催收          诉讼+保全并行       折扣转让出清
实物资产   →    运营提升价值        拍卖快速变现        拆分分别处置
股权资产   →    引入战略投资        公开挂牌转让        清算及时止损
```

## 二、估价方法速配

| 资产类型 | 主方法 | 核心参数 |
|---------|:-----:|:--------:|
| 银行不良贷款(大额) | DCF法 | 折现率12-20% |
| 银行不良贷款(小额) | 交易案例比较法 | 历史折扣率30-50% |
| 个贷不良 | 大数据评分模型 | 回收率分布 |
| 有担保债权 | 抵押物评估法 | LTV比率60-80% |
| 无担保债权 | 假设清算法 | 清偿比例 |
| 住宅 | 市场比较法 | 可比案例价 |
| 商办 | 收益法 | 资本化率5-8% |
| 工业用地 | 成本逼近法 | 基准地价 |
| 在建工程 | 假设开发法 | 完工价值-续建成本 |
| 控股权 | DCF+可比公司法 | EBITA倍数 |

## 三、30条处置技巧分类目录

### 银行不良贷款(1-10)
1. 批量包看区域集中度
2. 同区域单户合并诉讼
3. 抵押物估值取6折安全线
4. 个贷必须批量处置
5. 尾包折价最大机会
6. 新包比陈年包更有价值
7. IRR底线设死线
8. 抵债资产持有不超2年
9. 追加实控人连带担保
10. 大额报价争取承销费减免

### 不良债权(11-18)
11. 先查三账(工商/税务/司法)
12. 找软肋比找资产重要
13. 调解留台阶不逼绝路
14. 保全快准狠
15. 转让前通知债务人
16. 穿透审查防虚假债务
17. 保理比直接收购灵活
18. 票据追索期6个月

### 实物资产(19-25)
19. 住宅看城市能级
20. 商办做保守运营测算
21. 工业用地先查环保
22. 在建工程必须手续齐全
23. 土地收储找政府支持
24. 查封房产看首封法院
25. 违建拆除成本留预算

### 股权资产(26-30)
26. 不熟行业不投
27. 管理层要换人
28. 债转股先做税务筹划
29. 控股权才有价值
30. 壳资源先查干净度

## 四、两条核心铁律

**铁律一**：分类不准则处置方向必错
→ 先用知识卡片#2的"三个判断"法确认资产性质

**铁律二**：估值和处置必须联动看
→ 估不出就处不好，处不好就卖不好
