# 知识卡片 #1：不良资产核心概念（2026版）

## 定义
不良资产 = 债务人未能按约还款 → 债权人无法按时收回本息的资产

## 核心特征金字塔
```
             ┌──────────┐
             │ 信用风险高│ ← 核心特征
             └────┬─────┘
        ┌─────────┼─────────┐
    ┌───┴───┐ ┌──┴───┐ ┌───┴──┐
    │流动性差│ │价值不│ │处置难│
    │       │ │确定强│ │度高  │
    └───────┘ └──────┘ └──────┘
                   │
            ┌──────┴──────┐
            │ 回收周期长   │
            └─────────────┘
```

## 2026年中国不良资产市场速览
| 指标 | 数据 |
|------|------|
| 商业银行不良贷款余额 | 4万亿+ |
| 不良率 | 1.7%-1.8% |
| 银行批量转让规模 | ~2.8万亿元（2025年） |
| 个贷不良成交额 | ~4000亿元（2025年）→~5500亿元（2026年E）|
| AMC数量 | 5家全国性 + 62家地方性 |
| 线上成交占比 | 超60% |

## 核心公式：不良资产≠坏资产
- 不良资产是**错配的价值**——资产本身可能没问题，只是持有者（债务人）遇到了困难
- 处置目标是**价值修复**，而非简单清算
- 投资逻辑：低价收购 → 价值发现/修复 → 溢价退出

# 知识卡片 #2：不良资产五级分类与处置框架

## 商业银行贷款五级分类（2026年）

| 分类 | 逾期 | 风险 | 回收率 | 处置策略 |
|------|------|------|--------|---------|
| ✅ 正常类 | 未逾期 | 无 | 100% | 正常贷后管理 |
| ⚠️ 关注类 | <30天 | 潜在 | 85-95% | 预警+早期干预 |
| 🔶 次级类 | 30-90天 | 低 | 60-80% | 债务重组/债转股 |
| 🔴 可疑类 | 90-180天 | 中 | 40-60% | 综合处置 |
| ⚫ 损失类 | >180天 | 高 | 20-40% | 快速处置/NPAS |

## 处置工具包（2026年更新）

### 传统工具
1. **债务重组**：展期/降息/减免/债转股
2. **法律诉讼**：保全/执行/破产/和解
3. **资产拍卖**：公开竞价/协议转让
4. **打包转让**：银登中心批量竞价

### 创新工具（2025-2026）
1. **共益债**：新投入资金优先受偿 → 项目盘活
2. **REITs退出**：不良房地产项目→REITs→资本市场退出
3. **NPAS**：不良资产证券化→次级投资者→分散风险
4. **AI催收**：智能外呼+催收策略优化+客户画像
5. **QFLP**：合格境外有限合伙人→跨境不良资产投资
6. **类REITs**：底层资产为城投平台低效资产

## "三个判断"决策法
```
处置前问自己三个问题：
1️⃣ 债务人有无重生价值？→ 有则重组，无则清算
2️⃣ 资产有无市场流动性？→ 有则拍卖，无则持有
3️⃣ 回收周期是否可控？→ 短则快处，长则证券化
```

# 知识卡片 #3：不良资产估值入门

## 五大估值方法速记表

| 方法 | 一句话记忆 | 适用场景 | 关键参数 |
|------|-----------|---------|---------|
| 成本法 | "这东西值多少材料钱" | 房/地/设备 | 重置成本+成新率 |
| 市场法 | "隔壁老王卖了多少钱" | 标准化资产 | 可比案例+修正系数 |
| 收益法 | "未来能赚多少钱" | 经营资产/股权 | 现金流+折现率 |
| 假设清算法 | "拆了卖零件值多少" | 破产企业 | 清算价值+优先权 |
| 交易案例法 | "AMC上次收这类打几折" | 批量债权包 | 历史折扣+市场基准 |

## 折扣率速记口诀
**"次三可五损七成"**
- 次级类 → 折扣率10-30%
- 可疑类 → 折扣率30-50%
- 损失类 → 折扣率50-70%

## 折现率三要素
```
折现率 = 无风险利率(2.5-4%) + 风险溢价(5-15%) + 流动性溢价(3-8%)
                                   = 10-27% 总体
```

## 实战提醒
- 单方法估值不可靠，至少用2-3种方法交叉验证
- 敏感性分析必做：折现率±1%→估值变化5-15%
- 市场环境变化时需及时调整参数

# 知识卡片 #4：跨境不良资产投资QFLP四模式（2026年新增）

## QFLP是什么？
**QFLP** = Qualified Foreign Limited Partner（合格境外有限合伙人）
→ 境外资金通过QFLP结汇后投资中国境内不良资产的制度安排

## 四种投资模式

| 模式 | 操作方式 | 预期IRR | 典型玩家 |
|------|---------|---------|---------|
| 直投收购 | QFLP直接收购资产包+自行处置 | 15-22% | 橡树资本 |
| 与AMC合作 | QFLP做LP+AMC做GP+联合处置 | 12-18% | KKR |
| NPAS认购 | 认购不良资产证券化优先级 | 8-12% | 太盟(PAG) |
| 重整投资 | 破产重整+债转股投资 | 15-25% | 高盛资管 |

## 三个记忆点
1️⃣ **政策窗口**：2025-2026年是QFLP扩围红利期，外资持股限制已取消
2️⃣ **特殊折现**：跨境投资折现率 = 基础22-48% + 汇率2-5% + 合规1-3% + 信息差2-5% = 27-61%
3️⃣ **经典案例**：橡树资本以6折收购华融80亿资产包，通过价值重塑目标IRR 18-20%

## 跨境投资五大风险
🌐 汇率波动 | 🏛️ 政策收紧 | 🚪 退出受限 | 🔍 信息不对称 | ⏳ 处置低效

# 知识卡片 #6：中国不良资产四轮周期速记（1999–2026）

## 四轮周期口诀
```
一轮面值买  二轮按折价    ← 政策驱动期
三轮市场化  四轮大数据    ← 市场化成熟期
```

## 四轮周期一览表

| 轮次 | 时间 | 规模 | 驱动力 | 估值方式 | 处置标志 |
|------|------|------|--------|---------|---------|
| 1️⃣ | 1999-2003 | ~1.4万亿 | WTO入世+银行技术破产 | 面值1:1收购（政策性） | 债转股+一揽子接收 |
| 2️⃣ | 2004-2008 | ~1.8万亿 | 四大行股改上市 | DCF+抵押重估（20-40%折价） | 打包转让+外资合作 |
| 3️⃣ | 2012-2019 | 0.5→2.4万亿 | 经济减速+产能出清 | 市场化竞价（3-5折/1-3折） | 公开竞价+NPAS+AIC |
| 4️⃣ | 2020-2026 | 2.7→4.2万亿 | 疫情+地产+城投+个贷 | 大数据+NPAS+REITs定价 | AI催收+QFLP+个人破产 |

## 四个地标案例

| 轮次 | 案例 | 一句话记住 |
|------|------|-----------|
| 1️⃣ | 信达接收建行3,737亿 | "史上最大单笔不良转移" |
| 2️⃣ | 华融×高盛合资处置250亿包 | "外资首次入局" |
| 3️⃣ | 中钢集团债转股300亿留债+270亿转股 | "市场化债转股标杆" |

## 三大规律

1️⃣ **规模膨胀律**：每轮规模递增（1.4万亿→1.8万亿→2.4万亿→4.2万亿）
2️⃣ **工具进化律**：从单一到多元，从政策到市场，从线下到科技
3️⃣ **参与者扩容律**：四大AMC→62家地方AMC+外资+民营+科技

# 知识卡片 #8：不良资产形成机理 — "是病还是死"判断法

## 一句话核心
**不良资产形成的本质 = 系统性风险在特定主体身上的集中爆发**

## 三层传导模型（宏观→行业→主体）

```
[宏观]  周期 × 政策 × 货币 × 制度 → [行业] 产能×技术×信用
                    ↓
         [主体] 治理×经营×担保×道德 → 不良资产爆发
```

## 五大致病因子速记

```
# "治经担道不" = 五个因子
治=公司治理(35%) | 经=经营失误(25%) | 担=担保链(20%)
道=道德风险(10%) | 不=不可抗力(10%)
```

## 四类资产形成模式口诀

```
对公：杠杆太高现金流断
房产：三条红线融资难
个贷：多头借贷以贷养贷
城投：土地财政行不通
```

## "是病还是死"判断表

| 特征 | 流动性危机（病可救） | 经营危机（死难救） |
|------|:------------------:|:-----------------:|
| 主业盈利 | ✅ | ❌ |
| 资金原因 | 短贷长用/抽贷 | 市场消失 |
| 资产>负债 | ✅ | ❌ |
| 实控人态度 | 积极自救 | 失联 |
| 处置方向 | 过桥+展期 | 清算+拍卖 |
| 回收预估 | 70-100% | 20-40% |

## 逃废债四信号（见即警惕）

> 资产转移×空壳化×低价处置×假破产

**口诀**：移空低假四个字，见到一个就要查

# 知识卡片 #9：不良资产市场利润池与价值链（2026-05-18新增）

## 一句话核心
**不良资产的利润 = 收购折价(50-65%) + 处置增值(25-35%) + 流动性溢价(10-20%)**

## 价值链利润分布

```
总利润池：800-1,200亿/年

收购环节  ───── 30-40% (240-480亿) ← 竞争白热化
处置环节  ───── 35-45% (280-540亿) ← 利润的大头
退出环节  ───── 10-15% (80-180亿)
尽调环节  ─────  5-8%  (40-96亿)
估值环节  ─────  3-5%  (24-60亿)
```

## 各参与者利润模式口诀
**"四大吃资金，地方吃关系，民间吃信息"**

| 地方AMC | 8-15% | 6-10% | 处置专业驱动 |
