## 第一轮 (1999–2003): 政策性剥离，四大AMC创立

### 形成机制
- **国企预算软约束**: 国有企业亏损严重，地方政府强制银行贷款维持运转
- **"拨改贷"后遗症**: 1983年起财政拨款改为银行贷款，国企无力偿还
- **1997亚洲金融危机**暴露银行体系脆弱性
- **WTO入世倒逼**: 2001年入世后面临外资银行竞争，必须清理资产负债表
- 1999年四大国有银行平均不良率超过30%，部分超过40%

### 规模与参与者
- **剥离总量**: ~1.4万亿
- **四大AMC对应接收**:
  - 信达资产(1999.4) → 接收建设银行不良
  - 华融资产(1999.10) → 接收工商银行不良
  - 东方资产(1999.10) → 接收中国银行不良
  - 长城资产(1999.10) → 接收农业银行不良
- **收购方式**: 按账面面值收购，资金来源于央行再贷款(~5,700亿)和财政部担保金融债券(~8,200亿)

### 地标案例: 信达接收建行3,737亿不良资产包
- 中国历史上最大单笔不良资产转移
- 包括大量煤炭、纺织、军工等落后产能国企贷款
- 后续通过债转股、债务重组、企业重组等方式处置
- 典型案例：信达参与ST郑百文重组 → 上市公司重组NPL处置首个成功案例

### 估值方法 (当时)
- **政策性定价**: 四大AMC按面值1:1接收（非市场折价）
- 本质是政府资产负债表内的转移，不反映资产真实质量
- 财政部兜底：AMC最终损失由财政承担
- 国际对比：美国RTC对不良资产通常以账面值40-60%收购

### 处置方法
| 方式 | 说明 |
|------|------|
| 债转股 | 国企债务转为AMC持股，国企脱困+银行减负+AMC长期持股 |
| 债务重组 | 减免利息、展期、分期偿还 |
| 诉讼追偿 | 对恶意逃废债企业法律追索 |
| 打包转让 | 资产打包后折价转让（市场未发育） |
| 企业重组 | 引入战略投资者，推动改制上市 |
| 破产清算 | 对无重组价值企业申请破产 |

## 第二轮 (2004–2008): 二次剥离与商业化转型

### 形成机制
- 第一轮剥离后不良率仍偏高，2003-2005年国有银行启动股改+海外上市
- 二次剥离主要针对2000年后新暴露的不良贷款
- 大型国企"债务围栏"操作：核心优质资产剥离成立新公司，旧壳承担债务
- 交行2004年最先完成二次剥离，随后建行、中行、工行
- 中央汇金动用外汇储备注资（450亿美元注入中行和建行）

### 规模与参与者
- **剥离总量**: ~1.8万亿
- **时间线**:
  - 2004年：交行~530亿→信达；中行~1,500亿；建行~1,800亿
  - 2005年：工行~4,600亿+~3,500亿两次→华融
  - 2008年：农行~8,000亿→长城
- **外资机构首次进入**: 摩根士丹利、高盛、橡树资本、瑞银参与资产包投标

### 地标案例: 华融×高盛合资处置平台 (2004)
- 华融将面值~250亿不良资产包与高盛合作设立合资处置平台
- 外资首次深度参与中国不良资产处置
- "合作分成"模式（AMC提供资源，外资提供资金和技术）
- 同期摩根士丹利与信达也设立类似合资企业

### 估值方法
- 从政策性定价转向**商业化定价**的过渡期
- 逐户尽调: AMC开始对单笔大额贷款现场尽调
- DCF折现法引入: 根据预期回收现金流折现定价
- 抵押物重估: 土地使用权、厂房设备重新估价
- 外资使用更成熟的**Risk-Adjusted Return模型**
- 成交价通常为面值的**20-40%**

### 处置方法
| 方式 | 说明 |
|------|------|
| 打包转让 | 资产包分级，公开招标转让内外资（主流方式） |
| 债务重组 | 利息减免、本金打折、分期偿还 |
| 诉讼与执行 | 加大司法清收力度 |
| 不良ABS初探 | 2006-2008年信达、东方试点发行（规模小） |
| 企业重整 | 大型国企"债务围栏"—新设公司承接优质资产，旧壳留债 |
| 债转股延续 | 规模小于第一期 |

## 第三轮 (2012–2019): 市场化不良资产周期

### 形成机制
- **"四万亿"刺激后遗症**: 2009-2010信贷大扩张→2012年开始暴露
- **经济增速换挡**: GDP从10%+降至6-7%，企业经营恶化
- **产能过剩出清**: 钢铁、煤炭、水泥、光伏、造船等陷入困境
- **影子银行暴露**: 信托违约(中诚信托/吉林信托等)、委托贷款坏账
- **民企违约潮**: 2018-2019年去杠杆+贸易战叠加
- **监管数据做实**: 银监会要求"做实分类、提足拨备"

### 规模与参与者
- 商业银行NPL余额：2012年~5,000亿 → 2019年~2.41万亿
- 不良率：2012年~0.95% → 2015年~1.67% → 2019年~1.86%
- **参与者大幅扩容**:
  - 四大AMC: 信达(港股上市)、华融(港股上市)、东方、长城
  - **地方AMC爆发**: 2012年首批~8家 → 2019年末57家（覆盖31省）
  - 民营机构: 九鼎、鼎晖、盛世景等
  - 外资: 橡树资本、KKR、贝恩资本重仓中国NPL
  - 特殊机会基金: 聚焦困境企业投资

### 地标案例: 中钢集团市场化债转股 (2016)
- 2014-2015年中钢债务危机，潜在违约~1,000亿
- 2016年国务院主导重组方案
- **"留债+债转股"模式**: 约300亿留债 + 约270亿转股
- 标志着此轮市场化债转股重启（与此前政策性债转股不同）
- 随后2016年10月国务院发布《关于积极稳妥降低企业杠杆率的意见》

### 估值方法
- **市场化竞价成为主流**: 交易所公开挂牌，价高者得
- 三种定价模式并行:
  | 方法 | 适用场景 | 典型折扣 |
  |------|---------|---------|
  | 收益法(DCF) | 有稳定现金流的基础资产 | 视现金流而定 |
  | 市场法 | 标准化资产包 | 参照可比交易 |
  | 成本法 | 抵押物重置成本打折 | 有抵押3-5折 |
- 纯信用类: 1-3折
- 分层定价: 资产包内部分级，不同质量不同定价
- 互联网技术介入: 淘宝司法拍卖平台
- 银登中心(2016年成立)信息登记和交易撮合

### 处置方法
| 方式 | 说明 |
|------|------|
| 公开竞价拍卖 | 淘宝/京东司法拍卖兴起(2017年起爆发式增长) |
| 银登中心流转 | 信贷资产收益权转让、不良资产挂牌 |
| NPAS重启 | 2016年首批6家试点银行，此后逐年扩容 |
| 市场化债转股(AIC) | 工农中建交各设AIC（注册资本100-120亿） |
| 债务重组 | 利息减免、展期、债转股组合方案 |
| 破产重整 | 上市公司重整案例激增（重庆钢铁、抚顺特钢） |
| 线上催收 | 第三方催收公司、催收科技平台发展 |

### 关键政策节点
| 年份 | 政策 | 影响 |
|------|------|------|
| 2012 | 银监发[2012]1号—地方AMC设立办法 | 省级AMC获准设立 |
| 2012 | 《商业银行资本管理办法》 | 提高拨备要求，倒逼出清 |
| 2015 | 《存款保险条例》实施 | 银行退出机制建立 |
| 2016 | 银登中心成立 | 不良资产二级市场正式化 |
| 2016 | 国务院推动市场化债转股 | AIC设立，债转股重启 |
| 2017 | 《金融资产管理公司资本管理办法》 | AMC资本约束加强 |
| 2018 | 资管新规 | 影子银行加速暴露 |

## 第四轮 (2020–2026): 后疫情·地产下行·个贷爆发

### 形成机制 (多重叠加)

**(A) 新冠疫情冲击 (2020-2022)**:
- 2020年大量中小企业停摆，个人收入下降
- 延期还本付息政策(2020.6-2022年底)掩盖不良真实暴露
- 后疫情"疤痕效应": 消费复苏乏力，居民杠杆居高不下

**(B) 房地产深度调整 (2021-2026)**:
- 恒大(2021)、碧桂园(2023)、融创、世茂、阳光城等相继违约
- "三条红线"政策(2020.8)刺破地产泡沫
- 房地产贷款占银行贷款总额~25-30%
- 2025年房地产业不良率攀升至~5-7%[E]

**(C) 地方政府隐性债务 (LGFV)**:
- LGFV债务规模达~50-60万亿[E]
- 2023年起"一揽子化债方案"出台
- 弱资质区域(贵州、云南、天津等)城投展期、降息

**(D) 个人贷款不良爆发**:
- 信用卡、消费贷、经营贷不良率攀升
- 2021年首批6家银行+4家AMC试点个贷批量转让
- 2022年试点扩围至全国性商业银行+全部AMC+地方AMC
- 2023-2024年单年成交量突破~1,500亿(本金)[E]

### 参与者结构 (2026E)
| 类型 | 数量 | 特征 |
|------|:----:|------|
| 全国性AMC | 5家 | 信达/东方/长城/中信金融资产(原华融)/银河资产 |
| 地方AMC | ~62家 | 覆盖31省份，部分民营控股(滨海正信、国厚资产等) |
| 金融AIC | 6家 | 交银/农银/中银/建信/工银/邮惠(邮储) |
| QFLP试点 | 多城 | 上海/深圳/海南，外资入境投NPL新通道 |
| 个贷NPL投资者 | 数百家机构+个人 | 个贷不良成新资产类别 |

**行业重大变化**:
- **华融→中信金融资产**: 2021年巨亏(2020年亏损1,029亿)，中信集团入主。2024年正式更名
- **地方AMC分化**: 头部(浙商资产、江苏资产、山东金资等)全国影响力；尾部面临资本不足
- **外资再入局**: 橡树资本、KKR设QFLP基金；高盛、摩根士丹利通过QFLP回归

### 地标案例

**(A) 恒大集团债务重组 (2021-2026)**:
- 中国历史上最大规模企业债务违约
- 总负债~2.44万亿，涉及银行贷款、信托、供应商、美元债
- 2023年8月美国第15章破产保护
- 2024年1月香港法院下令清盘
- 2024-2025年境内债务重组持续推进（以房抵债、债转股、资产出售）
- **标志性意义**: 打破"大而不倒"神话，房地产行业信用重整起点

**(B) 碧桂园境外债重组 (2023-2025)**:
- 2023年8月首次美元债违约
- 2024年推出~197亿美元境外债重组方案
- 2025年初与债权人达成重组协议（部分接受30%+本金削减）
- 与恒大不同：维持经营重组（未进入清盘），项目交付持续推进

**(C) 个贷不良批量转让—2023年单笔最大成交**:
- 东方资产通过银登中心竞得某国有大行百亿级别个贷包
- 本金~120亿，成交折扣~2-3折
- 大数据模型评估回收率，AI催收策略管理
- 标志着个贷不良从"试点"到"主流"的跨越

### 估值方法 (2020-2026)

**个贷不良估值革命**:
- **大数据智能估值模型**: 借款人画像(年龄/职业/地区/历史还款/多头借贷等数百维度)预测回收率
- **统计学批量定价**: 按资产池统计特征定价（类似信用卡MBS逻辑）
- **"BL交易"模式**: 纯信用按本金3-8%批量出售；有抵押个贷10-30%

**对公不良估值**:
- DCF仍是主流，增加地产/城投等特殊参数
- **NPAS定价**: 分层设计优先/次级，以优先级市场收益率倒推
- **压力测试模型**: 多情景(乐观/基准/悲观)
- **REITs估值**: 持有商业地产的不良资产，引入REITs上市退出路径

### 处置方法 (创新工具爆发)
| 方式 | 说明 | 代表数据 |
|------|------|---------|
| 个贷批量转让(NPAS扩围) | 2021试点→2022全面推开；银登中心打包出售 | 2023~1,200亿[E]→2026E~2,000亿[E] |
| REITs/类REITs | 困境地产项目通过REITs盘活退出 | 华夏中国交建REIT等 |
| QFLP不良基金 | 境外资金通过QFLP直投境内NPL | 上海试点2022启动，橡树资本首批 |
| AI智能催收 | NLP催收机器人、智能质检、失联修复 | 百融云创、度小满等SaaS平台 |
| 个人破产试点 | 深圳率先开展(2021年) | 截至2024年已受理数百件 |
| 城投化债工具 | 特殊再融资债券、应急流动性SPV、展期置换 | 2023-2024年~4万亿特殊再融资债 |
| 保交楼专项借款 | 央行专项借款推动停工项目复工 | 2022-2024年累计超万亿 |
| 银登中心线上流转 | 标准化不良资产线上挂牌竞价成交 | 2023年流转规模超~5,000亿 |

### 关键政策变化 (2020-2026)
| 年份 | 政策 | 影响 |
|------|------|------|
| 2020.06 | 延期还本付息政策 | 短期掩盖不良暴露 |
| 2020.08 | "三条红线"地产调控 | 引发地产行业信用收缩 |
| 2021.01 | 个贷不良批量转让试点 | 开辟全新NPL资产类别 |

## 跨周期规律总结

### 三大规律
1. **规模膨胀律**: 每轮规模递增 (1.4→1.8→2.4→4.2万亿)
2. **工具进化律**: 从单一到多元，从政策到市场，从线下到科技
3. **参与者扩容律**: 四大AMC→62家地方AMC+外资+民营+科技

### 四轮核心逻辑
```
第一轮:   国家信用背书 → "清账" → 政策性剥离
          └─ 目标: 让银行活下去，让国企改制

第二轮:   股份制改造 → "包装上市" → 二次剥离+商业化探索
          └─ 目标: 银行IPO，引入国际标准

第三轮:   经济减速 → "产能出清" → 市场化+多元化
          └─ 目标: 化解系统性金融风险，建立市场化处置体系

第四轮:   疫情+地产+城投+个贷 → "多重叠加" → 工具全面创新
          └─ 目标: 守住不发生系统性风险底线，推动市场化纵深发展
```

### 关键趋势 (2024-2026)
1. **个贷不良成为核心增长极**: 预计2026年年成交量突破~2,000亿(本金)
2. **AMC行业格局重塑**: "5+62+N"格局，华融更名标志新阶段
3. **科技深度渗透**: AI催收取代30-40%人工，大数据估值成标配
4. **外资回归**: QFLP通道，预计2026年超~100亿
5. **REITs退出通道**: 困境地产项目通过类REITs/公募REITs盘活成熟
6. **个人破产制度扩大**: 为个贷不良提供最终清算通道
7. **城投化债持续**: 2024-2028年持续大主题，AMC扮演"化债商"
8. **监管趋严**: 不良认定标准更严格，拨备要求提高
