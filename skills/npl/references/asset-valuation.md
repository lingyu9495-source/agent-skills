# 不良资产估值实战：三重折价模型

> 合并自：npl-asset-valuation

## 核心公式：三重折价模型
```
实际可回收价值 = 面值 × (1-法律风险折价) × (1-流动性折价) × 时间折现系数
```

## 五大估值方法
1. **假设清算法**（最常用、最保守）：抵押物市场价值×变现折扣率-优先债权-处置费用
2. **现金流折现法(DCF)**：Σ(CF_t/(1+r)^t)，折现率22%-48%
3. **交易案例比较法**：参照2026Q1 AMC实际成交折扣率
4. **专家判断法**：综合法律、财务、行业专家意见
5. **期权定价法**：Black-Scholes，适用含重组选择权的高不确定性资产

## 六大资产类型估值要点
| 类型 | 核心方法 | 回收率 | 核心风险 |
|------|---------|--------|---------|
| 房地产抵押 | 假设清算法+市场比较 | 40-80% | 租赁/工程款优先/轮候 |
| 信用贷款 | DCF+专家判断 | 5-30% | 资产转移/担保人无力 |
| 应收账款 | 账龄分析+债务人评级 | 10-60% | 诉讼时效/抵销权 |
| 股权类 | 净资产法+清算价值 | 0-50% | 持续经营/负债结构 |
| 实物资产 | 重置成本+快速变现 | 20-70% | 折旧/市场需求 |
| 无形资产 | 收益法+市场法 | 0-40% | 法律状态/替代性 |

## 法律尽调五大红线
1. 诉讼时效过期（3年未催收→回收率→0）
2. 抵押未登记（抵押权不成立）
3. 轮候查封（非首封，处置权受限）
4. 建设工程款优先权（优于抵押权）
5. 买卖不破租赁（带租约拍卖折价30-50%）

## 风险等级映射
| 等级 | 特征 | 折现率 | 收购折扣 |
|------|------|--------|---------|
| A类 | 首封+无租赁+抵押充足 | 18-25% | 6-8折 |
| B类 | 一般抵押/有瑕疵 | 25-35% | 3-6折 |
| C类 | 弱担保/法律风险高 | 35-45% | 1-3折 |
| D类 | 纯信用/时效问题 | 45-60% | <1折 |
