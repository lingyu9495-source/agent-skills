# AI驱动的个贷不良处置科技（2026年参考）

## 核心场景

### 场景1：个贷不良资产包估值
- 输入：每笔借据的征信/多头/行为/催收数据
- 方法：LightGBM/XGBoost/DCN → 预期回收率
- 精度：误差±15%以内
- 相比传统折扣法：精度提升50%+

### 场景2：催收策略优化
- 强化学习/多臂老虎机 → 动态调整触达频次/渠道/话术
- 效果：首催回收率+8-15%

### 场景3：全流程合规管控
- 全量录音+AI质检（BERT/GPT意图理解）
- 话术合规率95%+
- 自动识别辱骂/威胁/诱导性话术

## AI估值公式

```
单笔回收现值 = P(还款|特征) × 期望金额 × (1+r)^(-t)

资产包估值 = Σ(单笔回收现值)

其中：
  P(还款|特征) = 模型预测（征信/多头/收入/行为/催收响应）
  r = 无风险利率(2.5%) + 风险溢价(5-15%) + 流动性溢价(5-10%)
  t = 逾期天数/365
```

## 合规红线（2026年）

1. AI外呼必须提示"本通话由AI完成"（不得冒充人类）
2. 每日每客户≤3次，时段8:00-21:00
3. 禁止收集与还款无关的个人信息
4. 自动化决策需提供人工复核通道
5. 算法需备案+定期公平性审计
