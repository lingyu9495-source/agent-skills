# 不良资产估值案例研究

## 案例1：制造业企业破产重整估值案例

### 案例背景
**企业名称**：某机械制造有限公司
**行业**：机械制造
**规模**：中型企业，员工500人
**债务情况**：总债务3.2亿元，其中银行贷款2.5亿元
**资产情况**：总资产4.8亿元，固定资产3.2亿元，流动资产1.6亿元
**破产原因**：资金链断裂，订单减少，经营困难

### 估值需求
- 为破产重整提供价值参考
- 确定投资者入股比例
- 制定债务重组方案

### 估值过程

#### 1. 资产分类与评估
**固定资产评估**
| 资产类别 | 账面价值 | 评估方法 | 评估价值 | 折扣率 | 最终价值 |
|----------|----------|----------|----------|--------|----------|
| 厂房 | 8000万 | 市场比较法 | 9600万 | 70% | 6720万 |
| 机器设备 | 15000万 | 重置成本法 | 12000万 | 50% | 6000万 |
| 办公设备 | 2000万 | 重置成本法 | 1500万 | 60% | 900万 |
| 小计 | 25000万 | | 23100万 | | 13620万 |

**流动资产评估**
| 资产类别 | 账面价值 | 评估方法 | 评估价值 | 折扣率 | 最终价值 |
|----------|----------|----------|----------|--------|----------|
| 原材料 | 3000万 | 可变现净值法 | 2400万 | 100% | 2400万 |
| 产成品 | 2000万 | 可变现净值法 | 1500万 | 80% | 1200万 |
| 应收账款 | 1000万 | 账龄分析法 | 600万 | 100% | 600万 |
| 小计 | 6000万 | | 4500万 | | 4200万 |

#### 2. 负债确认
| 负债类别 | 账面价值 | 确认金额 | 优先级 |
|----------|----------|----------|--------|
| 银行贷款 | 25000万 | 25000万 | 有担保 |
| 应付账款 | 4000万 | 4000万 | 无担保 |
| 职工债务 | 1500万 | 1500万 | 职工债权 |
| 税务债务 | 1500万 | 1500万 | 税款债权 |
| 小计 | 32000万 | 32000万 | |

#### 3. 估值计算
```
净资产评估 = 资产评估价值 - 负债确认金额
           = 13620万 + 4200万 - 32000万
           = -4180万
```

**考虑重整价值调整**：
- 重整后预期年收益：2000万
- 折现率：12%
- 收益期限：5年
- 收益现值：2000万 × (1 - 1.12^-5) / 0.12 = 7200万
- 重整价值调整：7200万 - 4180万 = 3020万

### 估值结果
- **净资产估值**：3020万元
- **估值方法**：假设清算法 + 收益现值法
- **最终估值**：3020万元
- **估值日期**：2026年3月15日

### 处置方案
1. **债务重组**：银行贷款转为60%股权
2. **投资者引入**：引入战略投资者，获得40%股权
3. **重整计划**：3年内扭亏为盈，5年内实现盈利增长

### 经验总结
1. **制造业企业估值需考虑重整价值**，单纯清算价值可能为负
2. **收益现值法适用于有持续经营能力的企业**
3. **重整价值调整需要谨慎**，需有明确的盈利预测
4. **投资者关注点**：技术实力、市场地位、管理团队

## 案例2：房地产不良资产包估值案例

### 案例背景
**项目名称**：某商业综合体项目
**位置**：一线城市核心商圈
**规模**：总建筑面积15万平方米
**开发商**：某房地产开发商
**债务情况**：总债务8亿元，其中银行贷款6亿元
**抵押物**：商业综合体项目

### 估值需求
- 为资产转让提供定价依据
- 确定折扣率
- 评估投资价值

### 估值过程

#### 1. 资产评估
**房地产评估**
| 物业类型 | 建筑面积 | 市场单价 | 市场总价 | 折扣率 | 评估价值 |
|----------|----------|----------|----------|--------|----------|
| 商业裙楼 | 5万㎡ | 6万/㎡ | 30亿 | 65% | 19.5亿 |
| 写字楼 | 8万㎡ | 4万/㎡ | 32亿 | 60% | 19.2亿 |
| 地下商业 | 2万㎡ | 3万/㎡ | 6亿 | 50% | 3亿 |
| 小计 | 15万㎡ | | 68亿 | | 41.7亿 |

#### 2. 收益分析
**年收益预测**
| 收入来源 | 年收入 | 备注 |
|----------|--------|------|
| 租金收入 | 3.2亿 | 出租率85% |
| 物业管理费 | 0.8亿 | 管理费标准 |
| 其他收入 | 0.5亿 | 广告、停车等 |
| 年总收益 | 4.5亿 | |

**运营成本**
| 成本项目 | 年成本 | 备注 |
|----------|--------|------|
| 管理费用 | 0.5亿 | |
| 维修费用 | 0.3亿 | |
| 税费 | 0.8亿 | 房产税、营业税等 |
| 其他费用 | 0.2亿 | |
| 年总成本 | 1.8亿 | |

**净收益** = 4.5亿 - 1.8亿 = 2.7亿

#### 3. 收益现值法计算
- **净收益**：2.7亿元/年
- **折现率**：8%（考虑风险溢价）
- **收益期限**：40年
- **终值增长率**：3%
- **收益现值** = 2.7亿 × (1 - 1.08^-40) / 0.08 = 32.4亿元

#### 4. 综合估值
- **市场比较法结果**：41.7亿元
- **收益现值法结果**：32.4亿元
- **加权平均**：(41.7 × 0.4) + (32.4 × 0.6) = 36.6亿元
- **风险调整**：36.6亿 × 0.7 = 25.6亿元

### 估值结果
- **市场价值**：41.7亿元
- **收益价值**：32.4亿元
- **综合估值**：25.6亿元
- **账面价值**：8亿元
- **折扣率**：32%

### 处置方案
1. **协议转让**：整体转让给资产管理公司
2. **价格谈判**：基于25.6亿元估值进行谈判
3. **支付方式**：分期付款，降低买方资金压力
4. **后续管理**：委托专业商业运营公司管理

### 经验总结
1. **商业地产估值需结合市场法和收益法**
2. **地理位置是核心价值因素**
3. **运营能力对价值影响巨大**
4. **风险调整系数需要根据项目具体情况确定**

## 案例3：债权资产估值案例

### 案例背景
**债权类型**：企业应收账款
**债务人**：某上市公司
**债权金额**：2亿元
**账龄**：1-3年
**担保情况**：无担保
**回收难度**：较高

### 估值需求
- 为债权转让提供定价依据
- 评估回收可能性
- 制定催收策略

### 估值过程

#### 1. 债权分析
**债务人状况分析**
| 分析维度 | 评估结果 | 风险等级 |
|----------|----------|----------|
| 经营状况 | 连续亏损 | 高风险 |
| 偿债能力 | 资产负债率85% | 高风险 |
| 信用记录 | 多次逾期 | 高风险 |
| 法律风险 | 有未决诉讼 | 高风险 |
| **综合评级** | **CCC级** | **高风险** |

**回收可能性分析**
| 回收渠道 | 预计回收金额 | 回收概率 | 加权回收额 |
|----------|--------------|----------|------------|
| 和解回收 | 8000万 | 30% | 2400万 |
| 诉讼回收 | 6000万 | 50% | 3000万 |
| 破产回收 | 4000万 | 20% | 800万 |
| 其他回收 | 2000万 | 10% | 200万 |
| **合计** | | | **6400万** |

#### 2. 估值方法
**账龄分析法**
| 账龄区间 | 金额 | 回收率 | 估值 |
|----------|------|--------|------|
| 1年以内 | 5000万 | 80% | 4000万 |
| 1-2年 | 8000万 | 50% | 4000万 |
| 2-3年 | 7000万 | 20% | 1400万 |
| **合计** | 20000万 | | 9400万 |

**债务分析法**
- **债务人净资产**：1.5亿元
- **债权优先级**：普通债权
- **预计回收率**：40%
- **估值结果**：1.5亿 × 40% = 6000万

**综合估值**
- **账龄法结果**：9400万元
- **债务法结果**：6000万元
- **加权平均**：(9400 × 0.6) + (6000 × 0.4) = 8040万元
- **风险调整**：8040万 × 0.8 = 6432万元

### 估值结果
- **账面价值**：2亿元
- **估值结果**：6432万元
- **折扣率**：32.16%
- **回收期限**：预计2-3年

### 处置方案
1. **债权转让**：折价转让给专业催收机构
2. **债务重组**：与债务人协商债务重组方案
3. **法律诉讼**：通过法律途径追讨债权
4. **资产抵押**：要求债务人提供额外担保

### 经验总结
1. **债权估值需多方法交叉验证**
2. **债务人状况是关键因素**
3. **回收概率需要保守估计**
4. **法律手段是重要保障**

## 估值方法对比总结

| 估值方法 | 适用场景 | 优势 | 劣势 | 适用案例 |
|----------|----------|------|------|----------|
| 假设清算法 | 破产清算 | 简单直接 | 价值偏低 | 案例1制造业企业 |
| 收益现值法 | 持续经营 | 考虑未来价值 | 预测难度大 | 案例2房地产项目 |
| 市场比较法 | 标准化资产 | 客观公正 | 可比案例少 | 案例2房地产项目 |
| 成本法 | 实物资产 | 依据充分 | 忽略市场价值 | 案例1制造业设备 |
| 账龄分析法 | 债权资产 | 简单实用 | 忽略债务人状况 | 案例3债权资产 |
