# 尽调实操七步法工作流

> 合并自：npl-due-diligence-workflow

## 七步法
1. **数字化信息预采集**（0.5天）：企查查/裁判文书网/征信/不动产登记
2. **法律尽调**（1-2天）：债权文件核查+十大致命陷阱
3. **财务尽调**（1天）：五维评估表+定价建议
4. **业务尽调**（1天）：现场勘察+市场调研+政策环境
5. **重整方案设计**（1-2天）：债转股/资产剥离/引入战投
6. **敏感性分析**（0.5天）：四变量+五种极端情景
7. **尽调报告输出**（0.5天）：执行摘要+完整分析

## 五维评估表
| 维度 | 权重 |
|------|------|
| 债权质量 | 30% |
| 担保/抵押 | 25% |
| 破产风险 | 20% |
| 税务成本 | 15% |
| 执行可行性 | 10% |
