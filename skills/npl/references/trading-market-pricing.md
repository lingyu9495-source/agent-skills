## 一、三层市场结构

```
一级市场（批发）：银行 → AMC      银登中心竞价/协议
二级市场（流转）：AMC↔AMC/投资者   阿里资产/京东拍卖/协议
三级市场（终端）：投资者→买方      拍卖/重整/证券化
```

## 二、各层定价特征

| 市场 | 折扣率 | 定价基础 |
|:----:|:------:|---------|
| 一级 | 3-5折（对公）/ 1-3折（个贷） | 账面价值×折扣率 |
| 二级 | 4-7折 | AMC成本+预期IRR |
| 三级 | 6-10折 | 资产真实变现价值 |

## 三、折扣率决定因素

1. **抵押物充足率** — 足值则低折
2. **担保效力** — 强则低折
3. **债务人行业+地域** — 长三角珠三角低折
4. **诉讼进展** — 已判决低折
5. **处置难度** — 租赁/职工安置高折
6. **竞价热度** — 多家竞争低折

## 四、竞价方式

| 方式 | 适用 | 特点 |
|-----|------|------|
| 多轮竞价 | 优质资产包 | 价格充分发现 |
| 一次报价 | 标准资产包 | 策略性报价 |
| 议标 | 复杂资产包 | 2-3家分别谈判 |
| 单议 | 定向出让 | 最接近公允价值 |

## 五、核心公式

```
三级回收价 - 处置成本 = 投资者净回收
一级收购价 < 投资者净回收 → 盈利
```

## 六、"三不买"原则

- ❌ 不看抵押不买
- ❌ 不查诉讼不买
- ❌ 不评估处置成本不买

## 七、快速参考实战口诀

```
一级看折扣，二级看溢价，三级看变现
抵押值钱就低折，信用不良就高折
竞价心理最重要，对手底线猜不到
```
