# 回收率量化建模

> 合并自：npl-recovery-modeling

## 核心公式：三重折价 + DCF 融合
```
实际可回收价值 = 面值 × (1-法律风险折价) × (1-流动性折价) × 时间折现系数
综合折现率 = 22% ~ 48%（无风险2-3% + 信用8-15% + 流动性5-15% + 法律3-10% + 操作2-5%）
```

## 三大定价方法
1. **DCF现金流折现法**（核心）：预测处置期内现金流 → 风险调整后折现 → NPV → 回收率
2. **期权定价法**：Black-Scholes，适用高不确定性资产
3. **市场比较法**（最实用）：收集可比交易 → 计算折扣率 → 调整差异因素

## 压力测试框架
| 情景 | 影响 |
|------|------|
| 经济衰退(GDP<4%) | 回收率-10-15pp |
| 利率上行(+100bp) | 回收率-5-8pp |
| 法律延迟(+2年) | 回收率-8-12pp |
| 流动性枯竭 | 回收率-15-20pp |

## 房地产NPL专项模型
```
回收率 = (处置收入 - 处置成本 - 税费 - 优先权清偿) / 债权面值
```
