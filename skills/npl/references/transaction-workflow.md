## 六步法速览

```
出表准备 → 挂牌公告 → 尽调估值 → 竞价博弈 → 成交交割 → 投后管理
  银行       银登中心      AMC        银登中心     签约         AMC
```

## 银行组包四法

| 方式 | 核心 | 适合 |
|:----:|:----|:----|
| 区域包 | 同一地区打包 | 管理效率高 |
| 大拖小包 | 优质带劣质 | 带量成交 |
| 行业包 | 同行业 | 经验复用 |
| 纯个贷包 | 标准化批量 | 规模效应 |

## 竞价四式

| 方式 | 适用 | AMC策略 |
|:----:|:----|:-------|
| 多轮竞价 | 优质包(3-5家) | 首轮试探,末轮冲价 |
| 一次报价 | 标准包(2-3家) | 底价+10%-15% |
| 议标谈判 | 复杂包(2家) | 信息差压价,保留价+15-20% |
| 单议定向 | 合作包 | 快速成交,最接近公允 |

## AMC决策四问

1. **IRR ≥ 12%？** → 达标才报价
2. **退出路径明确？** → 3-5年能退
3. **底线回收多少？** → 最坏情况算清
4. **超预期风险？** → 法律/政策/市场

## 流拍处理

| 轮次 | 底价下调 | 操作 |
|:----:|:---------|:----|
| 第一次 | 5-10% | 重新公告,延长尽调 |
| 第二次 | 10-20% | 银行调整预期 |
| 协议转让 | 底价以下可谈 | 一对一谈判 |
| 撤包 | — | 银行自处置或核销 |

## 处置团队铁三角

```
项目经理(策略) + 法务专员(诉讼) + 资产运营(现场)
         ↓ 外部律师代理具体案件
```

## 六步法口诀

```
银行拿包先组好，组包策略要记牢
银登中心来挂牌，信息公告不能短
AMC领料先初筛，估值模型往里带
多轮竞价拼心态，底价之上加溢价
成交之后签协议，档案移交要仔细
投后管理分四类，赚钱退出才算完
```
