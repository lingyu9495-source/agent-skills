## 一、四步报价转换框架

```
估值结果（区间）→ 报价锚点 → 竞价策略 → 最优报价
```

1. **底线估值**：最差回收率假设 × 预期回收金额（低于此线不参与）
2. **目标报价**：基准估值 × (1 - 安全边际) | 安全边际 = 风险溢价 + 资金成本 + 管理成本
3. **竞价环境分析**：对手数量 × 对手资金 × 对手策略偏好 × 历史竞价行为
4. **最终报价定案**：底线 + 目标 + 最高限价（三层报价体系）

## 二、三种竞价形态

### 形态A：银登中心多轮竞价（最常见）
- **规则**：2-3轮密封报价
- **策略**：首轮试探(底价+5%) → 二轮加码(+3-5%) → 末轮决断(不超上限)
- **公式**：见完整笔记中 `银登中心竞价出价模型`

### 形态B：司法拍卖（阿里/京东）
- **价格阶梯**：一拍(评估价70-80%) → 二拍(一拍80%) → 变卖(同二拍)
- **参与者策略**：专业AMC等二拍出手，实体买家一拍抢人，债权人可抵债
- **关键决策**：预期竞争激烈→一拍出手；预期竞争小→等二拍

### 形态C：协议转让/定向邀请
- **核心**：谈判代替竞价
- **技巧**：锚定效应（先出低价）+ 分期杠杆（高首付换折扣）

## 三、竞价博弈中的估值陷阱

| 陷阱 | 表现 | 应对 |
|:----|:----|:----|
| 赢家诅咒 | 出价最高=最乐观 | 硬性IRR≥12%底线 |
| 底价不对称 | 银行隐藏底价 | 历史反推+交叉验证 |
| 对手误判 | 用AMC逻辑对产业资本 | 区分对手类型出价 |

## 四、六种速查场景

| 场景 | 竞价方式 | 对手 | 策略 |
|:----|:-------:|:----|:----|
| 🅰 激烈多轮 | 银登3轮 | 4-5家 | 底价+5%→不超上限 |
| 🅱 温和多轮 | 银登2轮 | 2-3家 | 底价+10%→微调 |
| 🅲 单轮密封 | 产权所 | 多家未知 | 估值中位数 |
| 🅳 司法拍卖多人 | 阿里/京东 | 10+家 | 二拍，评估价55-65% |
| 🅴 司法拍卖少人 | 阿里/京东 | 2-3家 | 一拍或二拍均可 |
| 🅵 协议转让 | 面谈 | 1-2家 | 锚定+分期杠杆 |

## 六、快速出价计算（个贷包版）

```python
def bid_quote(base_amount, recovery_rate, discount_rate, term_year, cost_rate):
    pv = base_amount * recovery_rate / ((1 + discount_rate) ** term_year)
    cost = base_amount * cost_rate
    return {
        'recovery_pv': round(pv, 2),
        'round1_bid': round(pv * 0.6, 2),    # 首轮试探
        'target_bid': round(pv * 0.8, 2),    # 目标价
        'max_bid': round(pv * 0.9, 2),       # 最高限价
        'implied_discount': round(pv * 0.8 / base_amount, 4)
    }
```
