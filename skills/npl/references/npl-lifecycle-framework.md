## 五阶段核心逻辑

```
形成 → 出表 → 收购 → 处置 → 退出
 L1      L1    L2     L3    L4+L5
```

### 阶段一：形成（L1—概念/分类）
- 四条路径：企业经营恶化、房地产周期、个人信用崩塌、金融产品违约
- 三条防线：预警(30d)→干预(90d)→重组(180d+)→不良认定
- 核心洞察：不良在债务人丧失持续经营能力时已形成，逾期只是信号

### 阶段二：出表（L1—市场/实务）
- 主战场：银登中心（线上竞价占比60%+）
- 2026H1特点：个贷占成交>70%，消费贷占个贷80-90%
- 组包演进：大拖小→纯个贷包标准化、行业包→行业+区域混合

### 阶段三：收购（L2—估值）
- 估值公式：退出价值倒推 × 尽调修正 × 竞价博弈溢价
- 三法交叉验证：市场法+收益法+假设清算法
- 决策六问：退出路径？IRR≥12%？底线回收？尽调完整？协同？红线？

### 阶段四：处置（L3—策略）
- 策略矩阵：债务人重生价值 × 资产流动性 → 四种策略
- 处置效率排序：调解>司法拍卖>共益债>批量转让>NPAS>破产重整
- 团队铁三角：项目总监+法务处置组+资产运营组

### 阶段五：退出（L4+L5—案例+前沿）
- 五条通道：司法拍卖、NPAS/REITs、协议转让、资产盘活、跨境QFLP
- 2026趋势：产业资本替代金融资本成为不良接盘主力
