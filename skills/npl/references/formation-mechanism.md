# 不良资产形成机理

> L1基础 · 参考文件 · 2026-05-18
> 核心命题：不良资产为什么形成？如何在不同阶段识别预兆？

---

## 一、三层传导模型

```
宏观环境 → 行业传导 → 主体爆发
```

### 宏观层
- 经济周期：GDP增速↓1% → 不良率滞后12-24个月↑0.2-0.4%
- 货币政策：加息→资金链断裂；降息→隐性不良积累
- 产业政策：去产能/环保/三道红线/双减 → 行业集中爆雷
- 制度变迁：监管收紧→不良认定扩大→供给增加

### 行业层
- 产能过剩→价格战→利润压缩→亏损
- 技术替代→传统模式颠覆→资产贬值
- 信用收缩→融资困难→资金链断裂

### 主体层（五大致病因子）
1. 公司治理失效（35%）：一言堂、激进杠杆、关联交易、财务造假
2. 经营失误（25%）：多元化陷阱、逆周期扩张、技术被替代
3. 担保链传染（20%）：企业互保/联保→多米诺骨牌传导
4. 道德风险（10%）：逃废债、资产转移、虚假破产
5. 不可抗力（10%）：自然灾害/疫情/地缘冲突

## 二、四类资产的形成模式

### 对公不良
高杠杆投资→现金流恶化→抽贷→资金链断裂→违约

### 房地产不良（三道红线典型）
融资受阻→销售下降→停工烂尾→多方贷款同时违约→破产

### 个贷不良
过度借贷→多头授信→以贷养贷→全面崩塌
三个违约峰值：6-12月/18-24月/36月+

### 城投隐性债务
预算软约束→土地财政下行→偿债能力下降→展期重组→实质不良

## 三、核心判断工具

### 流动性危机 vs 经营危机
| 维度 | 流动性危机（可救） | 经营危机（难救） |
|------|:----------------:|:---------------:|
| 主业 | 仍盈利 | 持续亏损 |
| 原因 | 短期资金错配 | 市场消失/技术替代 |
| 策略 | 过桥贷款+展期 | 清算+拍卖 |
| 回收率 | 70-100% | 20-40% |

### 逃废债识别四信号
1. 资产转移：核心资产突然出售给关联方
2. 空壳化：主要客户/员工转移到新公司
3. 低价处置：评估价大幅低于市场价
4. 假破产：突然申请破产+无合理原因
