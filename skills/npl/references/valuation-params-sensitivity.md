# 估值参数设定与敏感性分析

> 合并自：npl-valuation-parameters-sensitivity

## 折现率构成
- 无风险利率：2.5-4%（国债收益率）
- 风险溢价：次级5-8% / 可疑8-12% / 损失12-15%
- 流动性溢价：高0-3% / 中3-6% / 低6-8%
- 综合折现率：22%-48%（NPL真实风险调整）

## 折扣率设定
- 次级类：10-30%
- 可疑类：30-50%
- 损失类：50-70%

## 敏感性分析要点
- 折现率±1% → 估值影响5-15%
- 增长率±1% → 估值影响3-10%
- 折扣率±5% → 估值影响10-25%

## 多参数综合情景
- 乐观：折现率-1% + 增长率+2% + 折扣率-5% → 估值+15-20%
- 悲观：折现率+2% + 增长率-2% + 折扣率+10% → 估值-25-30%
