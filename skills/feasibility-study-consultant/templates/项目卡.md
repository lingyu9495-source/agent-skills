# 项目信息采集卡（一页纸 Intake Sheet）

> 目的：**在动笔之前，把项目摸清楚**。填不满这张卡，就不要开始写论证——
> 论证的深度取决于输入的清晰度，输入是糊的，输出一定是套话。
>
> 用法：把这张卡直接发给客户/项目方填；或用第 2 页的引导方式，由你带着对方口头过一遍，你来填。

---

## A 必答区（5 问，缺任何一条都无法开工）

| # | 问题 | 为什么必答 | 你的答案 |
|---|------|-----------|---------|
| 1 | **这是件什么事？**（一句话：谁、在哪、干什么、多大规模） | 决定项目类型与论证框架 | |
| 2 | **钱从哪来？**（自筹／银行贷款／政府资金／专项债／投资人／上市募资） | 决定经济性论证口径与合规要求 | |
| 3 | **谁看这份论证、他要拿它做什么决定？**（企业负责人批预算／银行审贷／发改立项／投资人投钱／自己心里有底） | 决定"什么算过"的门槛 | |
| 4 | **什么时候要？**（3 天／2 周／1 个月+） | 决定做"快速研判"还是"详细论证" | |
| 5 | **最想回答哪个问题？**（能不能做／值不值得做／哪个方案更好／怎么做才成） | 决定先答什么、用什么方法 | |

## B 按项目类型补充（勾出类型，填对应组）

| 类型 | 关键补充信息 |
|------|-------------|
| **产能型**（工厂/园区/养殖/加工） | 建设内容与规模、主要设备与询价、原燃料来源与价格、产能与达产节奏、选址与要素（地/水/电/气/环保指标） |
| **服务型**（门店/医疗/教育/餐饮/物流服务） | 目标客群与数量、客单价与频次、单店/单点模型、选址与客流、人力配置与人工成本 |
| **科技型**（软件/硬件/AI/研发） | 技术成熟度（TRL 级别）、研发里程碑与投入、知识产权状态、目标客户的付费意愿证据、竞品替代方案 |
| **资产型**（地产/仓储/并购存量资产） | 资产权属与瑕疵、现金流现状、估值口径与可比案例、改造/持有/退出路径、税费 |
| **平台型**（双边市场/渠道/供应链） | 两侧用户的冷启动计划、网络效应来源、补贴与获客成本、单位经济（单笔） |
| **贸易型**（代理/分销/进出口） | 货源与账期、毛利与返点结构、客户集中度、汇率与关税敞口 |

## C 资源与证据可得性（决定论证能做多硬）

| 能拿到什么 | 有／无 | 备注 |
|-----------|-------|------|
| 一手数据（合同、订单、台账、报价单、批文） | | 有 = 证据等级 A，可信度最高 |
| 二手权威数据（行业年鉴、券商研报、协会统计） | | 证据等级 B |
| 只能靠公开报道与推断 | | 证据等级 C/D，结论必须标"待验证" |
| 能做访谈/调研的对象 | | 谁？几个？什么时候能约到？ |
| 能做小规模试点的条件 | | 预算多少？周期多久？ |
| 已知的硬约束（不批、没钱、没人、政策不允许） | | **有红线的先说，别写到最后才发现做不了** |

## D 红线清单（出现任一条，结论只能是"不可做"或"改变范围"）

- [ ] 资金来源不合法/不落实，且无替代方案
- [ ] 触碰政策/监管红线（准入、环保、土地、资质）
- [ ] 核心要素拿不到（地/许可/关键设备/关键技术）
- [ ] 需求不存在，或需求方明确不付费
- [ ] 单位经济为负且规模扩大无法改善（越做越亏）

## 填写示例（产能型·冷链物流园）

| # | 问题 | 示例答案 |
|---|------|---------|
| 1 | 这是件什么事 | 在某市建 5 万吨级冷链物流园，含低温库、分拣加工与配套 |
| 2 | 钱从哪来 | 自有 30% + 银行贷款 70% |
| 3 | 谁看、做什么决定 | 银行审贷部看，决定是否放贷；同时公司股东会看，决定是否投 |
| 4 | 什么时候要 | 1 个月（银行内部评审排期已定） |
| 5 | 最想回答什么 | 先答"值不值得做"（回报能否覆盖贷款本息），再答"怎么做"（规模与分期） |
| 类型 | 产能型 | 规模、设备询价、用地与能耗指标齐全；客户订单只有口头意向 |
| 证据 | 一手：用地批文、设备报价；二手：行业冷库出租率；缺口：客户订单未落纸 | → 客户订单是本项目最危险的假设，进台账优先验证 |
