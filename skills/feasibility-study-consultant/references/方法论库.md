# 论证方法论库（什么情况用什么方法）

> 用错方法的代价：拿"市场空间很大"去回答"值不值得投"，或者用一套财务模型去回答"技术上做不做得到"。
> **先判断问题类型，再挑方法**——这份库就是选型用的。

## 选型三步

1. **定问题类型**：能不能做（可行性）｜值不值得做（经济性）｜哪个方案更好（比选）｜怎么做才成（路径）
2. **定项目阶段**：机会研究（粗筛）｜初步可行性研究（判断要不要深做）｜详细可行性研究（决策依据）｜投资决策/报批（合规+财务）
3. **定读者与门槛**：企业负责人批预算／银行审贷／政府立项／投资人投钱——每种读者"什么算过"不同

> 项目阶段的三段式（机会研究 → 初步可行性研究 → 详细可行性研究）是国内外通行的前期研究递进结构：
> 越往后数据精度要求越高、投入越大。**别用详细可研的成本去回答一个机会研究就能解决的问题。**

## 一、阶段门判定（Stage-Gate）

| 项 | 内容 |
|----|------|
| **何时用** | 任何"要不要继续投钱/继续做"的决策点；多项目排队时的资源分配 |
| **怎么做** | 设门 → 用六准则逐条答（战略契合／产品与竞争优势／市场吸引力／技术可行性／协同与能力／财务回报与风险）→ 出四种决策之一：**Go / Kill / Hold / Recycle** |
| **要什么数据** | 每一准则下至少一条可核证据；答不上来的准则本身就是结论 |
| **输出** | 一页纸门径结论 + 下一步动作 + 下次复盘时间 |
| **常见误用** | 把门当形式（先决定做再补材料）；只给"做/不做"两个选项，忽略 Hold/Recycle 这两个更常见的正确答案 |

配套：`templates/决策门清单.md`

## 二、市场容量自下而上测算（TAM / SAM / SOM）

| 项 | 内容 |
|----|------|
| **何时用** | 需要回答"这生意天花板多大""我的目标客户到底有多少" |
| **怎么做** | ①TAM 总市场＝单位客单价 × 潜在客户总数；②SAM 可服务市场＝受地域/渠道/资质约束后能触达的部分；③SOM 可获取市场＝按竞争格局与销售能力现实能拿到的份额 |
| **要什么数据** | 客单价（报价/合同/公开招投标价）、客户数量（统计数据/名录/自下而上数）、约束条件（地域/资质/渠道） |
| **输出** | 三档市场规模 + 测算过程 + 每一层假设的来源 |
| **常见误用** | 用"行业报告说市场规模 X 万亿"直接当自己的市场；不自下而上交叉验证；不区分 TAM/SAM/SOM（把天花板当业绩） |

## 三、竞争壁垒分析（7 Powers）

| 项 | 内容 |
|----|------|
| **何时用** | 回答"凭什么赢、优势能维持多久"；判断项目是否会被迅速抹平 |
| **怎么做** | 逐项核对七种结构性优势：规模经济／网络效应／反向定位（对手难以模仿的战略）／转换成本／品牌／独占资源／流程能力。每种优势都要同时说清"给持有者什么好处"和"靠什么壁垒不让对手套利" |
| **要什么数据** | 成本结构曲线、用户规模与增速、客户切换成本证据、资源独占证明 |
| **输出** | 现有优势清单 + 优势建立路径 + 预计可维持年限 |
| **常见误用** | 把"我们更努力/更便宜/服务更好"当壁垒——那只是运营优势，不是结构性优势 |

## 四、单位经济模型（Unit Economics）

| 项 | 内容 |
|----|------|
| **何时用** | 回答"这生意每一单赚不赚钱"；平台型、服务型、SaaS、连锁业态必做 |
| **怎么做** | 单件（或单客户、单店）收入 − 变动成本 = 单位毛利；获客成本 CAC ÷ 单位毛利 = **回本周期**；LTV ÷ CAC 判断值不值得放大；再看规模扩大后是否改善（规模效应） |
| **要什么数据** | 客单价、单笔变动成本、获客渠道成本与转化率、复购/续费率、留存 |
| **输出** | 单位经济三指标（毛利、CAC 回收期、LTV/CAC）+ 规模化后敏感性 |
| **常见误用** | 用"整体亏损是因为规模不够"掩饰单位经济为负；把补贴后的数字当作常态模型 |

## 五、财务评价（IRR / NPV / 回收期 / 盈亏平衡 / 敏感性）

| 项 | 内容 |
|----|------|
| **何时用** | 回答"值不值得投"的核心，任何资金投入型项目必做 |
| **怎么做** | ①搭现金流模型（建设期投入 → 运营期收入/成本/税 → 净现金流）②算全投资 IRR、NPV（基准收益率折现）、静态/动态回收期、资本金 IRR ③盈亏平衡点（收入降到多少亏）④敏感性：关键变量 ±10% 看 IRR 是否跌破基准，找出**临界点** |
| **要什么数据** | 投资构成（建设投资/建设期利息/铺底流动资金）、成本结构、收入与达产节奏、税率、融资条件 |
| **输出** | 三情景（悲观/基准/乐观）指标表 + 临界点 + 关键假设清单 |
| **常见误用** | 只给基准情景（不测最坏）；用"大概%"代替能复算的模型；投资/成本/收入/指标四表数字互相对不上 |

> 注：政府投资类项目的完整合规格式与深度要求见发改委 2023 版大纲（通用大纲与企业参考大纲分列），
> 需要出正式可研报告时按大纲逐章对应。

## 六、多方案比选（加权决策矩阵 / AHP 思路）

| 项 | 内容 |
|----|------|
| **何时用** | 有 2 个以上可选方案（选址 A/B、规模大/中/小、自建/合作/并购）；决策因素多且相互冲突 |
| **怎么做** | ①定准则（4–8 条，太多会失真）②定权重（合计 100%，可借两两比较法求权重）③各方案逐条打分（统一量纲/评分基准）④加权求和排序 ⑤对权重和分数做敏感性（分数动了结论会不会翻） |
| **要什么数据** | 各方案在每条准则下的量化或半量化表现 |
| **输出** | 比选矩阵 + 排序 + "结论稳健性"说明 |
| **常见误用** | 权重定了却不说依据；用打分掩盖证据缺失；不做得分为何如此的说明（变成"数字版的拍脑袋"） |

配套：`scripts/feasibility_scorecard.py`

## 七、失败预演（Pre-mortem）

| 项 | 内容 |
|----|------|
| **何时用** | 论证完成、准备下结论之前；团队一致乐观时（越乐观越要做） |
| **怎么做** | 设定"项目已经失败"的未来场景，让每个人独立写下失败原因（各自写、不讨论）→ 汇总归类 → 对高概率高影响的原因补对策或改方案 |
| **要什么数据** | 无（靠结构化想象 + 已知同类失败案例检索） |
| **输出** | 失败原因清单 + 触发信号（早期预警指标）+ 对策 |
| **常见误用** | 变成走过场的"风险章套话"；只列风险不定预警信号与责任人 |

> 机制要点：把"未来已经发生"当既定事实来回顾，比问"可能有什么风险"能挖出更多真实风险。

## 八、假设台账与最小成本验证

| 项 | 内容 |
|----|------|
| **何时用** | 全程。项目论证的本质就是"把关键假设列出来，然后验证它们" |
| **怎么做** | ①列出结论所依赖的假设 ②按「影响 × 不确定性」排序（先验最要命的）③为每条设计最小成本验证（查一手数据/访谈/小样/试点/预付）④写明**判据阈值**（验到什么程度算过）⑤更新状态：未验证／验证中／已验证／已证伪 |
| **要什么数据** | 每条假设对应的一手来源或实验设计 |
| **输出** | 假设台账 + 验证计划 + 阻塞项清单 |
| **常见误用** | 只验容易验的（避免心理成本）；用"客户说有兴趣"当已验证；把致命假设留在结论之后没人管 |

配套：`scripts/assumption_ledger.py`、`templates/假设台账.csv`

## 九、双视角交叉（政策视角 × 资本视角）

| 项 | 内容 |
|----|------|
| **何时用** | 所有需要"这事现在做合适吗"的判断；强监管行业、政策驱动行业尤其必要 |
| **怎么做** | ①政策视角：产业政策方向、准入与审批、监管趋势、补贴与合规成本、地方态度 ②资本视角：资金可得性与成本、回报门槛、退出路径、同类交易估值锚 ③交叉：政策支持但资本回报不足＝小步试；资本赚钱但政策收紧＝谨慎/准备退出预案 |
| **要什么数据** | 政策文件与规划原文、同类项目融资与估值案例 |
| **输出** | 双视角结论 + 交叉判定 + 对项目形态的调整建议 |
| **常见误用** | 只看资本不看政策（尤其政府相关业务）；把政策利好当成商业可行性 |

## 十、证据分级与多源交叉（贯穿所有方法）

| 等级 | 说明 | 用法 |
|------|------|------|
| **A** | 官方/一手：政府文件、批文、合同订单、企业台账、审计报告 | 可直接作为结论依据 |
| **B** | 权威二手：行业年鉴、券商研报、协会统计、上市公司财报 | 可用，标注来源与年份 |
| **C** | 一般二手：媒体报道、第三方文章 | 仅作参考，需交叉验证 |
| **D** | 推断/假设：模型推算、类比估计 | 必须标"待验证"，不得单独支撑结论 |

**交叉规则**：核心数据（市场规模、投资额、收益率、政策依据）至少 2 个独立来源；两源矛盾时如实呈现差异并说明取舍理由，不回避。
