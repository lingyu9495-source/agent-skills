# 电商运营操盘手册

> 视角说明：本技能是**运营操盘**（店铺怎么赚钱），不是投资视角。
> 投资视角用 `e-commerce-industry-deep-dive` / `e-commerce-ai-investment-framework`。
> 数据来源：2026 巨量千川公开新规与行业口径（联网核实，非编造）。口径会变，**关键数字用前复核一次**。

## When to Use
- 用户要算某个店铺/单品的账（毛利、盈亏线、可承受广告费）
- 要做/诊断投放（千川、全域推广），问「为什么不起量/为什么亏」
- 选品定价、看竞品、定价格带
- 复购/私域/供应链周转诊断

## 一、先算账（一切结论的地基）

**六个必算公式**：
```
毛利        = 售价 − 产品成本 − 运费 − 平台佣金 − 售后/退货摊销
毛利率      = 毛利 ÷ 售价
保本ROI     = 1 ÷ 毛利率
可承受广告费 = 售价 − 产品成本 − 运费 − 平台佣金 − 目标利润
目标ROI     = 客单价 ÷ 可承受广告费
库存周转天  = 平均库存 ÷ 日均销货成本
LTV         = 客单价 × 复购次数 × 毛利率
```
**代入示例**（售价299/成本60/运费5/佣金5%=15/目标利润100）：
`可承受广告费 = 299−60−5−15−100 = 119` → `目标ROI = 299÷119 = 2.5`

**铁律**：任何投放建议先给上面这张账；不算账不给方案。

## 二、千川投放（2026 新规要点）

**结构性变化（必须知道，否则打法全错）**：
1. **标准推广已下线，全域推广是唯一新建入口**
2. **净成交ROI =（成交金额 − 退款金额）÷ 广告花费**（挤掉秒退水分）
   - ⇒ 切到净成交后账面 ROI 通常**下降 15–25%**，属「水分蒸发」，不是投放变差
3. 行业平均净成交 ROI ≈ **2.5**；品类差异极大：日用品≈3 / 美妆≈4 / 3C数码 6.5+ / 奢侈品 10+ / 珠宝 50+
4. 全域推广跨场景转化率是单场景的 **1.8 倍**

**冷启动 SOP（红线）**：
- 起步 ROI 设**低于历史/系统建议 10–20%**（设太高系统找不到放量空间，计划花不出去）
- **第 1–7 天三不动**：出价/定向/素材都不动（模型需 24–48h 数据）
- **每日改价 ≤ 2 次**（超了取消成本保障）；阶梯加价间隔 **≥20 分钟**
- 日常配比：**80% 控成本 + 20% 放量**

**四个隐形刹车**（踩了必亏）：
① ROI 目标设太高 → 花不出去　② 冷启动频繁调价 → 模型学不到
③ 素材跟不上消耗 → 提前烧完　④ 投产比 < 2.5 不暂停 → 明天只多亏一天

## 三、指标水位（日报必看）

| 指标 | 健康值 | 异常信号 |
|---|---|---|
| 点击率 CTR | ≥3%（竖版） | <1.5% 换素材 |
| 转化率 CVR | ≥2%（标品） | <1% 优化详情页 |
| 完播率 | ≥35% | <30% 重做前 3 秒 |
| 投放 ROI | 高于保本 ROI | 连续 3 天低于保本 → 暂停 |
| 日预算消耗 | ≥80% | <50% 说明起量困难 |
| 退货率 | 按类目看 | 突增先查秒退/刷单 |

**复盘节律**：新计划每 12h 看一次；稳定计划每天固定时间（次日上午 10 点）复盘前一天。

## 四、素材（2026 最大瓶颈）

- 素材生命周期已缩短到 **3–7 天**；**83% 商家卡在产能**
- **每周至少 5 条原创**；周产 <5 条的账号不要日均烧超 500 元
- 暗水印全面启用 → **混剪会被识别限流/拒审**
- 高转化结构：`痛点(3s) → 产品(5s) → 使用/效果(20s) → 价格(5s) → 行动引导(2s)`
- 硬标准：1080×1920 竖版、全程硬字幕 ≥28px、前 3 秒必须出产品或痛点
- 一次测 3–5 条不同风格，保留 CTR 高于行业均值 20% 的持续投

## 五、选品与定价

**选品四问**：
1. 需求真不真？（看搜索量/竞品销量，不看感觉）
2. 毛利够不够？（算完六公式；毛利 <30% 慎做投流）
3. 复购有没有？（一次性 vs 可复购，LTV 差 3–10 倍）
4. 竞品护城河在哪？（价格/供应链/内容/品牌，四选一）

**定价三层**：
- 引流款（低价、拉新、可亏）→ 利润款（主力，看 ROI）→ 形象款（高价，撑品牌）
- 用**价格带**看竞品：先画同品类价格分布，找空档而非挤红海

## 六、供应链与履约

- 成本：出厂价 + 包装 + 物流 + 退货损耗 + 平台佣金 = 真实成本（别只看出厂价）
- 账期：现金流比毛利重要（先问「什么时候回款」）
- 库存周转：>60 天是警戒线；滞销占比 >20% 立即处理
- 退货率：高于类目均值 1.5 倍，先查商品质量与描述不符

## 七、复购与私域

- 复购率 = 二次购买人数 ÷ 首购人数（按周期算，如 90 天）
- 私域三触点：店铺会员 / 微信社群 / 企微
- LTV > 3×CAC 才值得加投放；LTV < CAC 先修产品与复购

## 八、常见坑

1. **只看 ROI 不看毛利** → ROI 达标仍可能亏（佣金/退货/运费没算进）
2. **冷启动频繁调价** → 唯一正确做法是「稳住不动」
3. **素材不做产能规划** → 有钱投没素材跑，等于烧钱
4. **混剪/搬运** → 暗水印识别，直接限流
5. **用自然流思维看付费** → 付费是买确定性，算的是毛利不是 GMV
6. **把 GMV 当成绩** → 问的是「净利多少、回款什么时候到」

## 九、交付口径

- 报告结论**先给数字再给结论**；没有的数据标「拿不到」，不编
- 涉及花钱（投放预算）→ 先给「可承受广告费」上限与最坏亏损，让用户拍板
- 视觉物料走**低饱和暖色系配色**：米白底 + 琥珀金 #DF9C2A
