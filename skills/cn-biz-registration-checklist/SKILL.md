> 本包是完整版《工商财税实务包（4 技能+39 份表格）》的免费速查版：留材料清单 + 5 份高频空白表格。

## 一、有限责任公司设立（核心 7 项）

1. 《公司登记（备案）申请书》（设立项）——全体股东签字或盖章，法定代表人签字 + 公司盖章。
2. 全体股东**主体资格证明或自然人身份证明**复印件。
3. **公司章程**（全体股东签署；一人公司由股东签署）。
4. 法定代表人、董事、监事、高管的**任职文件及身份证明**。
5. 住所/经营场所**合法使用证明**（房产证或租赁合同）。
6. 经营范围涉及**前置许可**的，提交批准文件/许可证复印件。
7. 自主申报名称的，提交《名称自主申报告知书》《名称自主申报承诺书》。

> 一人有限公司：不设股东会，提交**股东决定**；章程用一人公司范本。

## 二、谈单采集清单（客户先给这些）

公司名称（备 1–3 个）、经营范围、注册资本（万元）、股权比例；地址产权材料（房产证每页拍照原图或购房合同）、房屋租赁合同拍照；法定代表人/监事/联络员/财务负责人及电话；全体股东身份证正反面拍照 + 电话；公司邮箱。**以上人员需可配合实名认证及扫码签字。**

## 三、其他主体速查

- **合伙企业**：申请书 + 全体合伙人签署的合伙协议 + 合伙人主体资格文件/住所证明 + 场所使用文件 + 前置许可（特殊普通合伙另需职业资格证明）。
- **个人独资企业**：申请书 + 投资人身份证明 + 场所使用文件。
- **分支机构**：申请书 + 场所使用文件 + 隶属企业营业执照复印件 + 负责人任职信息（**免于提交**隶属公司章程/合伙协议）。

## 四、名称与经营范围的线上前置动作

- **名称**：先做企业名称自主申报（告知书 + 信用承诺书）；名称结构 = 行政区划 + 字号 + 行业 + 组织形式。
- **经营范围**：在《经营范围规范表述查询系统》查规范表述；涉及前置许可的先办许可证。

## 五、设立后配套（按需办理）

税务登记/电子税务局开户 → 银行开户 → 公积金开户 → 涉许可经营的办许可证（如食品经营许可）。

**变更**常见项（改名/改址/范围/资本/董监高）：股东会决议或董事决定 + 修改后的章程或修正案 + 申请书 2026 版表格。**注销**：普通注销走清算+公告，简易注销用全体投资人承诺书；工商年报（每年 1-6 月）逾期会列入经营异常。

全部为**空白/占位件**，不含任何真实客户信息；办哪件事复制对应文件另存再填。
