# 权限与配置清单

## 一、创建应用（飞书开放平台）

1. 打开 https://open.feishu.cn/app → **创建企业自建应用**
2. 填名称与图标 → 创建完成，进 **凭证与基础信息** 页拿两样东西：
   - `App ID`（形如 `cli_xxxxx`）
   - `App Secret`
3. 这两样就是本套件的凭据，填进环境变量：

```sh
export FEISHU_APP_ID=cli_xxxxx
export FEISHU_APP_SECRET=xxxxx
```

## 二、开权限（权限管理 → API 权限）

| 权限 | 用途 | 不发的后果 |
|---|---|---|
| `im:message` | 发送消息 | 卡建好了但发不出去 |
| `im:message:send_as_bot` | 以应用身份发消息 | 同上 |
| `cardkit:card:write` | CardKit 建卡 / 更新卡 | 用了会报权限错误；此时可退回 `send` 命令（1.0 静态卡不需要它） |
| `im:chat:readonly` | 列出机器人所在群（拿 `chat_id`） | `chats` 命令返回空列表 |

## 三、发布版本（最容易漏的一步）

开发者后台 → **版本管理与发布** → 创建版本 → 申请发布。
企业自建应用通常需要**管理员审核通过**后才生效。改完权限必须**重新发布**，否则权限不生效。

## 四、拿到 receive_id（发给谁）

飞书发消息必须有 `receive_id`，四种类型：

| 类型 | 形态 | 怎么拿 |
|---|---|---|
| `chat_id` | `oc_xxxxx` | **最简单**：把机器人拉进群，然后 `feishu_card.py chats` 列出来 |
| `open_id` | `ou_xxxxx` | 用户与机器人产生会话（事件回调里带），或调通讯录接口 |
| `user_id` | 自定义 id | 管理员在通讯录设置的自定义 ID |
| `email` | 邮箱 | 直接填邮箱（需权限） |

```sh
# 机器人拉进群后：
python scripts/feishu_card.py chats
# → {"action":"chats","ok":true,"count":1,"chats":[{"chat_id":"oc_xxx","name":"测试群"}]}
```

**单聊场景**：把机器人拉进一个只有你和它的群，或在飞书里直接跟机器人对话，用回调事件里的 `chat_id`。
一劳永逸的办法是把它设进环境变量：

```sh
export FEISHU_RECEIVE_ID=oc_xxxxx
export FEISHU_RECEIVE_ID_TYPE=chat_id
```

之后所有命令都不用再传 `--receive-id`。

## 五、接好之后自检

```sh
python scripts/feishu_card.py token   # 凭据对吗
python scripts/feishu_card.py chats   # 能拿到会话吗
python scripts/feishu_card.py probe   # 卡片四个动作全通吗（不发消息）
```

三条全绿 = 接入完成。发一条实物验证：

```sh
python scripts/feishu_card.py think-card --receive-id oc_xxx
```
