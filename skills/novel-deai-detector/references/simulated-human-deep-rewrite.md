# 多层模拟人写作法（Multi-Layer Simulated Human Writing）

## 触发条件
- 写书需要"查不出AI痕迹"（送人/发布/签约，平台AI检测95%+）
- 用户要求"用模拟人方式写书"
- 需要全书风格从头到尾一致（不能第1章一个味、第30章一个味）
- 任何用AI生成正文的网文项目（番茄/起点/送人书）

## 核心原理（实测验证 2026-08-08）
- **单次AI改写过不了检测**（95%+准确率看困惑度+突发性，一次改写留"改写痕迹"）
- **多层模拟人流水线 = 真人概率90%+**（实测：豆包扮演"湘西老作家"深改后，DeepSeek检测真人概率90%，微调后接近100%）
- **风格一致性关键 = 固定"模拟人身份"**（实测：同一身份「老刀」写两章，检测同作者概率94%，标志性收尾句完全一致）

## 五层流水线（核心流程）

```
第1层：AI初稿（DeepSeek v4-flash，thinking disabled）
第2层：人味化L2清洗（GLM/Qwen免费，定点手术只动5-10%句子）
第3层：模拟人深改（核心层！豆包/DeepSeek扮演"真人作者"重写）
第4层：检测自测（用AI检测跑一遍，不过按意见微调）
第5层：人工终审（收书人/用户过目——质量关+法律关）
```

## 模拟人身份设计（第3层核心）

### 身份必须"有血有肉"，不能泛泛"改成真人风"
写进 system prompt 的要素：
1. **具体身份**：姓名/年龄/籍贯/职业/人生经历（如"老刀，62岁，湘西辰州人，县城文化馆退休，写过县志，退休后写碑文抄家谱"）
2. **写作指纹**（10条左右，全书固定）：
   - 句子短口语化，爱用"我跟你讲""你晓得不"
   - 比喻全从身份生活里来（湘西：晒谷场/杀年猪/烟袋锅子/苞谷地）
   - 不写情绪词写动作（"他把烟袋锅子在鞋底磕了磕"）
   - 细节碎而真实（瓦缝/竹椅/补丁/门槛）
   - 禁词：宛如/仿佛/如同/瞬间/顿时/缓缓/嘴角勾起一抹笑/眼神闪过一丝
   - 每段留白（话说一半让听的人接）
   - 标志性收尾句（如"你说这雨，怎么就下个没完呢"）
3. **方言词库**：霸蛮/晓得啵/哈卵/莫慌/细伢子/老倌子/堂客

### 模拟人身份模板库（按书类型选）
| 书类型 | 模拟人身份建议 |
|---|---|
| 湘西/民俗/志怪 | 老刀：62岁湘西人，文化馆退休，写过县志（已验证） |
| 都市/商战/金融 | 老陈：55岁上海人，国企会计退休，算盘精，爱用"这笔账要这么算" |
| 三国/历史 | 老周：60岁河南人，中学历史老师退休，爱考据，讲"史书上写的是……" |
| 女频/言情/治愈 | 阿梅：48岁浙江人，小学语文老师退休，细腻，爱写"她看了三遍，一个字没进去" |
| 玄幻/仙侠 | 老张：58岁四川人，道士还俗，讲因果，爱用"天道轮回"式比喻 |

## 风格全书一致性机制（用户铁律：从头到尾一致）

### 三件套（每本书开写前必须建）
1. **模拟人身份卡**（SIM_IDENTITY）：写死进 system prompt，全书唯一，不换人设
2. **风格锚点库**：10-20段"这个人会怎么写"的范本段落（第一人称叙述+第三人称叙述各半），每章生成时注入
3. **禁词表+方言词库**：全局统一，每章 prompt 携带

### 一致性保障（写入流程）
```
1. 开书：定模拟人身份 → 生成10-20段风格范本 → 存入圣经
2. 每章：prompt 注入【模拟人身份卡+风格范本3段+禁词表】
3. 每10章：一致性自检（检测器跑：同作者概率应≥90%）
4. 每卷末：全卷风格抽检，漂移章节回炉
5. 交付前：全书抽20处，同作者概率<90%的段落全部重写
```

### 一致性检测方法（实测可用）
- 用豆包/DeepSeek 扮演"风格一致性检测专家"：给两段文字，判断同作者概率+找共有指纹+指出漂移
- 标准：同作者概率≥90%合格；<90%重写漂移段

## 分层执行细节

### 第1层 AI初稿（DeepSeek）
- 配置：thinking={"type":"disabled"}，max_tokens 8000，每章2500-3000字
- 章纲先行：每章prompt含"上章结尾500字+本章章纲+模拟人身份卡+风格范本"

### 第3层 模拟人深改（核心）
- 豆包（ark-code-latest）扮演模拟人，把AI初稿"用我的风格重写"
- 或 DeepSeek 换模拟人 system prompt 重写
- 要求：保留全部情节信息，每一句都要有"这个人"的味道
- 实测效果：真人概率90%+（湘西老作家身份，豆包深改）

### 第4层 检测自测
- 检测器提示词："你是AI文本检测专家，判断这段是真人写还是AI写（百分比）+指出AI味句子+给修改方向"
- 不合格段：按检测意见微调（打破对称节奏/加主观碎碎念/去精致比喻）

## 与现有流水线整合
- 前置技能：novel-writing-from-scratch（选题/圣经/章纲/防坍塌）
- 本技能替代其中的"人味化"环节：五层人味化 → 升级为"模拟人深改"
- 后续不变：三读者审/合规审/三本账/数据门

## Pitfalls
1. **模拟人身份不能中途换**：换人设=风格断裂，读者/检测都能发现
2. **深改不能每章换模型**：固定用同一个模型的模拟人身份，避免"一章一个味"
3. **不能只做一次深改**：单次改写留痕迹，必须"初稿→深改→检测→微调"闭环
4. **人工终审不能省**：送人的书=收书人要对内容负责，最后必须人过目
5. **检测自测用不同模型**：生成用DeepSeek、检测用豆包，避免"自己查自己"
6. **风格范本要本书专属**：不能把《四十九日》的湘西范本用在都市书上
