# 服务型商业模式 · 可行性方案模板

**来源：** AI智能体定制服务 · 可行性方案 v3.0（2026-07-16实战）
**业务类型：** 服务交付型（AI定制化开发）
**适用场景：** 任何以「人力服务+技术搬运」为核心的商业方案

---

## 一、适用条件

使用此模板前请确认业务满足以下条件：
- [ ] 核心交付是人力服务（知识整理、方案设计、技术配置）
- [ ] 有续费/订阅模式（不只是卖一次性产品）
- [ ] 边际成本随经验积累递减（模板复用效应）
- [ ] 本地化/本地服务是壁垒
- [ ] 没有硬技术专利壁垒，壁垒来自know-how和信任

---

## 二、方案结构（推荐顺序）

### 先给结论
一句话说清：我们到底在做什么生意。例如：「这不是一个卖AI的生意，这是一个帮企业把知识管好、把流程整清的服务生意。」

### 第一章：商业模式本质 ← 这是服务型方案的灵魂章节

**1.1 商业模式公式**
```
总收入 = 新客数 × 客单价 × 转化率 + 老客数 × 续费率 × 续费单价
```

**1.2 边际成本曲线（核心洞察）**
- 第1个客户：X天（从零搭建）
- 第5个同行业客户：约30%的时间（模板复用）
- 结论：每做一个同行业客户，成本打6折

**1.3 收入三阶段模型**
- 验证期（1-3月）：免费/成本价跑3-5家，目的是跑通交付流程和建立模板
- 爬坡期（4-8月）：月增X家，验证可复制性
- 稳定期（9月起）：续费收入占比上升，利润率大幅攀升

**1.4 盈利能力模拟（12个月）**
逐月列出：累计客户数 / 新增收入 / 续费收入 / 总成本 / 净利润
标注：关键转折点（第几个月起续费开始显著贡献利润）

**1.5 风险边界**
- 续费率<30%才真正有威胁（应对：交付后持续维护+使用追踪）
- 产能瓶颈通过模板化+SOP缓解
- 多模型切换应对上游涨价

### 第二章：市场验证
- 市场规模（最新数据+来源等级）
- 为什么大厂做不了（成本结构分析）
- 本地市场分析（区域竞品摸底）
- 窗口期判断

### 第三章：产品定义
- 一句话说清卖什么
- 产品线（每个产品独立核价）
- 定价体系
- 成本优势的底层逻辑

### 第四章：核心交付方法论
- 交付流程（步骤化）
- 技术选型原则（不绑定）
- 为什么客户需要我们

### 第五章：风险评估
- 风险矩阵（概率×影响×应对）
- 判断基调（偏乐观/偏保守/中立+原因）

### 第六章：落地方案
- 合作条件（如有合作方）
- 独立启动路径
- 行动时间线

---

## 三、关键写作原则

1. **商业模式章节写完，读者应该能回答三个问题：** 这能赚钱吗？能赚多久？风险在哪？
2. **不写空话大话**——每个判断都要有数据支撑或明确假设前提
3. **数据标注来源等级**（A=官方源/B=行业媒体/C=自媒体/D=待验证）
4. **判断基调必须标注**：偏乐观/偏保守/中立，并说明原因
5. **合作方阅读时，注意力集中在商业模式和收入结构上**——不要在技术细节上花太多篇幅

## 四、与产品型方案的结构对比

| 维度 | 产品型（标准结构） | 服务型（本模板） |
|:-----|:------------------|:----------------|
| 开头 | 市场数据 | 商业模式本质 |
| 核心问题 | 市场够大吗？产品有竞争力吗？ | 这个模式能持续赚钱吗？ |
| 收入假设 | 一次性销售为主 | 首次收入+续费 |
| 成本分析 | 固定成本+变动成本 | 边际成本递减曲线 |
| 壁垒论证 | 技术/专利/品牌 | know-how积累+本地服务+信任 |
| 结论类型 | 应该做/不应该做 | 能做+多久回本+怎么持续 |
