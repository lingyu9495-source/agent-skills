# FA项目快速评估工作流

## 触发场景

用户发来一个项目/交易信息，说出关键数字，要求判断「这事能搞吗」「能融到钱吗」。典型信号：
- 「有个项目，总投资X，自有X，融资X」
- 「客户想做什么什么，缺钱」
- 「合作方式可谈，垫资代建/明股实债/共同投资」
- 「预计X个月回本」

## 工作流

### 第一步：数据解码

把用户给出的数字拆成独立要素：

| 要素 | 示例 | 关注点 |
|------|------|--------|
| 总投资 | 3000万 | 是否匹配行业常识？ |
| 自有资金 | 1000万 | 杠杆率多少？ |
| 需要融资 | 2000万 | 金额是否合理？ |
| 回本周期 | 11个月 | 行业标准是多少？差距多大？ |
| 合作模式 | 垫资代建/明股实债 | 哪种模式实操可行？ |
| 客户背景 | "医疗界行家" | 是否有可验证的硬证据？ |

### 第二步：硬伤优先（核心原则）

**不要先分析、不要先肯定、不要先包装。第一反应指出数字层面的问题。**

先回答三个问题：
1. **总投资是否低于行业门槛？** — 查市场数据：同类项目实际投资额（如癌症医院单台直线加速器就1500-3000万）
2. **回本周期是否脱离行业常识？** — 查行业数据：同类型业务的真实回本周期（如民营肿瘤医院5-8年回本）
3. **自有资金比例是否可控？** — 杠杆率>70%需要特别关注财务可持续性

输出格式：
```
## 🚩 硬伤清单

### 硬伤①：XX —— 具体问题
[市场对比数据表格]
[结论]

### 硬伤②：XX
...
```

数据支撑原则：
- 每个硬伤必须有市场数据对比（搜到的数据/行业常识）
- 标注数据来源等级
- 不要说"可能有问题"，直接说有数据和没说有

### 第三步：用户修正→快速pivot

用户可能会在讨论中修正前提（这是FA项目的常态）：
- 「不是建医院，是买设备」→ 评估框架全部换
- 「不是3000万，是3000万设备」→ 医疗设备融资租赁vs医院建设是完全不同的赛道
- 「11个月是单台设备回本，不是全院」→ 合理性完全不同

修正后需要：
1. 承认修正并重新定位问题：「这个澄清很重要，如果是XX，那就是另一个事情了」
2. 替换对标框架：找该赛道的标准融资渠道
3. 重新评估可行性（可能从❌变成🟢）

### 第四步：融资渠道映射

当项目被证实是「设备融资」而非「项目融资」时，渠道完全不同：

| 项目类型 | 找谁 | 看点 | 回本周期要求 |
|----------|------|------|-------------|
| 建医院/实体 | PE/VC/政府引导基金 | 团队/ROI/牌照 | 5-8年 |
| 买设备 | 融资租赁公司 | 设备残值/还款能力 | 3-5年分期 |
| 装修/改造 | 银行经营贷 | 抵押物/流水 | 3-10年 |
| 运营资金 | 供应链金融 | 应收账款/订单 | 6-12月 |

关键融资租赁渠道（设备类）：
- 远东宏信 — 医疗设备融资租赁龙头
- 平安租赁(医疗健康) — 平安系，标准化审批
- 海尔医疗金融 — 门槛相对低
- 国药控股租赁 — 适合带采购一起走
- 地方金租公司 — 看当地政策

### 第五步：可执行下一步（必做）

不能只分析，要落到用户能拿去做的事情：

1. **重建方案** — 帮对方改项目结构（总投/杠杆/回本周期）
2. **材料清单** — 去对接资方需要准备什么（设备清单报价/资质/运营预测）
3. **渠道对接** — 直接推荐具体机构（如远东宏信医疗金融部）
4. **话术建议** — 怎么跟客户说（不直接说"你不行"，而是给出替代路径）

话术示例：
```
「你这个项目有两个选择：
- 如果坚持做医院，投资额需要重新算，真实成本可能在X-Y亿
- 如果只是为了买设备，我们有更轻的路——融资租赁，不需要股权稀释
要不要我先帮你整理一套设备融资的材料清单？」
```

## 完整输出结构模板

```
## 结论
✅/🟡/❌ 一句话总判断

## 硬伤（如有）
1. ...
2. ...
3. ...

## 调整后重评（如用户修正了前提）
换了框架后：可行/有条件可行

## 融资渠道建议
推荐机构/方式/准备材料

## 可执行的下一步
1. 帮他对接XX
2. 整理XX材料
3. 准备XX话术
```

## 约束

- ❌ 不要默认认同项目前提（先怀疑数字，再验证）
- ❌ 不要只分析不给下一步（用户是FA，要落地的工具）
- ✅ 硬话软说但事实不妥协（第一轮就指硬伤，但用"如果..."给台阶）
- ✅ 用户修正前提后快速pivot（不要抱着旧框架不放）
