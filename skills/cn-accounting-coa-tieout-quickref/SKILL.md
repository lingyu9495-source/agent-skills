## 二、编码差异坑（跨准则换账必看）

- **成本类同科目不同码**：小企业 4001/4101/4301/4401/4403（生产成本/制造费用/研发支出/工程施工/机械作业）vs 企业准则 5001/5101/5301/5401/5403——**同一业务两套账编码不同，跨准则换账必须重编码**。
- **损益类 5xx→6xx**：小企业 5001 主营业务收入→企业准则 6001；5401 主营业务成本→6401；5601/5602/5603 三费→6601/6602/6603；5801 所得税费用→6801。
- **同码不同名**：1101 小企业叫「短期投资」、企业准则叫「交易性金融资产」；1501 小企业「长期债券投资」、企业准则「债权投资」。
- 企业准则独有 32 个科目（备抵类/金融工具/租赁/政府补助/减值类），小企业准则下**不计提减值准备**——坏账和存货损失直接走营业外支出。

## 三、三表勾稽规则（出报表前逐条过）

1. **资产负债表恒等**：资产总计 = 负债合计 + 所有者权益合计（含少数股东权益）。
2. **未分配利润滚动**：期末未分配利润 = 期初未分配利润 + 本期净利润 − 提取盈余公积 − 分配的股利。
3. **利润表→资产负债表**：本期净利润（利润表末行）必须等于资产负债表未分配利润的本期增加额（未考虑分红时）。
4. **现金流量表→资产负债表**：期末现金及现金等价物余额 = 资产负债表「货币资金」期末余额（含库存现金+银行存款+其他货币资金，受限资金需剔除并单独披露）。
5. **现金流量表内部**：现金净增加额 = 经营活动净额 + 投资活动净额 + 筹资活动净额；期末现金 = 期初现金 + 现金净增加额。
6. **收入费用勾稽**：营业收入 − 营业成本 − 税金及附加 − 期间费用 + 其他损益 ≈ 利润总额（差额应能逐项解释：投资收益/资产处置/减值/营业外）。
7. **应付职工薪酬**：期末 = 期初 + 本期计提 − 本期支付；**应交税费**：期末 = 期初 + 本期计提 − 本期缴纳。
8. **折旧勾稽**：期末累计折旧 = 期初累计折旧 + 本期计提折旧 − 处置转出。

## 四、月结核对顺序（七步骨架）

银行/支付宝/微信对账 → 往来款对账（应收/应付/其他）→ 存货盘点 → 税账核对（含递延税）→ 总账明细账勾稽 → 试算平衡 → 损益类科目余额结转为零 → 备份账套。
