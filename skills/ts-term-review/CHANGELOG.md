## v1.0.4

### 为什么版本号从 1.0.1 直接到 1.0.4

本技能自 v1.0.1 起**内容没有任何功能改动**——正文与 v1.0.1 逐字节相同。
版号变化只为**跨渠道对齐**，让 GitHub / SkillHub / 魔搭三处指向同一份制品：

- **v1.0.2 / v1.0.3**：只发布在 SkillHub 渠道，且制品有缺陷
  （v1.0.2 标签与包内版本不一致；v1.0.3 包内 `SKILL.md` 正文丢失、只剩 frontmatter）。
  这两个版本号在 Skills 平台上**已被占用且不可覆盖**，因此修正版只能往后取号。
- **v1.0.4**：正文完整、版本自洽的修正版。已在 Skills 平台上线并逐文件 sha256 校验通过，
  现同步至 GitHub 与魔搭，使三条渠道的版号与内容完全一致。

### 无功能变更

技能正文、`references/` 参考文件与 v1.0.1 完全一致。
本次发布性质为**制品修复 + 版号对齐**，不影响任何使用方式。
