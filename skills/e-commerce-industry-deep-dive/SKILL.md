# 电商行业深度研究

## 一、电商业务模式全景

### 1.1 按交易主体分类

| 模式 | 代表平台 | 核心特征 |
|------|---------|---------|
| **B2C** | 天猫/京东/拼多多 | 平台自营或品牌直营，标准化服务 |
| **C2C** | 淘宝/闲鱼 | 个人对个人，长尾商品，信用体系关键 |
| **B2B** | 1688/慧聪 | 企业间大宗交易，供应链效率核心 |
| **S2B2C** | 云集/爱库存 | 供应链赋能小B分销商触达C端 |
| **DTC** | 完美日记/Shein | 品牌直接触达消费者，数据驱动 |
| **社交电商** | 拼多多/快手电商 | 基于社交裂变，拼团/直播/短视频 |
| **内容电商** | 小红书/抖音电商 | 内容驱动消费，种草→拔草链路 |
| **即时零售** | 美团闪购/京东到家 | 30分钟-1小时达，本地供给+即时配送 |

### 1.2 电商产业链图谱

```
上游（品牌/制造商）→ 中游（平台/渠道）→ 下游（消费者）
           ↓                       ↓
      仓储物流                  支付体系
      供应链金融                流量分发
      TP/代运营                履约服务
```

## 二、电商供应链体系

### 2.1 供应链核心节点

| 节点 | 说明 | 投资关注点 |
|------|------|-----------|
| 选品/采购 | 商品开发、供应商管理 | 品类集中度、供应链深度 |
| 仓储 | 中心仓/前置仓/云仓 | 仓网布局、自动化程度 |
| 配送 | 干线+末端 | 配送时效、成本结构 |
| 库存管理 | 库存周转、SKU优化 | 周转天数、缺货率 |
| 退换货 | 逆向物流 | 退换率、处理成本 |

### 2.2 供应链模式对比

| 模式 | 代表 | 优势 | 劣势 |
|------|------|------|------|
| 自营供应链 | 京东 | 品质可控、时效快 | 重资产、资金占用大 |
| 平台轻模式 | 淘宝 | 资产轻、SKU丰富 | 品控难、履约体验不一 |
| 前置仓 | 朴朴/叮咚 | 即时配送、体验好 | 高履约成本 |
| 云仓/一件代发 | 1688 | 无需备货 | 利润薄、控制力弱 |

## 三、流量运营体系

### 3.1 流量来源分类

| 类型 | 渠道 | 成本特征 |
|------|------|---------|
| 公域流量 | 搜索(百度)、信息流(抖音)、平台内搜索(淘宝) | 持续付费，ROI可测算 |
| 私域流量 | 微信个人号/社群、企业微信、公众号 | 前期获客高、后期复购免费 |
| 商域流量 | 平台直通车/钻展/品销宝 | 竞价机制，竞争越激烈成本越高 |
| 直播流量 | 抖音直播/快手直播/淘宝直播 | 瞬时爆发，依赖主播IP |
| 内容流量 | 小红书笔记、抖音视频、公众号文章 | 长尾效应，可持续获客 |

### 3.2 流量运营核心公式

```
GMV = 流量 × 转化率 × 客单价 × 复购率
     ↑         ↑        ↑        ↑
  曝光量   转化漏斗   商品组合   用户留存
```

### 3.3 流量运营关键指标

| 指标 | 说明 | 健康值参考 |
|------|------|-----------|
| CAC（获客成本） | 获取一个客户的成本 | 电商<¥100，私域<¥30 |
| LTV（用户生命周期价值） | 用户一生贡献的毛利 | LTV/CAC > 3:1 |
| 复购率 | 重复购买用户占比 | 成熟品牌>40% |
| 转化率 | 浏览→购买转化 | 行业平均2-5% |
| 客单价 | 单次购买金额 | 各品类差异大 |

## 四、数字化运营体系

### 4.1 数字化运营能力矩阵

| 能力层 | 工具/系统 | 价值 |
|--------|----------|------|
| 数据采集 | 埋点/API/爬虫 | 用户行为数据化 |
| 数据分析 | BI系统/数据中台 | 经营洞察 |
| 用户画像 | CDP（客户数据平台） | 精准营销 |
| 自动化营销 | MA（营销自动化） | 降本增效 |
| 智能决策 | AI预测/推荐算法 | 库存/定价/推荐 |

### 4.2 电商企业数字化成熟度评估

| 级别 | 特征 | 典型企业 |
|------|------|---------|
| L1: 初级 | Excel管库存，手工对账 | 小商家 |
| L2: 标准 | ERP/CRM，业务在线化 | 中型卖家 |
| L3: 数据驱动 | 数据中台+BI分析 | 品牌电商 |
| L4: 智能运营 | AI预测+自动化决策 | 头部平台 |

## 五、电商赛道投资评估框架

### 5.1 电商企业投资评估维度

| 维度 | 核心问题 | 评估指标 |
|------|---------|---------|
| 商业模式 | 是否可持续、有壁垒？ | 毛利率、复购率、客户集中度 |
| 供应链 | 效率如何、是否可规模？ | 周转天数、履约成本占比 |
| 流量能力 | 获客成本、渠道依赖度？ | CAC、渠道占比、ROI |
| 数字化 | 数据驱动程度？ | IT投入占比、数据应用场景 |
| 团队 | 电商基因、行业经验？ | 核心团队背景、组织能力 |

### 5.2 电商赛道投资逻辑框架

```
判断赛道天花板
    ↓
评估竞争格局（集中度/壁垒）
    ↓
分析商业模式健康度（毛利率/现金流）
    ↓
验证供应链效率（周转/履约）
    ↓
审查流量获取能力（CAC/LTV）
    ↓
评估数字化水平（数据驱动程度）
    ↓
判断团队执行力（电商实战经验）
```

## 六、常见电商投资项目类型

| 类型 | 投资逻辑 | 风险 |
|------|---------|------|
| 平台型 | 网络效应，赢家通吃 | 烧钱大战，监管风险 |
| 品牌型(DTC) | 品类冠军，品牌溢价 | 流量成本上升 |
| 服务商(TP/代运营) | 卖水人，行业增长受益 | 客户流失风险 |
| 供应链型 | 效率提升，成本优势 | 重资产 |
| 技术型(SaaS/工具) | 订阅模式，高毛利 | 获客难 |
