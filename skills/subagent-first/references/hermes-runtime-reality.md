# 示例实现（Hermes）· 运行实况对齐（2026-09-13 实测）

> **这是「示例实现（Hermes）」一页，其他平台可以整页忽略。**
> 本技能的方法论是平台无关的（见 `SKILL.md` 正文与「工具名对照表」）；这一页只记录 Hermes 这一个平台在落地时的具体差异：
> 字段名、并发上限、后台语义、成本口径。换平台时，把下表中的 Hermes 项按你平台的对应机制替换即可。
>
> 派活前先看这一页，能避掉「以为派了其实在干等」「被上限整调用拒绝」「账单翻倍」三类事故。

## 一、`delegate_task` 的真实语义

| 朴素想象 | Hermes 实况 |
|---|---|
| 派出去 → 阻塞等结果回来 | **dispatch 立即返回**；子代理在后台跑，结果**在回合之间**作为新消息回到对话 |
| 主代理要盯着进度 | **禁止轮询或干等**（不要 wait/poll 产物、transcript、CI）。派完给一句状态 + 结束本回合 |
| 派出去就管不了了 | 运行中可现场控制：`action=list`（看全部子代理与状态）/ `steer`（往某个子代理灌纠正指令）/ `stop`（提前结束，部分成果仍会返回） |
| 一次调用 = 一个交付单元 | 默认整批算一个单元、一条消息回；开 `delegation.independent_completions` 后**每个任务或每个 `group` 各自回报**，先完成的先到，不被最慢的拖住 |
| 子代理能看到对话历史 | **完全看不到**。工单写不全 = 它一定跑偏（这是最高频的返工原因） |

## 二、参数与配置（真实字段名）

- 工单字段：`goal` / `context` / `output_schema`（**真会按 JSON Schema 校验**子代理的最终答复）/ `group`（回报分桶）
- 并发上限：`delegation.max_concurrent_children`（本机 5 个 profile 统一 **6**；上游默认 3，**无硬上限**）
  - 超限后果一：一次派出的 `tasks` 数量超过上限 → **整个调用被拒**（报 "Too many tasks"）
  - 超限后果二：同一轮里连发多个 `delegate_task` → 超出部分被**截断**（日志 `Truncated N excess delegate_task call(s)`）
- 子代理**不能**用 `clarify` / `delegate_task` / `memory` / `cronjob` → 要问人、要建定时、要写长期记忆的活**必须留在主代理**
- 子代理模型由 `delegation.provider` / `delegation.model` 决定；不配则继承主代理（付费）
- 子代理生命周期与一次委派绑定：会话 `/stop`、`/new`、进程退出都会丢 → 长活必须**落盘**

## 三、成本（原包未提，必读）

- 每个子代理**独立计费**：派 N 个 = N 份 token 账单，与主代理账单分开算
- 省钱三招：① 工单要求"只回报结论 + 产物路径"，中间过程别灌回主代理；② 用 `output_schema` 把回报结构写死，省掉二次解析；③ 后台活对单轮速度不敏感 → **优先走免费通道**
- 派之前先算一笔：**自己做的耗时 vs（写工单 + 等返回 + 回读验证）的总耗时**；不划算就自己做

## 四、与「随时应答」机制的关系（本机已装）

本机 5 个 profile 已启用 `display.busy_input_mode: interrupt` + `busy_ack_enabled: true` + `agent.gateway_notify_interval: 30`：
用户插话**立刻**被听到——模型请求期直接注入纠正并重试（已完成的工作保留）；工具执行期请求前台长命令 **yield 转后台**（不杀活）；有子代理在跑时自动降级排队保护，**不级联取消子代理**。长任务每 30 秒播报一次进度。
配套技能：`agent-responsiveness-delegation`（含一键落地 / 体检脚本 + SOUL 铁律块模板）。

> ⚠️ **插话模式别选 `steer`**：`agent/interrupt_control.py:217` 注释写明，steer 是把用户的话**附在"最后一条工具结果"上，等这批工具跑完才送达**，返回 False 才降级为 queue。主代理在前台跑长命令时，steer 会一直卡到命令退出——用户体感就是"没人理"。要"随时能插话"必须用 **interrupt**（走 `redirect()`，带 yield 机制）。
> ⚠️ **别用 `tools.disabled_toolsets` 禁主代理的重工具**来逼它派活：子代理**不能拥有主代理没有的工具**（`delegate_tool_toolsets.py:71`），禁了等于自废武功。

> 一句话：**方法论看本包，机制与参数看这一页。** 两份合起来才是"派得对 + 派得动 + 随时能回话"。
