# 派活工单

> 一份可直接复制的子代理派活模板。**填不满就不要派**——缺项意味着要判断的东西还没想清楚，
> 派出去只会得到一份需要你重做的产出。

## 使用说明

1. 复制下面「工单正文」整块，逐字段填写，方括号 `[...]` 里的提示文字全部替换掉。
2. 关键前提：**子代理看不到主代理与用户的对话历史**。凡是你脑中默认成立、但对方无法从文件
   或工单文本里读到的事实，都必须写进「背景 / context」。
3. 一条工单只对应一个子代理。任务太大就拆成多条工单，拆不开说明任务本身还没想清楚。
4. 工单里的每个路径都写成**实际可访问的相对路径或绝对路径**，不要写「上次那个文件」。

---

## 工单正文（复制以下全部内容）

```markdown
# 派活工单: [任务名，6-16 字，名词短语]

## 一、目标
[一句话。必须可验证：读完能判断"做完了没有"。]
[反例：帮忙整理一下资料。]
[正例：把 3 份竞品官网产品页抓成 markdown，按"定价/功能/差异点"三段归纳，写入指定文件。]

## 二、背景 / context（自包含，子代理看不到主对话）
- [为什么要做这件事：上游决策、用户诉求、交付对象]
- [已经确认的事实：口径、结论、数据来源，写清来源]
- [已排除的方案与原因，避免子代理重复走弯路]
- [术语与口径约定：同一指标在本任务里指什么、单位、取整规则]

## 三、输入
- 文件/目录：
  - `[路径]` —— [里面是什么，重点看哪部分]
  - `[路径]` —— [同上]
- 参考来源：[URL 或来源名；若无写"无"]（用 `web_extract` / `browser_navigate` 等工具取数）
- 需先确认的前置：[若依赖某个命令输出或某文件存在，写在这里]

## 四、约束与边界（必填，越具体越好）
- 允许： [可以做哪些动作]
- 禁止： [不许做哪些动作；例：不得修改 `X` 之外的文件、不得发起外部写操作、不得自行扩大检索范围]
- 工具： [推荐用哪些工具；例：优先 `terminal` 批量处理，抓取失败再用 `browser_navigate`]
- 预算： [预计轮数上限 / 时间上限 / 最多读取多少条记录]
- 不确定时的处理： [停下并在回传里提问，还是按最保守方案继续并标注]

## 五、输出物与路径（写死，不接受"放在合适的地方"）
- 主产出：`[文件路径]`（格式：[md/json/csv/docx…]，编码 UTF-8）
- 中间产物：`[路径或"不需要"]`
- 命名规则：`[例：YYYYMMDD_主题_版本]`
- 是否允许覆盖已有文件：[允许覆盖 `X` / 只新建不覆盖]

## 六、验收标准（逐条可勾选）
- [ ] [可观测事实 1：例 `[路径]` 存在且能读到，章节数为 3]
- [ ] [可观测事实 2：例 每个结论都带来源链接，无来源的结论单独标注"待核实"]
- [ ] [可观测事实 3：例 输出文件的数字与输入文件同口径，可逐项对账]
- [ ] [可观测事实 4：例 脚本/命令真实执行过，回传里附真实输出而非描述]
- [ ] 未完成或失败的项已如实标注，未用推测填充

## 七、回传格式（子代理照此结构回报，不要长篇叙述）
1. 结论： [一句话，做完 / 部分完成 / 失败]
2. 产出： [文件路径清单 + 每个文件的行数或大小]
3. 证据： [关键命令与真实输出片段；外部副作用给可回读的 handle/路径/ID]
4. 未决： [需要用户或主代理确认的问题，逐条列出]
5. 偏离： [与工单不一致之处及原因；无则写"无"]
6. 自检： [对照第六节验收标准逐条给结论：通过 / 不通过 + 依据]
```

## 常见填坑

| 坑 | 后果 | 正确做法 |
| --- | --- | --- |
| 背景只写「延续上次的工作」 | 子代理无历史，只能猜 | 把必要事实抄进工单，宁可重复 |
| 输出路径不写死 | 产出散落在临时目录，回收成本高 | 指定落地路径与命名规则 |
| 验收标准写「质量高」「仔细检查」 | 无法判定，只能凭感觉收 | 换成可观测事实：文件存在、条数、字段、可回读句柄 |
| 边界不写禁止项 | 子代理顺手改了不该改的文件 | 显式列出禁止动作与可写范围 |
| 目标一句话说不清 | 任务本身没想清楚 | 先自己做一步侦察，再拆成多条工单 |
| 不给预算 | 子代理可能无限检索消耗资源 | 写明轮数/时间/条数上限与超限处理 |

## 交付前自检

- [ ] 工单里出现的每个路径都真实存在（或明确标注为待创建）
- [ ] 「背景 / context」满不满足自包含：假定读者从未见过主对话，能否独立完成
- [ ] 验收标准每一条都能用命令或读文件判定
- [ ] 回传格式含「证据」与「自检」两栏，能直接用于验收清单逐条核对
- [ ] 若存在不可逆副作用（覆盖、删除、对外发送），已在工单中标注并移交主代理把关
