# 审计底稿速查（免费精简版）

> 当用户提到「年报审计怎么做底稿」「专项审计程序清单」「重要性怎么定」「审计调整分录」时使用本技能。

## 一、CAS 准则速查（按审计五阶段对号入座）

| 阶段 | 主要准则 | 落到什么程序 |
|------|---------|-------------|
| 初步业务活动 | CAS 1111（业务约定书）、CAS 1121（项目质量控制）、CAS 1153（前后任沟通） | 约定书条款审阅、独立性确认、前任沟通记录 |
| 风险评估 | CAS 1211（识别和评估重大错报风险）、CAS 1141（舞弊） | 了解单位及环境、识别特别风险、管理层凌驾应对 |
| 重要性 | CAS 1221（重要性） | 定整体重要性/实际执行重要性/明显微小临界值并写明理由 |
| 实质性程序 | CAS 1231（应对风险）、CAS 1312（函证）、CAS 1313（分析程序）、CAS 1311（存货监盘） | 七科目程序、函证控制、监盘、截止测试 |
| 完成 | CAS 1251（评价错报）、CAS 1332（期后事项）、CAS 1341（书面声明） | 错报汇总评价、期后事项检查、书面声明取得 |
| 报告 | CAS 1501（审计报告）、CAS 1502（非无保留意见）、CAS 1503（强调事项段） | 四种意见类型对号入座 |
| 归档与沟通 | CAS 1131（归档）、CAS 1151（与治理层沟通） | 报告日后 60 天内归档；底稿保存至少 10 年 |

## 二、底稿三件套铁律（写进每一张底稿）

1. 每张底稿必须有：**结论 + 依据（准则号/文件号）+ 证据索引**（交叉索引到凭证号/函证编号）。
2. 询证函由项目组**全程控制**（发出、回函、替代程序），不交给被审计单位转交。
3. 管理层口头解释只作线索，**必须落到书面证据**才进底稿。
4. 每张底稿留：**执行人 + 执行日期 + 复核人 + 复核日期**。

## 三、重要性计算骨架（CAS 1221）

三层结构：整体重要性 → 实际执行重要性（×50%-75%）→ 明显微小错报临界值（×3%-5%）。

基准选择速查：

| 被审计单位情况 | 推荐基准 | 典型百分比 |
|---|---|---|
| 盈利稳定（最常见） | 经常性业务税前利润 | 5%–10% |
| 微利/微亏/盈亏交替 | 营业收入 | 0.5%–1% |
| 新设/在建/无收入 | 总资产 | 0.5%–2% |
| 新兴行业抢市场 | 营业收入 | 0.5%–1% |
| 非营利组织 | 收入或费用总额 | 1%–2% |

比例定档：风险较高（首次审计/内控弱）→ 50%；一般中小企业 → 60%-65%；连续审计且错报少 → 70%-75%。

底稿骨架（索引号 AB-4）：选择基准（数字+理由）→ 确定百分比（勾选考虑因素）→ 计算 → 结论（错报超过 X 元即属重大）→ 特定类别更低重要性（关联方交易/管理层薪酬/重大收购处置/违反法规交易）。

## 四、审计调整三类分清

| 类型 | 是否调账 | 典型场景 |
|---|---|---|
| 重分类调整 | **只调表不调账** | 应收贷方→预收、应付借方→预付、长期借款一年内到期→一年内到期的非流动负债 |
| 账项调整 | 调表也调账 | 少提折旧、费用跨期、提前/延迟确认收入、应付账款未入账 |
| 跨年滚调 | 通过年初未分配利润 | 上年调整客户未入账：**损益类科目全部替换为「年初未分配利润」，资产负债类保持原科目和方向** |

三张汇总表骨架：账项调整分录汇总表（AF-1，序号/调整内容/借贷科目金额/合计/对净利润影响）→ 重分类汇总表（AF-2）→ 试算平衡表（AF-3：未审数+账项调整+重分类调整=审定数，资产总计=负债和权益总计 ✓）。

## 五、使用方式

- **前置条件**：业务承接资料齐（营业执照、上期报表、章程、股东会决议）、审计业务约定书已签。
- 顺序：总控台账 → 风险评估 → 定重要性 → 七科目实质性程序（货币资金/应收/应付/存货/固定资产/费用/收入）→ 错报汇总 → 报告意见。
- 每个程序在底稿留下「执行人＋日期＋证据索引」，按上表对号落准则号。
