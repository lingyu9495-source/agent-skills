# 生意判断与可研报告

## When to Use
- 用户问"这个生意能不能做/值不值得投/帮我看看这个项目"
- 要写可行性研究报告（可研）、立项报告、项目建议书
- 要做赛道研判、行业分析、商业计划书财务章节
- 关联知识：`knowledge/04-AI赛道与研判/AI赛道与生意研判知识库-2026.md`（含本轮全部来源与公式代入）

## 第一步：先定档（别一上来就写大报告）

| 档位 | 适用 | 交付 | 耗时 |
|---|---|---|---|
| **口算判断** | 用户随口问"这事能不能干" | 四层结论 + 三条风险，聊天框直接答 | 1 轮 |
| **简化可研** | 单品/小店/小项目 | 5 节、3~5 页飞书文档 | 半天 |
| **标准可研** | 中等投资、要给合伙人/银行看 | 按发改委 2023 参考大纲九章 | 2~3 天 |
| **投标/政府版** | 政府补贴、园区立项、招标 | **严格按《通用大纲 2023》** | 30 页起 |

**不确定要哪档 → 默认先出口算判断（快、免费），用户要成文再升档。**

## 第二步：四层生意判断（核心方法）

### 第 1 层 · 赛道（能不能做）——三线不齐不给结论
1. **政策眼光**：国家级文件点名？补贴/准入/牌照变化？**必须引政府官网原文+发文字号**，二手转述的"政策"不作数
2. **资本眼光**：近 12 个月融资事件数与金额、谁在出手（财务机构 vs 产业方/CVC）、阶段重心
3. **竞争格局**：CR3 集中度、有无平台级入口被卡、替代品威胁

### 第 2 层 · 单位经济（赚不赚钱）——★最关键，很多人跳过这层
```
单元贡献毛利 = 单元收入 − 单元变动成本(直接材料+平台佣金+履约+投放+赔付计提)

贡献毛利 ≤ 0 → 模式本身不成立，销量越大亏越多，直接否决
贡献毛利 > 0 → 才进入第 3 层
```
最小单元自己选：1 件商品 / 1 个客户 / 1 次服务 / 1 个项目。

### 第 3 层 · 盈亏平衡（多久回本）
```
平衡点销量 = 固定成本 ÷ 单位贡献毛利
平衡点销售额 = 固定成本 ÷ 贡献毛利率
```
**代入示例**：固定成本 30 万/年，单品贡献毛利 60 元 → 300000÷60 = **5,000 件/年 ≈ 13.7 件/天**。
→ 必须把固定成本、可变成本、经常性支出、一次性费用**全算进去**；算出的平衡点高得离谱 = 要么成本漏项要么生意不成立。

### 第 4 层 · 死在哪（必答三题）
1. 现金跑道几个月？（现金 ÷ 月均净流出）
2. 单位经济成立吗？
3. 三年内谁接盘、什么价、什么时候？

**最终必须给出"最可能死在哪的三条"，每条配触发信号与应对，不许写套话。**

## 第三步：写可研的官方框架

**权威依据**：《国家发展改革委关于印发投资项目可行性研究报告编写大纲及说明的通知》**发改投资规〔2023〕304号**（2023-03-23 印发，2023-05-01 施行）【https://www.ndrc.gov.cn/xxgk/zcfb/ghxwj/202304/t20230407_1353356.html】
- 政府投资项目 → 《政府投资项目可行性研究报告编写通用大纲（2023年版）》，**审批的基本依据**
- 企业投资项目 → 《企业投资项目可行性研究报告编写参考大纲（2023年版）》
- 官方定调：**"可行性研究是投资决策的核心环节"**
- 灵活性：单一/小规模项目可按规定简化；重大复杂项目可加摘要

### 企业投资参考大纲九章
1. **一、概述**——（一）项目概况：名称、目标任务、地点、内容规模、工期、**投资规模和资金来源**、建设模式、**主要技术经济指标**；（二）企业概况：基本信息、发展现状、财务状况、类似项目、信用与能力
2. **二、项目建设背景和必要性**
3. **三、项目需求分析与产出方案**
4. **五、项目建设方案**
5. **六、项目运营方案**
6. **七、项目投融资与财务方案** ← 钱在这章
7. **八、项目影响效果分析**
8. **九、项目风险管控**

### 简化版（5 节）
项目概况 → 市场与赛道 → 单位经济与盈亏平衡 → 投入与回收 → 风险三条

## 第四步：交付纪律（三条，违反不交稿）
1. **数字必须有来源**：市场规模引机构+日期、费率引官方、成本引实测；编不出来源的写明**"测算假设"**并标注，绝不冒充事实
2. **财务必给三张表**：投入构成表、月度现金流表（至少 24 个月）、盈亏平衡表；每个公式**公式+代入过程+示例数字**
3. **报告过三关**：反思（数据完整吗、来源可靠吗、逻辑有洞吗）→ 审查（结论与证据匹配吗、有无过度推断、有无反方观点）→ 修正，不达标绝不出

## 行业研究检查清单（赛道研判用）
中邮证券十二项【《如何撰写行业研究框架》2024-06-13】，一般项目至少覆盖前六项：
发展动力 → 市场空间 → 消费需求 → 政府政策 → 竞争格局 → 商业模式（+行业规律/产业链规律/成长路径/行业估值/公司估值/公司筛选）

## 边界（必须向用户提示）
- 我不是律师/会计师/审计机构：法律、财务、税务的最终意见需专业人士交叉验证
- **最终决策权永远在用户手里**
