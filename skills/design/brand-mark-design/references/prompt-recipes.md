# 文生图 prompt 配方（标识／头像发散用）

## 结构

`[主体] + [风格] + [材质／光影] + [配色／底] + [构图] + [排除项]`

**排除项固定加 `无文字`** —— 文生图极易生成乱码文字，标识里尤其致命。

## 风格词（按气质选，一批只走一个方向，方向要拉开）

| 想要的 | 关键词 |
|---|---|
| 现代科技标识 | 几何化、锐利三角构成、极简、扁平、品牌标志 |
| 高级优雅 | 流畅线条、大量留白、优雅曲线、奢侈品牌标志 |
| 图腾／徽章 | 圆形徽章、浮雕、图腾、铜鼓纹、对称 |
| 东方意境 | 水墨、写意、飞白、留白、宣纸 |
| 原始岩画 | 粗犷线条、斑驳岩壁质感、赭色矿物颜料 |
| 神圣威严 | 光芒、星辰、金光、深黑背景、神圣 |
| **APP 图标** | 手机APP图标、iOS风格、圆角方形、扁平化、居中 |

## 配色词

- 默认：`米白背景` / `纯白背景` + `琥珀金／古铜金`
- ⚠️ 只写"金色"会得到**偏亮的黄**，廉价；写 **"琥珀金／古铜金"** 才压得住，贴低饱和暖色系
- 需要更"重"的气场时才用 `深邃黑金背景`

## 构图词

`居中、对称、占满画面、四周留白、圆形构图`

## 已验证有效的意象方向（鹰主题示例，换主体可复用）

1. 展翅 + 星尘深黑底 —— 冲击力最强
2. 侧面主体 + 流畅线条 + 白底 —— 最像品牌标志
3. 几何三角构成 + 白底 —— 现代科技感
4. 双翼化放射光芒 + 白底 —— 抽象、**小尺寸最清晰**
5. 主体 + 铜鼓太阳纹圆形徽章 —— 图腾感、天然贴合圆形头像
6. 主体 + 星辰轨道 —— 未来与古典并存

## 迭代法

- **第一轮**：6–10 个**不同方向**的 prompt，广撒网（别在同一方向微调）
- **第二轮**：围绕较好的 2–3 个方向改细节词（线条／材质／底色）再跑一批
- **选定后**：把 3–6 张精选拼成一张对比图交付，附主推意见
- 每轮结束先裁圆再看 —— 水印和"裁切后是否成立"只有裁圆后才看得准

## 文化母题素材：花山岩画（用户本地母题 —— 天然不撞车，优先用）

用户所在地，**取当地文化母题是最安全的"原创"解法**（避开抄 Claude/OpenAI 的红线）。以下图案**均有实物／世界遗产出处，已核实**，可直接取形：

| 图案 | 形态要点 |
|---|---|
| **蹲式人形**（岩画主体） | 小方头、双臂屈肘上举、双腿屈膝外张（蛙蹲）；分正身／侧身，有的戴冠、腰佩环首刀 |
| **铜鼓** | 鼓面同心晕圈 + 中心十二芒太阳纹；边缘常铸立体蛙 |
| **太阳纹** | 同心圆 + 放射芒（铜鼓鼓心纹） |
| **羊角钮钟** | 上窄下宽的钟体，顶部钮两端伸出上弯的羊角（岭南特有青铜器） |
| **环首刀** | 直刃微弧，刀柄末端一个圆环 |
| **舟船** | 月牙形船身，船上载若干"羽人" |
| **犬** | 岩画动物图像的主角，皆侧身作小跑状 |
| **蛙** | 壮族图腾，铜鼓立体装饰的原型 |

**典型组合**（岩画原构图）：高大正身人为中心 → 脚下有犬 → 胯下／身旁置铜鼓 → 四周是形体短小的侧身人。

出处（交付时要讲）：左江花山岩画，崇左宁明，战国至东汉骆越人所绘，2016 年列入世界文化遗产，**中国岩画类第一处世遗**。

**取形注意**：纯手工用 PIL 复刻这些图案 → 天花板只到"图标级"（见 SKILL.md 铁律一）；优先让文生图去画，PIL 只做后期。
