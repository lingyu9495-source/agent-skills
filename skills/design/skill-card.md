## Description: <br>
Executes and critiques visual design with quantified rules for hierarchy, spacing, type scale, color, and layout. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ivangdavila](https://clawhub.ai/user/ivangdavila) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Designers, developers, and content creators use this skill to create or critique UI screens, landing pages, slides, graphics, emails, charts, and documents using measurable visual-design rules. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Local design preferences and project context may be retained in ~/Clawic/data/design/. <br>
Mitigation: Review or delete those files before installing or using the skill when retained design memory is not wanted. <br>
Risk: Design guidance can affect public-facing artifacts and accessibility outcomes. <br>
Mitigation: Review generated design changes against the skill's output gates, including contrast, hierarchy, alignment, and theme-specific checks, before delivery. <br>
