# 图文配图：零成本无水印出图方案

> 老板的硬要求：**便宜甚至免费、不要水印**。日更产能也压在这三条产线上。

## 先测环境，再选型（别凭印象）
```bash
nvidia-smi --query-gpu=name,memory.total --format=csv   # 常年"无 NVIDIA GPU"
free -h                                                   # 内存往往只剩 <1GB 可用
python3 -c "import PIL; print(PIL.__version__)"
fc-list | grep -icE 'cjk|wqy'                             # 中文字体数量
```
- **无 GPU + 内存吃紧 → 本地跑不了 SD/FLUX 一类生图**，这条路直接排除，别花时间试
- **有 PIL + 中文字体 → 代码生成卡片完全可行，这是主力**

常用字体：`/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc`（正文配 `NotoSansCJK-Regular.ttc`），备用 `wqy-zenhei.ttc`。

## 三条产线
| 图类型 | 工具 | 成本 | 水印 |
|---|---|---|---|
| 知识卡片 / 步骤图 | **本机 PIL 代码** | **0 元** | 无 |
| 工具实测图 | 直接截屏 | **0 元** | 无 |
| AI 封面 | 即梦（网页版）/ 通义万相 API | 0 ~ **¥0.14/张** | 无 |

- **内容页优先用真实截图**：平台在打击 AI 批量输出内容，截图更接近"真实表达"，还省一笔生图钱——省的钱和降的风险是同一件事
- 通义万相走已有的 DashScope key（`wanx2.1-t2i-turbo` 约 ¥0.14/张，开通百炼有免费额度），可自动化；即梦网页版免费无水印但要手动点
- **月成本测算**：日更 1 篇 ×（1 封面 + 4 图）→ 即梦 0 元 / 通义万相约 4.2 元。任何超过这个量级的报价都先停下来重新选型

## PIL 卡片配方（1242×1656，小红书 3:4）
- **配色按老板偏好维度喜用（配色偏好，钦定）**：土＝黄棕系、金＝白金系；**一律弃红**。实测配方：暖米白底 `#F6F1E7`+ 主文字深棕 `#2A2118`+ 次级灰棕 `#6E6152`+ 强调暗金 `#B8860B` + 亮金点缀 `#E8B94A`（金，）+ 卡片纯白 `#FFFFFF`+ 边框米色 `#E3D9C4`。**配色 3 色封顶**——爆款大字封面公式之一就是配色克制
- **标题用衬线体** `NotoSerifCJK-Bold.ttc`，正文用 `NotoSerifCJK-Regular.ttc`、标签用 `NotoSansCJK-Bold.ttc`：知识类博主的"专业感"主要来自衬线标题 + 无衬线标签的分工
- **版式（照流量大的博主改的）**：左上金色胶囊标签（内容背书，**不是账号名**）→ 超大标题 **168px**（封面字号越大点击越高，原 104px 不够）→ 分隔线 → 白底圆角卡/冲突对比条（「行业标准 7~15天 → 我用AI 1天」这类强冲突是 3S 之首）→ 结尾**提问式卡片**（CES 评论权重×4）→ 底部**纯留白**
- **❌ 不要在每张图打账号水印**（老板原话："不用太刻意的宣传"）——小红书发布后图片下方本来就显示作者昵称头像，图里再写一遍反而显刻意。页脚只留留白即可
- **换行按 `d.textlength(ch, font=font)` 逐字累加判断**，不要按字数估——中英混排与标点宽度差异会直接溢出
- **正文里的引号一律用 `「」`**：中文弯引号 `""` 与 Python 字符串定界符同形，写进 f-string 或字面量会炸在解析期（报 `invalid character`，指向的是引号后面的标点，极具误导性）
- `rounded_rectangle` + `ImageFont.truetype(path, size)`；字号阶梯建议 96（标题）/ 56（编号）/ 54（卡片标题）/ 42（正文）/ 40（标注）
- **出图后必须 `vision_analyze` 自查再交付**：排版溢出、字体回退成方框、文字重叠，只有眼睛看得出，代码不会报错
- 实测量级：单张 0.2 秒 / 143KB；模板参数化（传标题 + 三段要点）后可批量出一套
