# 财务模型构建五步法

> 合并自：financial-modeling

## 五步法
1. **历史数据整理**：过去1-3年财务数据标准化
2. **核心假设设定**：收入/成本/资本/融资/税务
3. **收入模型**：自顶向下(TAM→SAM→SOM) + 自底向上(客户×客单价)
4. **三表联动**：利润表→现金流量表→资产负债表
5. **估值输出**：DCF/可比公司/可比交易

## 三表联动关系
- 利润表净利润 → 现金流量表经营活动现金流起点
- 现金流量表期末现金 → 资产负债表现金科目
- 留存收益 = 期初 + 净利润 - 分红

## 关键财务指标
| 指标 | 公式 | 健康值 |
|------|------|--------|
| 毛利率 | (收入-成本)/收入 | >30% |
| 净利率 | 净利润/收入 | >10% |
| 现金流覆盖率 | 经营现金流/流动负债 | >1.5 |
| IRR | 使NPV=0的折现率 | >WACC+5% |
| ROI | (收益-成本)/成本 | >2x |
