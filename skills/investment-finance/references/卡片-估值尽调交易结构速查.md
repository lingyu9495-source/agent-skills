## VC法公式
```
投前估值 = 预期退出估值 / 目标回报倍数 - 投资额
```
- A轮目标回报：8-10x
- B轮目标回报：5-8x
- C轮目标回报：3-5x

## 六维尽调体系
1️⃣ 业务DD (2-3周) — 商业模式/客户验证
2️⃣ 财务DD (4-5周) — 三表真实/现金流
3️⃣ 法律DD (3-4周) — 实缴/IP/数据合规
4️⃣ 技术DD (3-4周) — AI透明/算法偏见
5️⃣ ESG DD (2-3周) — 碳足迹/治理
6️⃣ 人力DD (1-2周) — 核心团队/激励

## 红旗信号分级
🔴 致命：数据造假/IP纠纷/失信记录 → 终止
🟡 警戒：客户集中>50%/毛利率下降 → 延长DD
🟢 关注：估值>同类50% → 要求更多数据

## 混合融资标准结构
```
总对价 = 基础(60-70%) + 对赌(20-30%) + 里程碑(10%)
```

## 谈判筹码优先级
- 投资人：清算优先权 > 反稀释 > 董事会
- 创始人：估值 > 期权池 > 董事会控制
- FA策略：解决估值分歧优先，用信息权换核心条款
