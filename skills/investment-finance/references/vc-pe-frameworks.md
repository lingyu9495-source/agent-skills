# VC/PE投资尽调框架

> 合并自：investment-due-diligence
> 更新：2026-06-02 — L2深度学习扩展为六维尽调体系

## 投资尽调框架（经典五维）
1. **市场大小与增长率** — TAM/SAM/SOM量化验证
2. **竞争护城河**（技术/网络效应/转换成本/数据壁垒）
3. **团队质量与历史业绩** — 管理层背调+历史业绩验证
4. **单位经济**（LTV/CAC、毛利率、回收期、NDR）
5. **退出潜力与时间表** — IPO/并购/老股转让路径

## 2026年六维尽调体系

### 第一维：业务尽调（2-3周）
- 商业模式验证：收入来源可持续性
- 市场竞争分析：护城河深度
- 客户验证：头部客户质量
- ⚠️ 红旗：单一客户依赖>50%

### 第二维：财务尽调（4-5周）← 最重要维度
- 三表真实性验证（收入确认准则）
- 关联交易排查（利益输送风险）
- 现金流质量分析（FCF是否为正）
- 收入质量评估（经常性收入占比）
- ⚠️ 红旗：毛利率持续下降/应收膨胀

### 第三维：法律尽调（3-4周）
- 注册资本实缴状态（新公司法重点）
- 数据合规（个保法+AI训练数据）
- 知识产权归属（AI生成内容版权）
- 历史出资瑕疵排查
- 关联公司穿透（横向人格否认）
- ⚠️ 红旗：虚假出资/诉讼缠身

### 第四维：技术尽调（3-4周）← 2026年权重最高新增
- AI模型透明度与可解释性
- 算法偏见检测
- 核心IP归属与第三方依赖
- 技术架构可扩展性
- 代码安全审计
- ⚠️ 红旗：核心技术依赖单一人物

### 第五维：ESG尽调（2-3周）← 外资/机构必查
- E：碳足迹、排放合规
- S：劳动用工合规
- G：董事会独立性、审计委员会
- ⚠️ 红旗：ESG风险敞口未披露

### 第六维：人力尽调（1-2周）
- 核心人才稳定性
- 股权激励到位情况
- 薪酬竞争力
- 文化契合度
- ⚠️ 红旗：CTO/CFO近期离职

## 2026年DD流程时效标准
```
预筛选（1周）→ 通过率~30%
  ↓
快速DD（2周）→ 通过率~50%
  ↓
全面DD（4-6周）→ 通过率~60%
  ↓
投决会 → 通过率~70%
  ↓
签约交割
```

## 尽调检查清单（2026版）
- [ ] 财务报表（3年历史+预测）
- [ ] 客户集中度分析
- [ ] 技术/IP评估
- [ ] 监管合规审查
- [ ] 管理团队背景调查
- [ ] 市场验证
- [ ] 竞争定位图
- [ ] ESG评估报告
- [ ] 数据合规审查
- [ ] AI模型透明度评估
- [ ] 出资状态实缴核验
- [ ] 风险评估

## 报告结构
1. 执行摘要
2. 目标公司分析
3. 投资逻辑（VC/PE特定）
4. 盈利模式分析
5. 市场背景（TAM/SAM/SOM）
6. 估值分析与敏感性
7. 交易结构建议
8. 风险揭示与缓释措施
9. 可操作建议

## 红旗信号分级
| 等级 | 信号 | 应对 |
|------|------|------|
| 🔴 致命 | 财务数据造假/核心IP纠纷/创始人失信 | 直接终止 |
| 🟡 警戒 | 客户集中>50%/毛利率持续下降/技术依赖单人 | 延长DD |
| 🟢 关注 | 估值>同类50%/融资间隔<6月 | 要求更多数据 |

## 数据来源优先级
1. 官方文件（年报/招股书）
2. 行业报告（咨询/协会）
3. 新闻媒体
4. 公司网站
5. 内部知识
