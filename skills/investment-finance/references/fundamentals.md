## 核心概念（FA必知30词）

### 估值类
| 术语 | 英文 | 含义 | 实务要点 |
|------|------|------|---------|
| 投前估值 | Pre-money Valuation | 投资前公司价值 | TS中通常特指投前估值 |
| 投后估值 | Post-money Valuation | 投前+投资额 | 计算持股比例 |
| 完全稀释估值 | Fully Diluted Valuation | 考虑期权池+可转债 | 创始人实际感受的dilution |
| 市销率 | P/S | 估值/年收入 | SaaS/AI常用3-15x |
| 市盈率 | P/E | 估值/年净利润 | 成熟公司15-30x |
| 企业价值 | EV | 市值+净债务 | 并购定价基础 |

### 条款类
| 术语 | 含义 | 实务要点 |
|------|------|---------|
| Term Sheet (TS) | 投资意向书 | 核心谈判文件 |
| LPA | 有限合伙协议 | GP/LP权利义务 |
| SPA | 股份购买协议 | 正式投资合同 |
| Liquidation Preference | 优先清算权 | 1x非参与是市场标准 |
| Anti-dilution | 反稀释条款 | 加权平均vs完全棘轮 |
| VAM | 对赌协议 | 需合理设目标 |
| Drag-along | 拖售权 | 保护投资人退出 |
| Tag-along | 随售权 | 保护小股东利益 |

### 基金类
| 术语 | 含义 |
|------|------|
| GP/LP | 普通合伙人/有限合伙人 |
| Management Fee | 管理费（2%/年） |
| Carry | 收益分成（20%） |
| Hurdle Rate | 门槛收益率（8%/年） |
| Capital Call | 资本调用 |
| Waterfall | 瀑布分配 |
| DPI/TVPI | 已分配/总收益倍数 |

### FA类
| 术语 | 含义 | 收费标准 |
|------|------|---------|
| 买方FA | 帮投资人找项目 | 向投资方收费 |
| 卖方FA | 帮企业融资 | 向融资方收费 |
| 排他期 | 独家委托期（3-6个月） | 锁定合作关系 |
| 成功费 | 交易完成时支付 | 主体部分（1-5%） |
| 数据室 | 文件合集供投资人查看 | 结构化线上/线下 |
| 成功费阶梯 | 融资额递进制 | <100万:5%+ → 100-500万:3-5% → 500-3000万:2-3% → 3000万-1亿:1.5-2.5% → >1亿:1-2% |
| 独家FA | 排他期内客户不得另找FA | 保护FA劳动成果 |

## 核心公式

| 公式 | 计算方式 | 说明 |
|------|---------|------|
| 投后估值 | 投前估值 + 投资额 | 投前/投后是TS核心谈判点 |
| 投资人持股% | 投资额 / 投后估值 | 决定稀释比例 |
| 创始人摊薄后持股% | 原比例 × (1 - 投资人比例 - 期权池比例) | 投前预留期权池影响显著 |

## FA报价阶梯

| 融资额 | 费率 | 佣金估算 |
|-------|------|---------|
| <100万 | 5%+ | 5万+ |
| 100-500万 | 3-5% | 3-25万 |
| 500-3000万 | 2-3% | 10-90万 |
| 3000万-1亿 | 1.5-2.5% | 45-250万 |
| >1亿 | 1-2% | 100万+ |

## 一票否决信号（FA 10分钟判断法）
- ❌ 团队只有一个人（缺技术/业务互补）
- ❌ TAM < 1亿（天花板太低）
- ❌ 商业模式说不清怎么赚钱
- ❌ 估值离谱（高于同类50%+）
- ❌ 数据造假或过度承诺
- ❌ 创始人有失信记录/诉讼
- ❌ 历史出资未实缴（新公司法下的致命问题）

## 融资六步流程
1. 融资准备（1-2月）：BP+财务+法律
2. 投资人接触（2-4周）：机构筛选+FA推荐
3. BP展示（3-6周）：一对一会议+材料迭代
4. 路演交流（3-6周）：路演+筛选+决策
5. Term Sheet谈判（2-4周）：估值+条款设计
6. 法律文件与交割（2-4周）：协议+审核+交割

## FA八步法（FA视角的融资流程）

| 步骤 | 名称 | 时间 | 关键动作 | 交付物 |
|------|------|------|---------|--------|
| 1 | 融资准备（筹） | 1-2月 | 梳理公司、财务模型、法务规范 | BP+财务模型+数据室 |
| 2 | 投资人接触（找） | 2-4周 | 机构筛选、FA推荐、初步沟通 | 投资人清单+NDA |
| 3 | BP展示（磨） | 3-6周 | 一对一会谈、材料迭代 | 定制版BP |
| 4 | 路演交流（亮） | 3-6周 | 正式路演、筛选、决策推进 | 跟进纪要+Q&A |
| 5 | TS谈判（谈） | 2-4周 | 估值+条款设计、核心谈判 | 签署TS |
| 6 | 法律文件与交割（签） | 2-4周 | SPA/股东协议、审核、交割 | 交割完成 |
| 7 | 投后管理（收） | 持续 | 投资人关系管理、后续融资 | 季度报告+里程碑 |

> 口诀：筹→找→磨→亮→筛→谈→签→收

## 风险控制四象限

| 风险类型 | 典型问题 | 应对策略 |
|---------|---------|---------|
| 信息风险 | 财务数据不透明/不规范、历史融资文件缺失、关联交易未披露 | 全面财务尽调+法务尽调 |
| 法律风险 | 历史出资未实缴、知识产权权属不明、竞业限制未清理、章程与投资协议冲突 | 法务尽调清单逐项核查 |
| 市场风险 | 赛道泡沫、技术路线被替代、政策监管变化(AI合规/数据安全) | 行业对标分析+技术验证 |
| 交易风险 | 对赌目标不合理、赎回条款执行难、否决权被滥用、反稀释过度摊薄 | 有经验律师审查核心条款 |

## 2026年Q2更新：投融资基础新变化
### 新公司法对基本概念的影响
- **出资加速到期**：公司资不抵债时，债权人可要求股东提前实缴（2026年已有首案群）
- **类别股入法**：优先股/AB股正式入法，工商登记系统逐步对接
- **横向人格否认**：关联公司债务可穿透至实控人（2026年1月首案确立三混同标准）
- **FA实务建议**：融资前完成出资实缴→避免交易延迟+估值下降

### 2026年Q1-Q2市场基本面
- AI应用层融资额首超基础模型层（55%:45%）
- 新消费融资回暖（1月18亿元），关注盈利模型
- 全球医疗健康2025全年600亿+美元融资
- 中东主权基金对华投资Q1约45亿美元（+65%）
- S基金市场爆发（Q1交易120亿元，+22%）

### 2026年FA报价策略调整
- 热门赛道（AI/具身智能）：3-4%，低基础+高成功费
- 传统赛道（消费/制造）：4-6%，高基础+里程碑付费
- 跨境交易（含中东资本）：3-5%+架构费
| 早期/天使轮 | 5-8%，股权+现金混合

## L1补充：FA必知财务与指标基础

### 财务三表速查（FA基础级）
| 报表 | 核心内容 | FA关注要点 |
|------|---------|-----------|
| 利润表(P&L) | 收入—成本—费用—利润 | 毛利率趋势、研发费用率、SG&A效率 |
| 资产负债表(BS) | 资产=负债+所有者权益 | 现金余额、应收账款、注册资本实缴情况 |
| 现金流量表(CF) | 经营/投资/筹资三流 | 经营现金流是否为正、烧钱速度(burn rate) |

### 核心指标速查
| 指标 | 定义 | FA实务意义 |
|------|------|-----------|
| Burn Rate (烧钱率) | 月均净现金流出 | 判断公司「跑道」(Runway)长短，通常需12-18个月 |
| Runway (现金跑道) | 现金余额÷月烧钱率 | 投资人判断下轮融资紧迫性的核心指标 |
| Gross Margin (毛利率) | (收入-直接成本)/收入 | SaaS>70%、硬件>40%为健康线 |
| ARR (年度经常性收入) | 月经常性收入×12 | SaaS/AI公司的定价基准 |
| MRR (月经常性收入) | 月订阅收入总额 | 增长率的计算基础 |
| NRR (净留存率) | (期初ARR+增量-流失)/期初ARR | >120%为优秀，表明客户在增购 |
| CAC (客户获取成本) | 销售总费用÷新客户数 | 需结合LTV看是否健康 |
| LTV (客户生命周期价值) | ARPU×客户平均生命周期 | CAC的3x以上为健康 |
| IRR (内部收益率) | 投资现金流折现后的年化收益 | 投资人评估项目回报的标准指标，VC目标>25% |
| MOIC (投资回报倍数) | 退出金额/投资金额 | 直观看赚了多少倍，1x=保本 |

### FA委托协议要点（Engagement Letter）
| 条款 | 说明 | 避坑建议 |
|------|------|---------|
| 独家期 | 3-6个月不得另找FA | 确认到期自动终止，无隐式续期条款 |
| 成功费阶梯 | 按融资额递进费率 | 确认是否含认股权证/可转债转换部分 |
| 预付费用 | 尽职调查/差旅等 | 务必可抵后续成功费（credit against fee） |
| 成功费触发点 | 签署SPA还是到账交割 | 建议以资金到账为触发 |
| 分阶段融资 | 多轮close如何处理 | 明确每轮close单独计费 |

### 数据室最小清单（FA基础版）
| 类别 | 文件 | 说明 |
|------|------|------|
| 公司文件 | 营业执照、章程、股东名册、历次融资文件 | 核实股权结构和历史融资条款 |
| 财务文件 | 近3年审计报告+最近一期管理报表、财务模型、税务合规证明 | 核心尽调材料 |
| 业务文件 | BP、收入明细top20客户、产品路线图、竞品分析 | 讲清楚业务逻辑 |
| 法务文件 | 知识产权清单(专利/商标/软著)、核心员工劳动合同+竞业限制、重大合同 | 法律风险排查 |
| 团队文件 | 创始人简历、核心团队组织架构、员工期权计划 | 验证团队完整性 |
