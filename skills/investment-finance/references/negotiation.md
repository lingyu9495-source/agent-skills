# 投融资谈判实战技能

> 合并自：investment-negotiation-skills
> 更新：2026-05-27（第3轮L3深度学习·补充TS谈判策略）

## 投融资谈判核心理念

**低价+宽松条款 > 高价+严苛条款**
优先争取"生存攸关"条款（清算优先、反稀释、控制权），次要条款可让步换取主要条款优势。

## 四步谈判框架
1. **谈判准备**：背景调查、市场分析、BATNA确定
2. **谈判执行**：开局技巧、让步策略、僵局突破
3. **僵局处理**：利益重新定位、条款创新、外部介入
4. **协议达成**：条款优化、文件准备、交割

## 关键条款谈判策略

### 估值条款
- 多方法交叉验证（DCF+市场法+可比交易）
- 开局先要高20-30%（留足让步空间）
- 行业数据支撑高于感情谈判
- 折中方案：如有对赌，估值可适当让步

### 治理条款
- 董事会平衡（投资者不超1/3）
- 保护条款覆盖（7-10项为合理范围）
- 信息权充分性（季度+年度审计，非月度）

### 经济条款
- 参与优先清算（优先于不参与）
- IPO自动转换
- 明确退出机制

### TS阶段优先谈判顺序
1. **清算优先权** — 直接影响退出回报
2. **反稀释条款** — 影响后续融资摊薄
3. **董事会构成** — 影响公司控制权
4. **保护条款范围** — 影响日常运营自由度
5. **对赌条款** — 影响创始团队风险敞口
6. **估值** — 虽然关注度高，但非最高优先

## 僵局处理三原则

1. **利益重新定位** — "不是拒绝，是寻找更好的方案"
   - 将"不要X"转化为"给我们Y，我们接受X"
   - 寻找双方利益交集点

2. **条款创新** — 引入新机制打破僵局
   - 引入ESG/KPI挂钩
   - 设置阶梯式对赌
   - 分阶段到账安排

3. **外部力量** — 引入第三方力量
   - 行业对标数据
   - 同行案例比较
   - 智库/行业专家意见
   - 其他投资人的市场竞争

## 谈判准备检查清单
- [ ] 对方背景调查完成
- [ ] BATNA确定（最佳替代方案）
- [ ] 底线与优先级设定（哪些条款绝不让步）
- [ ] 让步策略准备（哪些条款可用于交换）
- [ ] 红旗条款清单准备（识别不可接受条款）
- [ ] 行业对标数据准备（估值/条款市场标准）
- [ ] 应急方案制定（谈判破裂后的选项）
- [ ] 时间预算（控制谈判节奏）
