# 小股操盘模式投资方利益保护六条款

> 生成日期：2026-06-17
> 场景：品牌方/运营方出小股（10-20%）+负责运营，投资方出大股（80-90%）+提供资金
> 典型案例：诺亚新舟门诊南宁落地项目——诺亚出10%，资方出90%

---

## 核心逻辑

```
品牌方（10%）→ 品牌/运营/SOP/医生资源 ↕ 出钱不出力
投资方（90%）→ 资金/物业/本地关系    ↕ 出力不出钱
                      ↓
            双方利益绑定不对称
      资方风险敞口远大于品牌方
                      ↓
        需要六个硬条款锁死风险
```

---

## 条款一：控制权设计 —— 董事会+一票否决权

**核心原则：** 股权比例不完全等于控制权。资方出90%但日常运营交给品牌方，需要在重大事项上保有否决权。

### 推荐架构

| 维度 | 建议方案 | 说明 |
|------|---------|------|
| 董事会席位 | 5席：资方3席（含董事长）+ 品牌方2席（含CEO/院长） | 资方占多数，但不拿日常运营权 |
| 一票否决权范围 | ✅ 章程修改、增资减资、合并分立、清算<br>✅ 超过XX万元资产处置（如设备采购>50万）<br>✅ 对外担保、重大合同（>30万）<br>✅ 年度预算外支出<br>✅ 核心医生聘任/解聘<br>❌ 日常诊疗运营 | 范围要精确，避免过度干预 |
| 董事长权限 | 召集董事会、在票数相同时有决定票 | 香港等地法律中董事长通常无决定票，需在章程明确 |
| 否决权期限 | 持续到资方收回全部投资本金+约定回报 | 之后可改成重大事项须2/3以上同意 |

### 谈判话术
> "不是不信任你们运营能力，是大资金的标配风控机制。一票否决不影响你们日常赚钱，只是保护资方不会因为越过了底线而血本无归。"

## 条款二：资金按里程碑分期释放

**这是最容易被忽略但最重要的条款。** 不要让品牌方一次拿到全部资金。

### 四期释放方案

| 阶段 | 释放比例 | 释放条件 | 资方控制节点 |
|:----:|:--------:|---------|:-----------:|
| 首期 | 30% | 门店选址签约+租赁合同完成 | 确认选址符合要求 |
| 二期 | 30% | 装修完成+设备到位+验收 | 确认硬件达标 |
| 三期 | 20% | 核心医生团队签约+诊所备案通过 | 确认人力+合规 |
| 四期 | 20% | 开业运营满6个月+月度经营数据 | 确认模式跑通 |

### 变体方案
- **更保守**：首期20%+二期30%+三期30%+四期20%
- **更激进**：首期40%+二期30%+三期30%（适合信任度高的品牌方）

### 核心价值
品牌方必须兑现每一个里程碑才能拿到下一笔钱。如果中途发现"选址不对""医生招不到""装修超预算"，资方可以直接止损退出，不会因为钱已经全部打过去而被迫追加。

## 条款三：优先清算权 + 回购权（保底机制）

### 优先清算权（1x Non-Participating）

```
触发场景：项目被收购/清算/破产
执行顺序：
  第1层：清偿员工工资+供应商欠款+税款
  第2层：资方收回全部投资本金（1x）
  第3层：剩余如有，双方按股权比例分配

变体：
  1x Participating：资方先拿回本金，再按比例参与剩余分配
  → 对资方更有利，但品牌方通常不接受
  推荐用 1x Non-Participating：公平且市场惯例
```

### 回购权（Redemption）

```
触发条件（满足任意一条）：
  • 开业后连续2年净利润为负
  • 核心医生团队离职超过协议约定人数
  • 发生重大医疗事故/诊所牌照被吊销
  • 品牌方创始人离职/违约
  • 连续2年门诊量 < 约定目标的70%

回购价格：投资本金 × (1 + 8-12%年化单利) - 已收到的分红
支付方式：3年内分期支付，首期不低于30%

注意：
  • 新公司法下有限责任公司回购有条件限制（不得损害债权人利益）
  • 可约定由品牌方母公司/创始人承担兜底回购义务
  • 或将回购权与品牌方提供的房产抵押/股权质押绑定
```

## 条款四：关键人锁定 + 竞业禁止

**品牌方的核心价值在于人**——品牌无非是团队积累的信任。如果核心团队跑了，资方只剩下租约和设备。

### 条款设计

| 约定 | 内容 |
|------|------|
| 关键人定义 | 品牌方创始人+运营负责人+首席医生（至少3人），须列出姓名 |
| 任职要求 | 全职为南宁项目服务，每月在岗不低于20天 |
| 锁定期限 | 自项目公司成立起不少于3年 |
| 离职触发 | 非正常离职（辞职/违约/被解聘有责）→ 触发回购 |
| 竞业范围 | 离职后2年内，不能在南宁+周边200km范围内从事同类型高端门诊业务 |
| 竞业赔偿 | 违反竞业 → 赔偿资方全部投资金额 + 没收从项目中获得的所有分红 |

### 谈判让步空间
- 竞业范围可缩小到"南宁+柳州+北海"（而非200km）
- 关键人锁定可缩短到2年
- 但基本锁定期至少2年是底线

## 条款五：财务透明权

| 信息类目 | 频率 | 内容 |
|---------|:----:|------|
| 经营数据 | **月度** | 门诊量、各科室收入、成本、现金流、患者满意度 |
| 财务报表 | **季度** | 利润表+资产负债表+现金流量表，附简要分析说明 |
| 独立审计 | **年度** | 第三方审计机构出具审计报告 |
| 关联交易 | **随时** | 超过1万元的关联交易须事先报备 |

### 账户与系统共管
- 项目公司银行账户实行**双人签字制**（资方1人+品牌方1人）
- 财务系统（金蝶/用友等）给资方**只读权限**，24小时可查
- 大额支出（>设定金额）须经双方指定人员共同确认

### 常见陷阱
- 品牌方用"商业机密"拒绝提供详细数据 → 在协议中约定"资方有权获取完整经营数据，不得以商业机密为由拒绝"
- 品牌方提供虚假数据 → 约定"数据造假视为重大违约，触发回购"

## 条款六：FA自身利益保障（用户专属）

你作为FA，不能光帮别人谈，自己也要收好报酬。

### 推荐费结构

```
【基础月费 — 现在就拿】
  ¥3,000-5,000/月 × 融资完成前
  由诺亚新舟支付
  话术："不收月费我无法全职推进你的项目，你没有风险"

【成功费 — 成交后拿】
  融资金额的3-5%（行业标准）
  由诺亚新舟支付
  注：约定"不管谁介绍的投资人，只要是与我的投资人清单有交集的人成交都算"

【排他条款】
  • 6个月独家FA委托协议
  • 此期间诺亚新舟不能找其他FA
  • 违反排他 → 按预计融资额×2%支付违约金

【月费抵扣】
  收到的月费总额 × 50% 抵扣成功费尾款
  → 降低品牌方月费负担感知
```

### FA委托协议关键条款

| 条款 | 建议内容 |
|------|---------|
| 服务范围 | 投资人筛选→商业计划书优化→路演安排→交易结构设计→条款谈判→交割跟进 |
| 排他期 | 6个月独家 |
| 月费 | ¥3,000-5,000/月 |
| 成功费率 | 融资金额的3-5% |
| 保护期 | FA退出后12个月内，品牌方不得与FA介绍的投资人直接成交而不支付费用 |
| 争议解决 | 仲裁优于诉讼（保密性强+周期短） |
| 付款条件 | 月费月结；成功费于交割后15个工作日内支付 |

## 谈判策略总表

| 条款 | 硬性底线（必须守住） | 可协商空间 | 让步条件 |
|:----:|:------------------:|:----------:|:--------:|
| 一票否决权 | 重大资产处置+对外担保+预算外支出 | 可限定金额门槛 | — |
| 分期释放 | 至少3期（不可一次到账） | 首期比例可微调（20-40%） | — |
| 优先清算 | 1x Non-Participating 保本 | 是否参与剩余分配 | — |
| 回购权 | 8%年化单利保底 | 触发条件可协商 | 可延长支付周期 |
| 关键人锁定 | 至少锁定2年 | 关键人名单可调整 | 竞业范围可缩小 |
| 财务透明 | 月度经营+季度财务+年度审计 | 具体报告格式可协商 | 签字人可调整 |
