# 投资备忘录自动生成引擎

> 属于 investment-finance umbrella（2026-07-16吸收自 standalone investment-memo skill）
> 
> 用途：输入公司/赛道/项目 → 联网获取最新数据 → 多维度结构化分析 → 输出专业级投资备忘录

## 执行流水线

### 第1步：信息收集（联网搜索）

**赛道层面：**
```
搜索指令：      "XX行业 市场规模 2025 2026"
              "XX行业 竞争格局 头部玩家"
              "XX行业 政策 监管 趋势"
搜索引擎：      search.js all (Bing/搜狗/360/百度)
降级方案：      web_search → Chrome CDP → 用户协助
```

**标的层面：**
```
搜索指令：      "XX公司 融资 估值"
              "XX公司 产品 商业模式"
              "XX公司 竞品 对比"
```

**财务层面（如适用）：**
```
搜索指令：      "XX公司 营收 利润 财报"
              "XX行业 毛利率 对标"
```

### 第2步：信息结构化
- 提取搜索结果中的关键数据点
- 标注每个数据的来源和采集时间
- 对冲突数据做交叉验证（至少2个独立来源）

### 第3步：分析框架应用

**赛道分析**
- 行业生命周期阶段（导入期/成长期/成熟期/衰退期）
- 波特五力分析
- 关键成功要素

**财务分析**
- 简单利润公式（收入-成本=利润）
- LTV/CAC估算（如适用）
- 对标公司估值倍数

**风险分析**
- 风险矩阵（5×5: 概率×影响）
- 最坏情况估算

### 第4步：庙算评估
调用 `li-yu-decision-engine`：
- 五行辨运 → 五事推演 → 七计对照 → 庙算总账
- 从儿格（土金为用）评分

### 第5步：输出报告
- 结构化Markdown文档
- 发布到飞书云文档（`publish_to_feishu.py`）
- 同步到IMA知识库（AI工作成果库）
- 可选：编译为PPT（多模型协同流水线）

## 判断校准机制

### 判断基调标注
每个Memorandum的「投资论点」和「估值区间」必须标注：
- **偏乐观**：数据支撑充分，主要风险可控
- **偏保守**：存在未确认的关键假设，下行风险显著
- **中立**：数据支持与风险因素基本平衡

### 事后追踪
- 将预测结果（估值/判断）记录到 #DecisionHistory
- 月度回顾偏差模式
- 识别系统性偏见（哪个赛道容易看走眼）
