## 一、Term Sheet（投资意向书）深度解构

### 1.1 TS 的本质与定位

Term Sheet 是投资人与企业之间达成的**非约束性投资意向书**（部分条款具有约束力），是投融资谈判的核心文件。TS 谈判往往决定了最终交易90%以上的关键商业条款。

**TS vs SPA 的关系：**
- TS → 商业条款 + 部分法律原则
- SPA → 法律条款 + 全部约束力
- 实务中，TS 谈崩 = 交易失败；SPA 修改范围通常不超过TS的10-15%

### 1.2 TS 完整条款体系（2026版）

#### A. 经济条款（占谈判焦点的70%）

| 条款 | 内容 | 市场标准（2026） | FA视角 |
|------|------|-----------------|--------|
| 估值 | 投前/投后估值 | AI: P/S 5-10x; SaaS: P/S 8-15x | 多方法交叉验证，避免单一方法 |
| 投资额 | 本轮融资金额 | 混合融资结构（可转债+股权）占主流 | 建议分阶段到账 |
| 清算优先权 | Liquidation Preference | 1x非参与优先为市场标准 | 2x+参与为红旗条款 |
| 反稀释 | 估值调整保护 | 广义加权平均为市场标准 | 完全棘轮为红旗 |
| 股息权 | 累计/非累计 | 非累计优先为主流 | 非上市企业罕见 |
| 转换权 | 优先股转普通股 | IPO或特定事件自动转换 | 关注触发条件 |
| 赎回权 | 投资人要求回购 | 5-7年，清偿顺序 | 关注回购责任主体 |

#### B. 治理条款（占谈判焦点的20%）

| 条款 | 标准做法 | 风险信号 |
|------|---------|---------|
| 董事会席位 | 投资人≤1/3 | 投资人占多数 = 控制权丧失 |
| 保护条款 | 清单明确（增发/并购/重大资产处置） | 定义过宽的保护范围 |
| 信息权 | 季度财报+年度审计 | 要求月度财报 = 过度干预 |
| 检查权/视察权 | 合理通知+正常工作时间 | 无限制检查 = 红旗 |
| 优先购买权 | 按比例参与后续融资 | 需关注是否包含反摊薄强化 |
| 共同出售权(Tag-along) | 与主要股东同步退出 | 适用范围需明确 |
| 领售权(Drag-along) | 50-75%投资人同意可强制出售 | 触发门槛过低 = 风险 |

#### C. 2026年新增条款（ESG/AI合规）

| 条款 | 内容 | 适用场景 |
|------|------|---------|
| ESG承诺条款 | 碳足迹报告、多元化目标 | 机构LP要求，欧洲基金标配 |
| AI透明度条款 | 算法可解释性、偏见检测 | AI/科技企业必谈 |
| 数据合规条款 | 数据来源、处理、安全审计 | 所有数字企业 |
| 技术对赌 | 以技术里程碑替代财务对赌 | 硬科技/生物医药 |

### 1.3 TS 谈判全过程时间线

```
Day 1-7   投资人发出TS → 创始团队初步评估
Day 8-14  TS条款内部讨论（FA主导红线分析）
Day 15-21 正式谈判（2-3轮会议）
Day 22-28 签署TS → 进入排他期（通常30-60天）
Day 29-60 尽调 + SPA起草并行
Day 61-75 交割
```

**FA核心职责：**
1. 在TS阶段识别所有红旗条款
2. 帮助创始人理解每条经济含义
3. 提前模拟SPA阶段的争议点
4. 控制谈判节奏，避免过早进入排他期

## 二、LPA（有限合伙协议）深度分析

### 2.1 LPA 核心结构

LPA 是投资基金层面最重要的法律文件，GP与LP之间的"宪法"。

```
┌─────────────────────────────────────┐
│           LPA 核心架构               │
├─────────────────────────────────────┤
│ 第一层：基金基本参数                  │
│  - 基金规模、存续期、投资期           │
│  - GP出资比例、管理费                 │
├─────────────────────────────────────┤
│ 第二层：经济利益分配                  │
│  - Waterfall（瀑布分配结构）          │
│  - Carry（收益分成）                 │
│  - Hurdle Rate（门槛收益率）         │
├─────────────────────────────────────┤
│ 第三层：治理机制                     │
│  - 投委会/咨委会                     │
│  - LP同意权范围                      │
│  - 关键人条款                        │
├─────────────────────────────────────┤
│ 第四层：合规与披露                   │
│  - 报告义务、审计要求                │
│  - ESG披露要求（2026重点）           │
│  - 利益冲突管理                      │
└─────────────────────────────────────┘
```

### 2.2 LPA 核心条款详解

#### 出资条款
| 要素 | 标准做法 | 风险信号 |
|------|---------|---------|
| Capital Call | 提前10-15个工作日通知 | 临时通知=现金流风险 |
| 违约处罚 | 利息12-15%/年+稀释 | 处罚过高=LP保护需加强 |
| Clawback | GP返还超额Carry | 需明确计算方式 |

#### 收益分配（Waterfall）

**American Waterfall（按项目分配 - 美股市场主流）：**
```
Step 1: 100% → LP（返还该项目投资本金）
Step 2: 100% → LP（优先回报，通常8%年化）
Step 3: 100% → GP（Catch-up至Carry比例20%）
Step 4: 80% → LP / 20% → GP
```

**European Waterfall（按基金整体分配 - 欧洲市场）：**
```
Step 1: 100% → LP（返还全部投资本金）
Step 2: 100% → LP（优先回报，8%年化）
Step 3: 100% → GP（Catch-up）
Step 4: 80% → LP / 20% → GP
```

**关键差异：** European Waterfall 对LP更有利（先返还全部本金后再分配），American Waterfall对GP更有利（单个项目退出即可分配）。

#### 2026年LPA新趋势
1. **ESG条款入LPA** — LP要求基金层面碳足迹报告、排除清单
2. **GP出资比例上升** — 从1%升至2-5%，GP利益绑定更深
3. **Carry结构创新** — 分级Carry（IRR越高，GP分成比例越高）
4. **Side Letter标准化** — 大型LP单独约定条款的普及
5. **S基金交易条款** — 基金份额转让流程标准化

## 三、投资协议（SPA/SSA）实务要点

### 3.1 投资协议类型

| 类型 | 全称 | 适用场景 |
|------|------|---------|
| SPA | Share Purchase Agreement | 股权收购（买老股） |
| SSA | Subscription & Shareholders' Agreement | 认购新股+股东协议 |
| SHA | Shareholders' Agreement | 股东权利义务（常与SSA合并） |
| SIA | Subscription & Investment Agreement | 跨境投资常用 |

### 3.2 SPA核心条款结构

```
┌──────────────────────────────────────┐
│            SPA 核心结构               │
├──────────────────────────────────────┤
│ 第一编：交易本身                      │
│  - 购买与出售、对价、交割             │
│  - 交割条件（先决条件清单）            │
├──────────────────────────────────────┤
│ 第二编：陈述与保证                    │
│  - 公司陈述（业务/财务/法律/IP）      │
│  - 投资人陈述（合格投资者/资金来源）    │
│  - 2026新增：AI/数据合规陈述          │
├──────────────────────────────────────┤
│ 第三编：交割前承诺                    │
│  - 经营正常进行、无重大变化            │
│  - 信息披露义务                      │
├──────────────────────────────────────┤
│ 第四编：交割后承诺                    │
│  - 业绩承诺、合规维持                 │
│  - 信息报送（季度/年度）              │
├──────────────────────────────────────┤
│ 第五编：赔偿与终止                    │
│  - 陈述保证违约赔偿                  │
│  - 赔偿上限、追索期限                 │
│  - 终止条款                          │
└──────────────────────────────────────┘
```

### 3.3 2026年SPA审查新增要点

#### AI/科技企业特有条款
1. **IP权属条款**
   - 明确区分"职务发明"和"个人开发"
   - 开源代码使用合规性声明
   - 训练数据来源合法性保证
   - 模型权重归属（重大争议点）

2. **数据合规条款**
   - 个人信息处理合规（个保法/GDPR）
   - 数据跨境传输合规
   - 算法备案完成情况
   - 生成式AI内容标识合规

3. **技术对赌条款**
   - 以技术里程碑替代纯财务对赌
   - 明确可量化的技术指标
   - 技术失败时的退出安排

## 四、实务案例：AI企业B轮Term Sheet谈判全流程

### 背景
- **企业**：某AI Agent开发平台，成立于2023年
- **轮次**：B轮融资，目标¥8000万
- **投资人**：知名美元基金（领投）+ 一家产业资本（跟投）
- **阶段**：ARR ¥1500万，NRR 120%，GMV ¥5000万
- **FA角色**：用户（本工具）担任卖方FA

### TS条款谈判过程

#### 第一轮投资人TS草案（初始报价）

| 条款 | 投资人初始提案 | FA评估 |
|------|--------------|--------|
| 投前估值 | ¥3亿 | 偏低（对标P/S 20x=¥3亿，但增速支持更高） |
| 投资额 | ¥8000万 | 合理 |
| 清算优先权 | 1.5x参与优先 | 🚩 红旗，远高于市场标准 |
| 反稀释 | 广义加权平均 | ✅ 可接受 |
| 董事会 | 3席：创始2+投资人1 | ✅ 合理 |
| 保护条款 | 10项重大事项需投资人同意 | 🚩 过多，应缩减至7项 |
| 对赌 | 2027年ARR≥¥5000万 | 偏激进但可谈 |
| 排他期 | 90天 | 🚩 过长，标准30-60天 |

#### FA应对策略

**Step 1 — 估值谈判**
- 提出对标法：可比公司P/S 25-35x，建议投前估值¥3.5-4亿
- 用行业基准数据支撑（同类AI Agent平台B轮P/S中位数28x）
- 折中方案：投前¥3.5亿，附业绩对赌加速

**Step 2 — 清算优先权**
- 强烈反对1.5x参与优先（同时拿优先回报+参与分配）
- 提出替代方案：1x非参与优先（市场标准）
- 最终让步：1x非参与优先 + 年化8%累计股息

**Step 3 — 对赌条款修改**
- 将单一ARR对赌改为"收入+NDR+新客户"三指标组合
- 设置阶梯式对赌（达标90%/100%/110%对应不同估值调整）
- 删除个人连带担保

#### 最终TS条款（谈判后）

| 条款 | 最终协议 | 谈判成果 |
|------|---------|---------|
| 投前估值 | ¥3.5亿 | 比初始提升16.7% |
| 清算优先权 | 1x非参与优先 | 从红旗降至市场标准 |
| 反稀释 | 广义加权平均 | ✅ 不变 |
| 董事会 | 创始2+投资人1 | ✅ 不变 |
| 保护条款 | 缩减至7项 | 删除3项过度条款 |
| 对赌 | 三指标组合，阶梯式 | 更合理、风险更低 |
| 排他期 | 45天 | 从90天降至45天 |
| 创始人个人担保 | 无 | ✅ 完全删除 |

### 关键洞察
1. **FA最大的价值在TS阶段** — 80%的条款核心争议在TS阶段解决
2. **清算优先权是最高频的红旗条款** — 1x非参与为底线
3. **估值谈判要用行业数据说话** — 纯感情谈判效率最低
4. **对赌条款要"组合化"** — 单一指标对赌风险过高
5. **排他期是FA的保护期** — 过长排他期绑定企业不利

## 五、风险控制三层面

### 第一层：TS阶段风险识别

| 红旗条款 | 严重程度 | 替代方案 |
|---------|---------|---------|
| 完全棘轮反稀释 | 🔴 极高 | 广义加权平均 |
| 2x+参与优先清算 | 🔴 极高 | 1x非参与优先 |
| 无上限创始人个人担保 | 🔴 极高 | 限定50%或删除 |
| 无限期不竞争条款 | 🟡 中 | 限定1-2年 |
| 定义过宽"重大不利变化" | 🟡 中 | 列举具体事件 |
| 月度财报要求 | 🟢 低 | 季度财报+年度审计 |

### 第二层：尽调阶段风险排查

| 风险类型 | 排查重点 | 常见发现 |
|---------|---------|---------|
| 财务风险 | 关联交易、收入确认 | 提前/跨期确认收入 |
| 法律风险 | 股权清晰、IP归属 | 核心IP在个人名下 |
| 业务风险 | 客户集中度、续约率 | 前3客户占60%+收入 |
| 技术风险 | 代码合规、数据合规 | 使用了GPL代码未处理 |
| 团队风险 | 创始团队稳定性 | 联合创始人缺少股权绑定 |

### 第三层：交割后监测

| 监测项 | 周期 | 阈值 |
|-------|------|------|
| 现金流 | 月度 | 低于3个月运营成本=警示 |
| 营收/ARR | 月度 | 偏离预测>15%=触发检查 |
| NRR | 季度 | <100%=增长质量下降 |
| 关键人员 | 持续 | CTO/CTO离职=重大事件 |
| 合规状态 | 季度 | 新法规出台=评估影响 |

## 六、FA实战技巧

### 6.1 文件审查技巧

**Term Sheet "五看法"**
1. **看估值逻辑** — 是否有多方法支撑，还是单一拍脑袋值
2. **看清算优先级** — 参与/非参与，倍数
3. **看控制权条款** — 董事会+保护条款是否平衡
4. **看退出路径** — 回购触发条件+Drag-along门槛
5. **看对赌合理性** — 是否与商业计划书一致，是否有数据支撑

**SPA "五查法"**
1. **查定义** — 关键术语定义是否过宽/过窄
2. **查陈述** — 公司陈述保证是否过于绝对
3. **查赔偿** — 赔偿上限、追索期限、第三方索赔流程
4. **查交割** — 先决条件清单是否可执行
5. **查附录** — 附表/附件是否完整，交叉引用是否一致

### 6.2 谈判策略

**价格谈判（估值/投资额）**
- 开局先要高20-30%（留足让步空间）
- 退出时提到"其他投资人"（制造竞争假象）
- 确有用，但过度使用会损伤信任

**条款谈判（非价格条款）**
- 低价+宽松条款 > 高价+严苛条款
- 优先争取"生存攸关"条款（清算优先、反稀释、控制权）
- 次要条款可让步换取主要条款优势

**僵局处理三原则**
1. **利益重新定位** — "不是拒绝，是寻找更好的方案"
2. **条款创新** — 引入ESG/KPI挂钩等新机制
3. **外部力量** — 引入第三方专家/行业对标

### 6.3 2026年FA增值服务方向

| 服务类型 | 内容 | 收费标准 |
|---------|------|---------|
| TS条款审查 | 全条款逐条审查+红旗预警 | ¥3-5万/次 |
| 对赌设计 | 对赌目标行业对标+阶梯式设计 | ¥5-8万/次 |
| SPA审查 | 法律条款+商业条款双重审查 | ¥5-10万/次 |
| LPA评估 | LP视角的LPA风险评估 | ¥8-15万/次 |
| 交割支持 | 交割条件跟踪+风险预警 | 按项目规模0.3-0.5% |

### 知识卡片2：Waterfall速算

**American Waterfall 示例（项目退出¥100万，投资本金¥30万）：**
```
Step 1: LP收回本金 ¥30万 → 剩余¥70万
Step 2: LP获得优先回报 ¥30万×8%×2年=¥4.8万 → 剩余¥65.2万
Step 3: GP Catch-up 至20% = ¥65.2万×20% = ¥13.04万 → 剩余¥52.16万
Step 4: LP 80% = ¥41.73万 / GP 20% = ¥10.43万

LP总计：¥30+4.8+41.73=¥76.53万
GP总计：¥13.04+10.43=¥23.47万
```
