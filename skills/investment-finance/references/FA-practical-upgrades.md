## 一、新公司法对融资流程的实操影响（2026Q2已验证案例）

### 1.1 出资加速到期风险

| 影响环节 | 问题 | FA/创始人应对 |
|---------|------|-------------|
| 投前估值 | 股东未实缴→需定向减资→估值下调 | 融资前完成实缴或减资，避免交易延迟 |
| 条款谈判 | 出资加速到期条款写入SPA | 创始人争取"出资豁免条款"保护 |
| 交割条件 | 工商变更需先完成出资合规 | 预留1-2个月合规缓冲期 |

**案例**：某AI芯片公司B轮融资因股东未实缴出资，被迫定向减资后再引入投资人，交易延迟2个月，估值下降约15%。

### 1.2 类别股（优先股/AB股）入法

截至2026Q2的实操现状：
- ✅ 新公司法已纳入类别股条款
- ⚠️ 工商登记系统尚未完全对接，仅少数案例成功登记AB股
- 📋 科创板拟上市企业优先采用类别股安排
- 💡 **FA建议**：TS中预留类别股转换条款，待登记指引完善后执行

### 1.3 横向法人人格否认

2026Q1出现首例横向人格否认案，三混同标准确立（人员/业务/财务）：
- 尽调中增加关联交易审查
- FA建议创业公司提前做业务切割
- 避免"一套人马多块牌子"的风险

## 二、FA实战升级

### 2.1 "量减价升"市场下的FA报价策略

| 项目类型 | 推荐费率 | 收费结构 | 适用场景 |
|---------|:-------:|---------|---------|
| 热门赛道（AI/具身智能） | 3-4% | 低基础费+高成功费 | 竞争激烈，快速成交 |
| 传统赛道（消费/制造） | 4-6% | 高基础费+里程碑付费 | 周期长，需持续服务 |
| 跨境交易（含中东资本） | 3-5%+架构费 | 成功费+架构咨询费 | 复杂度高 |
| 早期/天使轮 | 5-8% | 股权+现金混合支付 | 高风险，需长期绑定 |

### 2.3 创始人融资前自查清单（FA内训版）

```
⚠️ 新公司法专项自查：
□ 股东出资是否全部实缴？（不足5年需规划减资或补充）
□ 章程是否已按新公司法修改？（审计委员会/类别股条款）
□ 关联公司是否存在横向混同风险？
□ 是否设类别股（AB股/优先股）需求？

📊 商业基础自查：
□ BP是否清晰说明"如何赚钱"（单位经济模型）？
□ 是否有一票否决信号？（首条：团队只有一个人）
□ TAM是否大于1亿元？
□ 估值是否在同类合理范围内（±20%）？

📋 材料准备自查：
□ 数据室是否结构化？
□ 财务预测是否有情景分析？
□ 是否有创始人个人信用/诉讼记录？
□ 是否有竞业限制纠纷风险？
```

## 四、AI应用层融资案例模板（2026Q2）

以某AI Agent垂直应用公司A轮融资为参考基准：

| 维度 | 参考数据 |
|------|---------|
| 公司类型 | AI Agent垂直行业应用 |
| 融资轮次 | A轮 |
| 融资金额 | 8000万人民币 |
| 投前/投后估值 | 4亿/4.8亿人民币 |
| 投资方构成 | 产业资本CVC + 知名VC + 中东主权基金(QFLP) |
| 交易周期 | 5个月（含新公司法合规调整1个月） |
| 创始人出让 | ~16.7%（含期权池8%） |
| 核心条款 | 1x非参与优先清算权 + 加权平均反稀释 |

**尽调六大发现**（按严重程度排序）：
1. 🔴 数据合规（AI训练数据版权）→ 引入律所出具意见书
2. 🟡 团队竞业限制 → 原单位出具豁免函
3. 🟡 股东出资未实缴 → 出资承诺函+SPA加速到期触发条件
4. 🟢 客户集中度（前3占70%）→ 对赌条款含12月内多元化
5. 🟢 知识产权归属（外包代码）→ 补签归属协议
6. 🟢 关联交易 → 签署框架协议
