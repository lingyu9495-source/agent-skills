# 中国企业财务报表快速分析方法

> 实战指南：30分钟内从三张表+附注提取核心判断
> 基于广西昌弘制药有限公司尽调实战（2026-07-17）

## 一、拿到报表后的第一件事

不要逐行读表。先做三件事：
① 看审计意见 → 保留意见/无法表示意见 → 直接亮红灯
② 看净利润 → 正/负、绝对值、同比变化 → 判断经营基本面
③ 看资产负债率 → 总负债/总资产 → 判断财务风险高低

## 二、五步快速分析法

### Step 1: 利润表
- 毛利率(收入-成本)/收入 → >40%有定价权
- 净利率净利润/收入 → >10%优秀
- 收入趋势同比环比 → 增长>20%高增长

### Step 2: 资产负债表
资产端：货币资金越多越好，应收越高风险越大
负债端：总负债率<50%安全，>70%高风险

### Step 3: 现金流量表
黄金组合：经营正+投资负+筹资负=优秀
危险组合：经营负+筹资正=靠借钱活着

### Step 4: 附注
应收账龄(1年内>80%正常)、其他应收前五名(个人借支？)、研发资本化vs费用化

### Step 5: 交叉验证
第三方报告 vs 财务报表 vs 银行流水 → 三合一验证

## 三、风险评级表
🟢净利正+负债<50%+现金流正 → 可深度尽调
🟡净利正但应收高/负债50-70% → 需补充尽调
🔴亏损/负债>70%/经营现金流负 → 谨慎或放弃
⚫资不抵债/无法表示意见 → 直接放弃

## 四、30分钟节奏
0-5min概览 → 5-10min利润表 → 10-15min资产负债表 → 15-20min现金流+附注 → 20-25min行业关注 → 25-30min交叉验证
