## 常见产业项目估值陷阱

1. **增长率外推陷阱**：过去3年50%增长 ≠ 未来5年50%增长（市场天花板、竞争加剧）
2. **利润率假设陷阱**：没有考虑规模不经济（管理复杂度增加、边际成本上升）
3. **Capex低估陷阱**：产业项目往往需要持续大规模资本投入（设备维护/升级/扩产）
4. **营运资本陷阱**：高增长通常伴随高营运资本需求（库存、应收账款）
5. **退出倍数陷阱**：用当前市场高点倍数预测退出（均值回归是常态）
6. **汇率/政策风险**：跨境项目需考虑汇率波动和政策变化
7. **技术路线风险**：产业技术更迭可能导致现有资产减值

## 快速行业研究清单

评估一个产业项目时，必须回答以下问题：

- [ ] 行业处于生命周期的哪个阶段？
- [ ] 过去3年和未来5年的CAGR分别是多少？
- [ ] 主要驱动因素是什么（政策/技术/需求/供给）？
- [ ] 前5大企业市占率合计多少？（CR5）
- [ ] 行业平均毛利率和净利率是多少？
- [ ] 进入壁垒有哪些（资金/技术/牌照/客户关系）？
- [ ] 有哪些替代品威胁？
- [ ] 上游供应商集中度如何？
- [ ] 下游客户集中度如何？
- [ ] 政策风险（税收优惠变化/环保要求/贸易壁垒）？
- [ ] 技术S曲线位置？下一代技术何时到来？
- [ ] 是否有季节性/周期性特征？
- [ ] 行业Benchmark估值倍数（P/E, EV/EBITDA, P/S）？
- [ ] 近3年有哪些IPO/并购退出案例？估值水平如何？
