# PE/VC基金运作指南

> 合并自：pe-fund-operations

## 基金架构
GP（普通合伙人，1%出资+无限责任+管理决策权）
LP（有限合伙人，99%出资+有限责任）

## LPA核心条款
- 管理费：2%/年
- Carry：20%
- Hurdle Rate：8%
- 基金期限：10年（投资期3-5+回收期5-7）

## 收益分配(Waterfall)
### American（逐笔分配）
1. 100%→LP（返还本金）
2. 100%→LP（优先回报）
3. 100%→GP（Catch-up至20%）
4. 80%→LP / 20%→GP

## 核心绩效指标
- DPI（已分配/已投入）：>1.5x
- TVPI（总回报/已投入）：>2.0x
- IRR：>20%
- MOIC：>3.0x

## S基金交易
- NAV百分比法（70-90%）
- DCF法
- 可比交易法
