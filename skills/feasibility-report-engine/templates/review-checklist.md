# 报告审查清单（P3 阶段产出）

> 用法：**初稿完成后单独走一轮**，不要边写边审。逐条打勾，发现的问题记在"修正记录"里。
> 原则：宁可晚交，不能错交。

## 第一关：反思（回顾研究过程）

- [ ] **数据完整**：该找的信息源都找了吗？有没有明显的遗漏方向？
- [ ] **来源可靠**：一手还是二手？关键数字能否回到原始出处？引用有没有失真？
- [ ] **逻辑无跳跃**：从证据到结论中间有没有"想当然"的一步？
- [ ] **范围一致**：写的范围和约定的范围一致吗？有没有悄悄扩大或缩小？

## 第二关：审查（逐项核对）

### 结论与证据
- [ ] 每个结论都有证据支撑，不是"感觉上应该是"
- [ ] 证据强度与结论强度匹配（弱证据不写成强结论）
- [ ] 没有把相关性当因果、把局部当整体、把个例当规律

### 反方视角
- [ ] 风险 / 局限 / 反方观点有专门段落
- [ ] 反面证据被正面回应，而不是回避
- [ ] 没有只挑对结论有利的数据（幸存者偏差）

### 准确性
- [ ] 数字、名称、日期、法规条文逐条核对过
- [ ] 同一件事全文口径统一（前后数字不打架）
- [ ] 单位、币种、口径（含税/不含税、口径时点）标注清楚

### 诚实性
- [ ] 不确定的地方如实标注（待核实 / 估计 / 假设）
- [ ] 没有把推测写成事实
- [ ] 没有为了好看而删掉不利信息

## 第三关：修正与复查

- [ ] 发现的问题已全部修正
- [ ] **修正处再扫一遍**（重点看改动是否引入新的不一致）
- [ ] 全文术语统一（同一概念一个叫法）
- [ ] 目录 / 页码 / 图表编号与正文对得上
