# 财务测算口径与勾稽检查

## 一、投资估算构成（第一原则：不重不漏）

```
项目总投资 = 建设投资 + 建设期利息 + 铺底流动资金
    建设投资 = 工程费用 + 设备购置费 + 安装工程费 + 工程建设其他费用 + 预备费
    建设期利息 = 贷款额 × 年利率 × (建设期/2 + 0.5)     ← 建设期均匀提款的近似
    铺底流动资金 = 流动资金 × 铺底比例（通常 30%）
```

⚠️ **最常见口径错误**：先按"建设投资占比 95%"算出建设投资，再把建设期利息与铺底流动资金加上去，
总投资被重复计算、校验位不为 0，评审一眼看出。

✅ 正确做法：**建设投资 = 总投资 − 建设期利息 − 铺底流动资金**（反向推导）。
配套套表 `2_投资估算` 已按此实现，`校验位` 恒为 0。

## 二、资金筹措

- 项目资本金比例：制度要求通常 **20%–30%**（按行业与项目性质确定，政府投资项目资本金比例另有规定）
- 债务融资：银行贷款／债券／其他；综合融资成本按 LPR + 点差估算
- **资金合计必须 = 总投资，资金缺口为 0**

## 三、收入成本现金流模型（套表第 3 表逐年推进）

```
投产标记(0建/1产) → 达产率 → 营业收入 → 可变经营成本 → 固定成本
→ 折旧费 → 利息费用 → 增值税及附加 → 所得税 → 净利润 → 净现金流
```

- **全投资净现金流 = 净利润 + 折旧 + 利息**（利息加回，剔除融资方式影响，用于算全投资 IRR）
- **资本金净现金流 = 净利润 + 折旧 − 当年还本**（股东视角）
- 建设期年份：全投资口径流出 `−总投资/建设期`；资本金口径流出 `−总投资×资本金比例/建设期`

## 四、指标判据

| 指标 | 计算口径 | 判据 |
|---|---|---|
| 全投资财务内部收益率 IRR | IRR(全投资净现金流) | ≥ 基准收益率 ic（产业类 8–10%，基础设施 6–7%） |
| 全投资财务净现值 NPV | NPV(ic, 现金流) | > 0 |
| 资本金财务内部收益率 | IRR(资本金净现金流) | 高于股东要求回报 |
| 静态投资回收期 | 累计净现金流转正时点插值 | 一般不超过项目寿命期的 2/3 |
| 利息备付率 | EBIT / 应付利息 | ≥ 2（银行通常要求） |
| 偿债备付率 | (EBITDA − 所得税) / 应还本付息 | ≥ 1.3 |
| 资产负债率 | 负债总额 / 资产总额 | 行业合理区间 |

## 五、四表勾稽检查表（交付前逐项跑一遍）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 建设投资 + 建设期利息 + 铺底流动资金 = 总投资 | 差值为 0 |
| 2 | 资本金 + 债务融资 = 总投资 | 缺口为 0 |
| 3 | 逐年收入 ≈ 达产年收入 × 当年达产率 | 逐项核对 |
| 4 | 折旧 = 计提基数 × (1 − 残值率) / 折旧年限 | 运营期逐年恒定 |
| 5 | 财务指标由现金流公式算出（非手填数值） | 改参数后指标跟着变 |
| 6 | 报告正文数字与套表输出一致 | 逐项比对，不凭记忆 |

## 六、口径坑（实战踩过）

1. **含税/不含税混用**：收入按不含税计，则成本、费用口径必须同口径；增值税单独列示
2. **分期口径**：一期/二期分开测算时，IRR 必须标口径（"一期 300 亿元投资口径"），不能混算
3. **建设期利息重复计入建设投资**（见第一节）
4. **增值税附加基数**：城建税及教育附加按**增值税额**计提，不是销售额
5. **达产率爬坡**：第 1 年即满产会让 IRR 虚高；爬坡曲线要贴合行业实际
6. **敏感性情景与基准情景必须同口径**，否则不可比
7. **铺底流动资金 vs 全额流动资金**：可研阶段用铺底口径，报批阶段按全额流动资金复核

## 七、敏感性分析

三情景（悲观／基准／乐观）+ 关键变量（收入、经营成本、投资额、利率）±10% 网格。
目标不是给出精确值，而是**找出使 IRR 跌破基准收益率的临界点**，写入风险章作为管控依据。

## 八、测算周期约束

测算期 = 建设期 + 运营期 ≤ 20 年（套表年份列固定 20 年）。需要更长时，在表尾复制公式扩列；
运营期一般按 10–20 年取值，与主要设备经济寿命匹配。
