# 房地产项目投资测算

> 用户专属：用户提供基础参数，分析助手自动完成全套投资测算。

## 触发场景
- 用户说"测算一下XX项目"、"帮我算算这个地值不值"、"投资测算"
- 需要做：规划指标测算→销售计划→成本测算→税金→现金流→利润→敏感性分析

## 碧桂园测算表完整结构（25个Sheet）

### 核心流程
```
编制说明 → 总表 → 规划指标 → 销售计划/户型配比 → 总成本
→ 土增税 → 增值税 → 现金流 → 成就共享 → 利润表
→ 分业态综合成本 → 敏感性分析(地价/售价/成本) → 异常提示
```

### 关键Sheet说明
| Sheet | 作用 | 关键输入 |
|:------|:-----|:---------|
| 编制说明（必读） | 填表指引 | 按说明填 |
| 总表 | 项目总览 | 项目名、日期、我司权益比例 |
| 规划指标 | 地块参数 | 用地面积、容积率、计容面积、业态配比 |
| 销售计划 | 货值测算 | 各业态售价、去化节奏、销售比例 |
| 营销户型配比 | 户型结构 | 户型套数、面积、单价 |
| 总成本 | 成本汇总 | 土地款、建安成本、配套、管理费、营销费、财务费 |
| 土增税 | 税负测算 | 土增税率、土地溢价、公配分摊 |
| 增值税 | 销项进项 | 税率、物料采购比例 |
| 现金流 | 资金计划 | 付款节奏、回款节奏、融资 |
| 成就共享-首年/周期 | 碧桂园激励 | 首年回款、周期利润 |
| 利润表 | 损益测算 | 收入-成本-税金 |
| 分业态综合成本 | 业态成本 | 各业态单方成本 |
| 敏感性分析 | 风险测试 | 地价±%/售价±%/成本±% |
| 异常提示 | 校验 | 自动检查逻辑错误 |

### 测算核心公式
```
货值 = Σ(各业态面积 × 售价)
总成本 = 土地成本 + 建安成本 + 配套费 + 管理费 + 营销费 + 财务费 + 税金
增值税 = (销项税 - 进项税) 按税率计算
土增税 = 增值额 × 适用税率 - 速算扣除数
利润总额 = 收入 - 总成本 - 税金及附加
净利润 = 利润总额 - 所得税(25%)
IRR = 现金流折现后内部收益率
销售净利率 = 净利润 / 销售收入
```

## 需要用户提供的基础参数清单

### 一、地块参数（必填）
- 项目名称、城市、区域
- 用地面积（亩/㎡）
- 容积率、计容建筑面积
- 业态构成（住宅/商业/办公/车位/自持）
- 各业态面积或配比

### 二、销售参数（必填）
- 各业态销售单价（住宅/公寓/商铺/车位）
- 车位数量及售价
- 销售节奏（年度去化比例）
- 自持/出售比例

### 三、成本参数（必填）
- 土地取得成本（楼面价或总价）
- 建安成本单方（按业态）
- 配套费用（市政/教育/公建）
- 管理费率、营销费率
- 财务费用（融资利率/周期）
- 物料采购比例（进项税抵扣）

### 四、财务参数
- 我司权益比例
- 合作方出资方式（股权/土地作价）
- 融资方案（贷款额、利率、期限）
- 税率（增值税率/土增税率/所得税25%）

### 五、其他
- 是否有溢价合作/小股操盘模式
- 合作方是否参与成就共享
- 特殊成本（如旧改、拆迁）

## 输出报表
1. 总表：项目投资总览（货值/成本/利润/IRR/净利率）
2. 利润表：完整损益
3. 现金流表：年度资金计划
4. 敏感性分析：地价/售价/成本变动对IRR、净利率的影响
5. 结论建议：项目是否可投、关键风险、优化建议

## 注意事项
- 参数不全时，先列出缺失项问用户，不瞎猜
- 税率按最新政策（增值税9%/土增税四级超率累进/所得税25%）
- 结果为决策参考，重大投资需结合尽调
