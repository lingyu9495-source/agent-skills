# 强制弹药装载（通用版 v1）

> 老板钦定 2026-09-09：知识库/技能库建了一堆，智能体动手时却常"从零开始"——沉淀没被调用=死资产。
> 本skill强制：**任何实质任务动手前，必须扫描并装载≥1项相关沉淀（技能/知识/经验），并在产出中实际用上。**
> 原型：小说域"弹药装载机制"（gen_ammo.py）——现抽为全领域通用铁律，供团队所有智能体安装（助手/助手/开发/方案…）。

## 一、触发条件
- 一切非闲聊的实质任务：写小说/剧本/文案、软件开发、数据分析、方案报告、尽调、设计、运营、文档……
- 只要任务有"产出物"，就必须过本流程
- 纯闲聊/查时间/一句问答不触发

## 二、强制三步（缺一不可，违反=不合格交付）

### 第一步 弹药扫描（先扫再想，禁止直接动手）
1. `skills_list` 扫全部可用技能，按名称/描述找出与本任务相关的候选
2. 扫本任务的"弹药源"：
   - 项目目录内的 素材/、参考/、历史经验/、坑文档/、评审报告/
   - Obsidian知识库中本领域沉淀（团队记忆/工作成果）
   - 记忆 memory 中相关经验条目（模型坑/流程坑/老板偏好）
   - 历史同类任务产物（上次同类任务怎么做的、结论是什么）
3. 2分钟内列候选清单（别陷进扫描里出不来）

### 第二步 弹药装载（必须选≥1并加载内容）
- 从候选选最相关的1-3项并**真加载**：
  - 技能 → `skill_view(name)` 读全文
  - 知识文件 → `read_file` 读关键节；有弹药装载器的域调它（小说域：`gen_ammo.py ammo_for()`；其他域自建同型装载器）
  - 经验文档 → 重点读"教训/红线/规范/踩坑"部分
- **没有加载任何沉淀就开工 = 违规**（等于不体检上手术台）
- 若该域确实无沉淀 → 记录"弹药空白"，任务完成后补沉淀（见四）

### 第三步 应用与自证（用到产出里，交付时说明）
- 把装载的弹药实际织进产出，至少1处可指认：
  - 写作 → 时代细节/母题配额/结构手法/人物弧光 至少1处来自装载素材
  - 编程 → 复用团队规范/规避已知坑/采用沉淀的架构与命令
  - 方案/报告 → 引用历史案例数据/已知红线/领域框架
- 交付时说明一句："本任务应用了{技能/知识名}：用在了{具体哪里}"
- 自查三问：
  - [ ] 我装载了哪项沉淀？（叫得出名字）
  - [ ] 它用在了产出的哪个部分？（指得出来才算数）
  - [ ] 若没用上——这任务真没有相关沉淀，还是我没扫到？（没扫到=回去扫）

## 三、弹药源地图（通用模板，各域按表自填）
| 任务域 | 弹药源示例 |
|---|---|
| 网文/剧本 | 写作技能群(novel-session-pipeline/novel-writing/humanizer等)、项目素材库(历史尽调/拆书库)、gen_ammo.py、母题配额表、病变总表 |

| 设计/内容 | 设计系统、风格参考、竞品拆解、平台规则(番茄/公众号/抖音) |

## 四、沉淀闭环（干完活弹药回仓，越用越厚）
- 任务中**新学到的/踩的坑/有效手法** → 更新对应skill（skill_manage patch）或追加项目经验文件
- 本次若是"弹药空白"域 → 任务结束后补建最小弹药包（先把这次的经验写成参考）
- 沉淀原则：错误教训写成"下次别…"式规则，成功手法写成可复用步骤，都进对应skill而非只留会话

## 五、团队安装与检查
1. 安装：把本skill（SKILL.md）拷进目标智能体的 skills/ 目录（各profile的skills/下）
2. 装完第一个实质任务前，先跑一遍"弹药扫描"熟悉本域弹药源在哪
3. 团队统一汇报格式：**每份任务交付带一行"弹药使用：用了X，用在Y"**——主脑/主脑据此检查是否真用了沉淀，没用的打回补扫
4. 检查点（主脑复盘时问）：这任务他装载了吗？用上了吗？还是空手做的？

## 六、与现有机制衔接
- 小说域细版：见 novel-session-pipeline 第十三节"弹药装载机制"（含gen_ammo.py调用法）
- 知识沉淀铁律：SOUL.md"沉淀铁律"+知识回流闸门（来源完整/事实核对/状态明确/未来可用四关）
- 本skill只管"用起来"，"存进去"由各域沉淀skill负责——两半合起来才是闭环
